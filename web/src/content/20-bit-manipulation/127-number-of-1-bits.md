# 127. 位1的个数

## 题目描述

编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 `1` 的个数（也被称为汉明重量）。

### 示例 1

```
输入：n = 00000000000000000000000000001011
输出：3
解释：输入的二进制串 00000000000000000000000000001011 中，共有三位为 '1'。
```

### 示例 2

```
输入：n = 00000000000000000000000010000000
输出：1
解释：输入的二进制串 00000000000000000000000010000000 中，共有一位为 '1'。
```

### 示例 3

```
输入：n = 11111111111111111111111111111101
输出：31
解释：输入的二进制串 11111111111111111111111111111101 中，共有 31 位为 '1'。
```

### 约束条件

- 输入必须是长度为 `32` 的二进制串。

## 题目分析

### 算法思路

**朴素想法**：逐位检查 32 位，`count += num & 1; num >>= 1`。无论 1 的个数多少都要循环 32 次。

**方法一：Brian Kernighan 算法**

核心技巧：`n & (n-1)` 会消去 `n` 二进制中**最低位的 1**。理由：设最低位的 1 在第 `k` 位（第 0 位是最低位），则 `n-1` 会把第 `k` 位变成 0、把第 `0..k-1` 位全部变成 1，而第 `k` 位以上保持不变。两者相与后：第 `k` 位以上相同而保留，第 `k` 位因 `1 & 0 = 0` 归零，低 `k` 位因 `n` 原本就是 0 而仍然为 0——恰好只去掉这一个 1。

```
例如：n       = 101100
     n - 1   = 101011
     n & (n-1) = 101000  （最低位的 1 被消除）
```

**算法步骤**：令 `count = 0`；只要 `num != 0`，就执行 `num &= num - 1` 并 `count++`；最后返回 `count`。

**为什么正确**：如上分析，每执行一次 `num &= num - 1` 就恰好消去一个 1，且不会影响其余任何位。因此循环执行次数正好等于 `num` 中 1 的个数；当 `num` 归零时所有 1 都被消掉，`count` 即所求。

**方法二：逐位检查**：循环 32 次，每次 `count += num & 1; num >>= 1`，统计当前最低位后右移一位。逻辑最直观，但固定 32 次循环。

### 复杂度分析

- **时间复杂度**：方法一 O(k)，`k` 为 1 的个数，最坏（全 1）为 32；方法二固定 O(32)。
- **空间复杂度**：O(1)，只用了常数个变量。

### 关键点

- `n & (n-1)` 会消去最低位的 1，是位运算里最常用的技巧之一，务必记住。
- 顺带记一个推论：它可用于判断 2 的幂——`n > 0 && n&(n-1) == 0`。
- 取最低位用 `num & 1`，语义比 `num % 2` 更贴合位运算（对无符号数两者等价）。
- `num` 用 `uint32`，方法二的 `num >>= 1` 才是逻辑右移；若换成有符号类型，算术右移会不断补 1，导致 1 的个数被无限累加。
- 边界：`num = 0` 时两个方法都返回 0；`num = 0xFFFFFFFF` 时返回 32，不要写成 31。
- 该技巧的循环次数与 1 的个数相同，最坏仍是 32 次，所以本题本质上仍是常数时间。

## Go 代码实现

```go
package main

import "fmt"

// 方法一：Brian Kernighan 算法
func hammingWeight(num uint32) int {
    count := 0
    for num != 0 {
        num &= num - 1 // 消除最低位的 1
        count++
    }
    return count
}

// 方法二：逐位检查
func hammingWeight2(num uint32) int {
    count := 0
    for i := 0; i < 32; i++ {
        count += int(num & 1)
        num >>= 1
    }
    return count
}

func main() {
    testCases := []uint32{
        0b00000000000000000000000000001011, // 3
        0b00000000000000000000000010000000, // 1
        0b11111111111111111111111111111101, // 31
    }

    for _, n := range testCases {
        fmt.Printf("n = %032b, 1的个数 = %d\n", n, hammingWeight(n))
    }
}
```
