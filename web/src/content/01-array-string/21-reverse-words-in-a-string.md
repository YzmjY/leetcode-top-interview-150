# 21. 反转字符串中的单词

## 题目描述

给你一个字符串 `s`，请你反转字符串中 **单词** 的顺序。

**单词** 是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的 **单词** 分隔开。

返回 **单词** 顺序颠倒且 **单词** 之间用单个空格连接的结果字符串。

**注意：** 输入字符串 `s` 中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**示例 1：**

```
输入：s = "the sky is blue"
输出："blue is sky the"
```

**示例 2：**

```
输入：s = "  hello world  "
输出："world hello"
解释：反转后的字符串中不能存在前导空格和尾随空格。
```

**示例 3：**

```
输入：s = "a good   example"
输出："example good a"
解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。
```

**约束条件：**

- `1 <= s.length <= 10^4`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中 **至少存在一个单词**

**进阶：** 如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 `O(1)` 额外空间复杂度的 **原地** 解法。

## 题目分析

**算法思路：** Go 中字符串不可变，使用 `strings.Fields` 分割单词（自动处理前导、尾随和单词间的多余空格），然后反转单词数组，最后用 `strings.Join` 以单个空格连接。

**算法步骤：**

1. `words := strings.Fields(s)`：按空白切分并丢弃空片段，得到按原顺序排列的单词列表。
2. 用双指针交换 `words[i]` 与 `words[n-1-i]`（`i < n/2`），把整个列表逆序。
3. `strings.Join(words, " ")` 连接后返回。

**为什么正确：**

`strings.Fields` 的切分规则是"连续的非空白字符构成一个字段，空白序列只作分隔、不进入结果"，这正好等价于题目对"单词"（不含空格的最大连续子串）的定义，因此 `words` 与输入中的单词序列一一对应。把 `words` 逆序后按单个空格连接，得到的字符串单词顺序与输入相反、单词之间恰好一个空格、且没有前导/尾随空格，完全满足题目对输出格式的三点要求。

**时间复杂度：** O(n)，分割、反转、连接各遍历一次字符串或数组。

**空间复杂度：** O(n)，保存切分出的单词切片以及最终结果字符串（Go 字符串不可变，无法原地修改）。

**进阶说明：** 若语言支持可变字符串（例如改用 `[]byte`），可以先把整个串原地反转，再对每个单词单独反转一次，同时压缩多余空格，把额外空间降到 O(1)。本题解选择可读性更好的 `Fields` 方案。

**易错点 / 边界情况：**

- 不能用 `strings.Split(s, " ")`：连续空格会产生空字符串元素，连接后出现多余空格。
- 必须处理前导/尾随空格（示例 2），`Fields` 天然满足，手写实现容易漏掉。
- 只有单个单词时结果就是该单词；单个单词带前后空格时必须把空格去掉。
- 边界用例：`"a"`、`"   a   "`、`"a   b"`、长度为 10⁴ 的输入。

## Go 代码实现

```go
import "strings"

// reverseWords 反转字符串中单词的顺序
// 使用 strings.Fields 自动处理多余空格
func reverseWords(s string) string {
    // Fields 按空格分割，自动去除前导、尾随和多余空格
    words := strings.Fields(s)

    // 反转单词数组
    n := len(words)
    for i := 0; i < n/2; i++ {
        words[i], words[n-1-i] = words[n-1-i], words[i]
    }

    // 用单个空格连接
    return strings.Join(words, " ")
}
```
