# 11. H 指数

## 题目描述

给你一个整数数组 `citations`，其中 `citations[i]` 表示研究者的第 `i` 篇论文被引用的次数。计算并返回该研究者的 **h 指数**。

根据维基百科上 **h 指数的定义**：`h` 代表"高引用次数"，一名科研人员的 `h` 指数是指他（她）至少发表了 `h` 篇论文，并且每篇论文至少被引用了 `h` 次。如果 `h` 有多种可能的值，**h 指数** 是其中最大的那个。

**示例 1：**

```
输入：citations = [3,0,6,1,5]
输出：3
解释：给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 3, 0, 6, 1, 5 次。
由于研究者有 3 篇论文每篇至少被引用了 3 次，其余两篇论文每篇不多于 3 次，所以他的 h 指数是 3。
```

**示例 2：**

```
输入：citations = [1,3,1]
输出：1
```

**约束条件：**

- `n == citations.length`
- `1 <= n <= 5000`
- `0 <= citations[i] <= 1000`

## 题目分析

**算法思路：** 朴素做法是把 `citations` 从大到小排序再线性扫描，复杂度 O(n log n)。但注意 h 指数不可能超过论文总数 `n`——要有 h 篇论文被引用至少 h 次，首先得有 h 篇论文——所以答案一定落在 `[0, n]` 内，可以用计数排序代替比较排序：开一个长度为 `n+1` 的计数数组 `count`，`count[i]` 记录引用次数恰好为 i 的论文篇数，并把引用次数 ≥ n 的论文统一记入 `count[n]`（它们的精确值已不影响 h 的判定）。然后从大到小累加，第一个满足「引用次数 ≥ i 的论文数 ≥ i」的 i 就是答案。

**算法步骤：**

1. `n = len(citations)`，开 `count[0..n]` 并全部置 0。
2. 遍历 `citations`：若 `c >= n` 则 `count[n]++`，否则 `count[c]++`。
3. 令 `total = 0`，从 `i = n` 递减到 `0`：`total += count[i]`，此时 `total` 恰好是引用次数 ≥ i 的论文数；一旦 `total >= i`，说明「有 i 篇论文被引用至少 i 次」成立，直接返回 `i`。
4. 兜底返回 0（实际上 `i = 0` 时 `total >= 0` 恒成立，不会走到这一行）。

**为什么正确：** 对任意 i，`total = count[i] + count[i+1] + ... + count[n]`，由 `count` 的定义这正是引用次数不少于 i 的论文篇数，所以 `total >= i` 与「h = i 可行」完全等价。扫描从 `i = n` 递减，第一次遇到的可行 i 就是最大的可行值，即 h 指数。而 h ≤ n 保证了答案必在 `[0, n]` 中，这也是计数数组开 `n+1` 大小、并把大引用次数截断到 `count[n]` 的依据。

**时间复杂度：** O(n)，一次遍历统计 + 一次长度为 n+1 的倒序扫描。

**空间复杂度：** O(n)，计数数组 `count`。

**易错点：**

- 引用次数可能大于 n，必须把 ≥ n 的值截断到 `count[n]`（数组下标只有 0..n），否则直接 `count[c]++` 会越界 panic。写成 `c >= n` 或 `c > n` 都可以，关键是不能直接按原值当下标。
- 倒序扫描时不能一遇到 `total < i` 就返回 0，必须继续减小 i 检查；h 指数可能落在较小的值上（如 `[1,3,1]` 的答案是 1）。
- h 的定义同时要求「至少 h 篇论文」和「每篇至少 h 次引用」，两个 h 是同一个值，不能只比较总引用次数。
- 边界：`[0]` 返回 0；所有论文引用次数都大于 n 时返回 n；`n == 1` 且引用数 ≥ 1 时返回 1。
- 题目约束 `citations[i] <= 1000`、`n <= 5000`，计数法不会退化；即使没有这个上界，把 ≥ n 的值截断到 n 也仍然是 O(n)。

## Go 代码实现

```go
// hIndex 计算研究者的 H 指数
// 使用计数排序思想，h 指数不会超过数组长度 n
func hIndex(citations []int) int {
    n := len(citations)
    // count[i] 记录引用次数为 i 的论文数量
    // 引用次数大于等于 n 的论文统一记录在 count[n] 中
    count := make([]int, n+1)

    for _, c := range citations {
        if c >= n {
            count[n]++
        } else {
            count[c]++
        }
    }

    // total 记录引用次数 >= i 的论文累计数量
    total := 0
    // 从大到小遍历，寻找最大的满足条件的 h
    for i := n; i >= 0; i-- {
        total += count[i]
        // 如果引用次数 >= i 的论文数量 >= i，则 i 就是 h 指数
        if total >= i {
            return i
        }
    }
    return 0
}
```
