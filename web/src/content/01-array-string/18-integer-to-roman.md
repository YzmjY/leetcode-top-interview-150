# 18. 整数转罗马数字

## 题目描述

罗马数字包含以下七种字符: `I`, `V`, `X`, `L`, `C`, `D` 和 `M`。

```
字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

例如，罗马数字 `2` 写做 `II`，即为两个并列的 1。`12` 写做 `XII`，即为 `X + II`。`27` 写做 `XXVII`，即为 `XX + V + II`。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`，数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V` (5) 和 `X` (10) 的左边，来表示 4 和 9。
- `X` 可以放在 `L` (50) 和 `C` (100) 的左边，来表示 40 和 90。
- `C` 可以放在 `D` (500) 和 `M` (1000) 的左边，来表示 400 和 900。

给你一个整数，将其转为罗马数字。

**示例 1：**

```
输入: num = 3
输出: "III"
```

**示例 2：**

```
输入: num = 4
输出: "IV"
```

**示例 3：**

```
输入: num = 9
输出: "IX"
```

**示例 4：**

```
输入: num = 58
输出: "LVIII"
解释: L = 50, V = 5, III = 3.
```

**示例 5：**

```
输入: num = 1994
输出: "MCMXCIV"
解释: M = 1000, CM = 900, XC = 90, IV = 4.
```

**约束条件：**

- `1 <= num <= 3999`

## 题目分析

**算法思路：** 贪心算法。把所有"符号 + 数值"对按数值从大到小排成一张表，其中除 7 个基本符号外，还要显式列出 6 个减法组合（`CM`=900、`CD`=400、`XC`=90、`XL`=40、`IX`=9、`IV`=4）。每次从 `num` 中减去当前能用的最大数值，并把对应符号追加到结果中，直到 `num` 减为 0。

**算法步骤：**

1. 准备 `values = [1000,900,500,400,100,90,50,40,10,9,5,4,1]` 与对应的 `symbols`，两者一一对应且从大到小。
2. 令 `result` 为空串，按顺序枚举表中的每个 `values[i]`。
3. 当 `num >= values[i]` 时反复执行 `num -= values[i]`、`result += symbols[i]`（同一符号可重复使用，如 3000 用三个 `M`）。
4. 表中符号处理完或 `num == 0` 后返回 `result`。

**为什么正确（贪心选择性质）：**

标准罗马数字在 `[1, 3999]` 上的表示是唯一的，并且它的首位符号恰好是"不超过 `num` 的最大符号"：`num` 落在哪个区间（如 900~999 对应 `CM`、1000~3999 对应 `M`），首位符号就是该区间的表项。贪心每一步取的正是这个最大可用符号，即每一步都选出了标准表示的首符号；减去它之后，剩余部分的表示同样由更小区间的表项唯一决定。因此整个过程拼出的字符串就是标准表示本身。

换一个角度看是按十进制位分解：千位用若干个 `M`，百位按 `900/500/400/100` 的顺序取，十位、个位同理。贪心表的顺序正是 `1000 → 900 → 500 → 400 → 100 → …`，与逐位处理的顺序完全一致。

**时间复杂度：** O(1)。符号表固定 13 项；`num ≤ 3999` 时字符追加总次数不超过 15，与输入规模无关（严格说与数字位数对数相关，但在本题范围内是常数）。

**空间复杂度：** O(1)。除输出字符串外只用常量额外空间，输出长度上限为 15 个字符。

**易错点 / 边界情况：**

- 必须把 6 个减法组合放进表里；只列 7 个基本符号会输出 `IIII`、`DCCCC` 这类非法写法。
- 表必须严格按数值降序，且 `900` 要排在 `500` 前、`400` 排在 `100` 前，否则 400 会被错误地拆成 `D` 加若干 `C`。
- 内层用 `for num >= values[i]` 而不是 `if`，因为同一符号可以重复多次。
- 边界用例：`1`（最小）、`4`、`9`、`3999`（最大）、`3888`（输出最长，15 个字符）。

## Go 代码实现

```go
// intToRoman 将整数转换为罗马数字
// 使用贪心策略，从大到小尽可能使用较大的罗马数字符号
func intToRoman(num int) string {
    // 将所有可能的罗马数字表示按数值从大到小排列
    values := []int{1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1}
    symbols := []string{"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"}

    // 输出最长只有 15 个字符，直接用字符串拼接即可
    result := ""

    for i := 0; i < len(values) && num > 0; i++ {
        // 当前数值可以被 values[i] 表示多少次
        for num >= values[i] {
            num -= values[i]
            result += symbols[i]
        }
    }

    return result
}
```
