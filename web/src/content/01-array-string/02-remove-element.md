# 2. 移除元素

## 题目描述

给你一个数组 `nums` 和一个值 `val`，你需要 **原地** 移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

不要使用额外的数组空间，你必须仅使用 `O(1)` 额外空间并 **原地** 修改输入数组。

元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

**示例 1：**

```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：你的函数应该返回 k = 2, 并且 nums 中的前两个元素均为 2。
你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。
```

**示例 2：**

```
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,4,0,3,_,_,_]
解释：你的函数应该返回 k = 5，并且 nums 中的前五个元素为 0,0,1,3,4。
注意这五个元素可以任意顺序返回。
你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。
```

**约束条件：**

- `0 <= nums.length <= 100`
- `0 <= nums[i] <= 50`
- `0 <= val <= 100`

## 题目分析

**算法思路：** 朴素做法是另开一个数组，把不等于 `val` 的元素按序放进去，最后拷回 `nums`，但题目要求 O(1) 额外空间。注意到我们只需要保证「前 `k` 个位置放的是保留下来的元素」，后面留什么无所谓，因此可以让一个慢指针只在原地维护有效前缀：凡是保留下来的元素就写入 `slow` 位置，`slow` 只增不减，绝不会写到还没读过的元素上。

具体使用快慢指针：

- `slow` 指向下一个「保留元素」应当放置的位置，同时它的值就是当前已保留元素的个数（初值 0）；
- `fast` 从 0 遍历到 `n-1`，逐个检查元素。

当 `nums[fast] != val` 时，把 `nums[fast]` 写到 `nums[slow]`，然后 `slow++`；当 `nums[fast] == val` 时跳过，`slow` 不动。

**算法步骤：**

1. `slow = 0`。
2. `fast` 从 0 到 `n-1`：若 `nums[fast] != val`，执行 `nums[slow] = nums[fast]; slow++`。
3. 返回 `slow`。

**为什么正确：** 循环维护的不变量是「遍历到 `fast-1` 为止，所有保留下来的元素都已经按原相对顺序放在 `nums[0..slow-1]` 中，且个数恰好为 `slow`」。由于 `slow <= fast` 恒成立（只有保留元素时才自增，最多与 `fast` 同步），写 `nums[slow]` 时该位置要么就是 `fast` 本身（`slow == fast`，自赋值），要么是已经检查过的位置，不会破坏尚未检查的数据。遍历结束后所有 `!= val` 的元素都恰好被写入一次，`slow` 就是保留元素个数。

**时间复杂度：** O(n)，`fast` 恰好遍历一次数组，常数时间操作。

**空间复杂度：** O(1)，只用两个下标变量，原地修改。

**易错点 / 边界情况：**

- 空数组 `nums = []`：循环不执行，返回 0，代码天然正确。
- 所有元素都等于 `val`：返回 0；所有元素都不等于 `val`：返回 `n`。
- `slow` 与 `fast` 的职责不要混淆：`slow` 是「写指针」而不是「已删除元素计数」，把自增写错位置会少写或多写元素。
- 本题允许返回值之后的位置残留任意内容，不要额外去清零（那样反而是画蛇添足，虽然不影响复杂度）。
- 题目允许前 `k` 个元素任意顺序，本实现保留相对顺序。对示例 2，代码实际得到前 5 个元素为 `[0,1,3,0,4]`，与题面示意图 `[0,1,4,0,3]` 顺序不同但集合相同，两者都合法。

## Go 代码实现

```go
// removeElement 原地移除数组中所有等于 val 的元素，返回新数组长度
// 使用快慢指针：慢指针指向有效位置，快指针遍历数组
func removeElement(nums []int, val int) int {
    // slow 指向下一个不等于 val 的元素应该放置的位置
    slow := 0
    // fast 遍历数组中的每个元素
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != val {
            // 将不等于 val 的元素移动到前面
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```
