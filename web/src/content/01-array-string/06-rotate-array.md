# 6. 轮转数组

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

**示例 2：**

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

**约束条件：**

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

**进阶：**
- 尽可能想出更多的解决方案，至少有 **三种** 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 `O(1)` 的 **原地** 算法解决这个问题吗？

## 题目分析

**算法思路：** 最朴素的两次翻转需要额外数组，直接模拟 `k` 次「整体右移一位」则需要 O(nk) 时间并可能超时（`k` 最大 10^5）。要原地 O(1) 完成，需要找到一个「只靠交换就能实现循环移位」的变换。

关键观察：向右轮转 `k` 位，等价于把数组切成 `A = nums[0..n-k-1]` 和 `B = nums[n-k..n-1]` 两段，让它们交换位置变成 `BA`。而这一效果可以完全通过**三次翻转**得到：

1. 翻转整个数组：`AB` → `reverse(B) reverse(A)`；
2. 翻转前 `k` 个元素：`reverse(B)` → `B`，得到 `B reverse(A)`；
3. 翻转后 `n-k` 个元素：`reverse(A)` → `A`，得到 `BA`。

先对 `k` 取模 `k = k % n`，当 `k > n` 时避免多余操作。

**算法步骤：**

1. `n = len(nums)`，令 `k = k % n`；若 `k == 0` 直接返回。
2. 写一个辅助函数 `reverse(l, r)`，用双指针对撞交换 `nums[l..r]`。
3. 依次执行 `reverse(0, n-1)`、`reverse(0, k-1)`、`reverse(k, n-1)`。

**为什么正确：** 设 `B = nums[n-k..n-1]`（长度为 `k` 的后缀），`A = nums[0..n-k-1]`（长度为 `n-k` 的前缀），原数组为 `AB`。翻转整个数组后变成 `reverse(B) · reverse(A)`；再翻转前 `k` 个元素，`reverse(B)` 被翻回 `B`，此时数组为 `B · reverse(A)`；最后翻转后 `n-k` 个元素，`reverse(A)` 被翻回 `A`，得到 `BA`。而 `BA` 正是右移 `k` 位的结果：原来的后缀 `B` 移到了前面。取模不改变结果，因为右移 `n` 位等于原数组，右移 `k` 与右移 `k mod n` 等价。

**时间复杂度：** O(n)。三次翻转合计走过的元素数为 `n + k + (n-k) = 2n`，每个元素被交换两次，是常数倍。

**空间复杂度：** O(1)，只使用下标变量与就地交换。

**易错点 / 边界情况：**

- 必须先对 `k` 取模。`k` 可以大于 `n`（例如 `n = 3, k = 7`，等价于 `k = 1`），不取模时 `k-1 >= n` 会越界。
- `k % n` 在 `n == 0` 时会除零崩溃；本题约束 `n >= 1`，若需通用可先判断空数组。
- `k == 0`（含取模后为 0）时直接返回只是一次剪枝：即使不返回，`reverse(0, k-1) = reverse(0, -1)` 空操作，而 `reverse(0, n-1)` 与 `reverse(k, n-1) = reverse(0, n-1)` 两次整体翻转互相抵消，结果仍为原数组、同样正确。显式返回只是省掉两次无意义翻转，并非正确性所必需。
- 三次翻转的顺序（整体 → 前 k → 后 n-k）不能随意调换，交换前两次会得到错误结果。
- `reverse` 的区间是闭区间 `[l, r]`（`for l < r` 时交换），调用时传 `n-1`、`k-1`，不要按 Go 惯用的左闭右开写成 `reverse(0, n)`。
- 取模后 `k` 是后缀 `B` 的长度，前缀 `A` 的长度是 `n-k`，第二、三次翻转的分界点都是下标 `k`（`reverse(0, k-1)` 与 `reverse(k, n-1)`），注意别把分界点写成 `n-k`。

## Go 代码实现

```go
// rotate 将数组向右轮转 k 个位置，使用三次翻转法
func rotate(nums []int, k int) {
    n := len(nums)
    // k 可能大于 n，取模避免无效操作
    k = k % n
    if k == 0 {
        return
    }

    // 辅助函数：翻转 nums[l:r+1] 区间
    reverse := func(l, r int) {
        for l < r {
            nums[l], nums[r] = nums[r], nums[l]
            l++
            r--
        }
    }

    // 1. 翻转整个数组
    reverse(0, n-1)
    // 2. 翻转前 k 个元素
    reverse(0, k-1)
    // 3. 翻转后 n-k 个元素
    reverse(k, n-1)
}
```
