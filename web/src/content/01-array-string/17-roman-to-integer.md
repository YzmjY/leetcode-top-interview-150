# 17. 罗马数字转整数

## 题目描述

罗马数字包含以下七种字符: `I`, `V`, `X`, `L`, `C`, `D` 和 `M`。

```
字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

例如，罗马数字 `2` 写做 `II`，即为两个并列的 1。`12` 写做 `XII`，即为 `X + II`。`27` 写做 `XXVII`，即为 `XX + V + II`。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V` (5) 和 `X` (10) 的左边，来表示 4 和 9。
- `X` 可以放在 `L` (50) 和 `C` (100) 的左边，来表示 40 和 90。
- `C` 可以放在 `D` (500) 和 `M` (1000) 的左边，来表示 400 和 900。

给定一个罗马数字，将其转换成整数。

**示例 1：**

```
输入: s = "III"
输出: 3
```

**示例 2：**

```
输入: s = "IV"
输出: 4
```

**示例 3：**

```
输入: s = "IX"
输出: 9
```

**示例 4：**

```
输入: s = "LVIII"
输出: 58
解释: L = 50, V= 5, III = 3.
```

**示例 5：**

```
输入: s = "MCMXCIV"
输出: 1994
解释: M = 1000, CM = 900, XC = 90, IV = 4.
```

**约束条件：**

- `1 <= s.length <= 15`
- `s` 仅含字符 `('I', 'V', 'X', 'L', 'C', 'D', 'M')`
- 题目数据保证 `s` 是一个有效的罗马数字，且表示整数在范围 `[1, 3999]` 内
- 题目所给测试用例皆符合罗马数字书写规则，不会出现跨位等情况

## 题目分析

**算法思路：** 模拟法。从左到右遍历罗马数字字符串，比较当前字符与下一个字符对应的数值。如果当前字符代表的数值小于下一个字符，说明当前字符是减法特例（如 IV、IX），应当减去当前数值；否则加上当前数值。

例如 `MCMXCIV = M(+1000) + C(-100) + M(+1000) + X(-10) + C(+100) + I(-1) + V(+5) = 1994`。

**算法步骤：**

1. 建立字符到数值的映射（只有 7 种字符，用哈希表或定长数组均可）。
2. 令 `result = 0`，从左到右枚举下标 `i`。
3. 对每个 `i`：若 `i+1 < n` 且 `value(s[i]) < value(s[i+1])`，说明 `s[i]` 与其右邻构成减法组合，执行 `result -= value(s[i])`；否则执行 `result += value(s[i])`。
4. 遍历结束后返回 `result`。

**为什么正确：**

罗马数字的数值可以按"位"拆开理解：千位由若干 `M` 组成，百位是 `CM/CD/D/C` 之一，十位、个位同理。每个"位"的数值恰好等于对该段字符逐个应用上述加减规则之和——因为同一段内只有段首那个字符可能小于它的右邻（如 `CD` 中的 `C`），其余字符都满足"不小于右邻"。

题目保证输入是合法的罗马数字，因此"左邻数值小于右邻"的相邻对只可能出现在 `IV / IX / XL / XC / CD / CM` 这六种组合中。于是逐字符判断加减，等价于把每个字符按它在整个数字中实际承担的角色计入总和，结果与按位拆解求和一致。

**时间复杂度：** O(n)，只遍历字符串一次。

**空间复杂度：** O(1)，字符表大小固定为 7，与输入规模无关。

**易错点 / 边界情况：**

- 最后一个字符没有右邻，必须走"加"的分支（代码用 `i < n-1` 短路，同时避免越界）。
- 减法只发生在**相邻**两个字符之间，不能写成"只要后面出现过更大的数就减"。例如 `MCMXCIV` 中第二个 `M` 左边是 `C`，但它自身仍要加。
- 合法写法中不会出现跨位组合（如 `IL`），因此不需要额外校验。
- 边界用例：单字符（`I`）、连续相同字符（`VIII`）、同时含多个减法组合（`MCMXCIV`）、最大值 `MMMCMXCIX = 3999`。

## Go 代码实现

```go
// romanToInt 将罗马数字字符串转换为整数
// 使用哈希表映射字符到数值，通过比较相邻字符决定加减
func romanToInt(s string) int {
    // 罗马数字字符到数值的映射
    romanMap := map[byte]int{
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000,
    }

    result := 0
    n := len(s)

    for i := 0; i < n; i++ {
        currentVal := romanMap[s[i]]
        // 如果当前字符的数值小于下一个字符的数值，执行减法
        if i < n-1 && currentVal < romanMap[s[i+1]] {
            result -= currentVal
        } else {
            result += currentVal
        }
    }

    return result
}
```
