# 1. 合并两个有序数组

## 题目描述

给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**注意：** 最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0`，应忽略。`nums2` 的长度为 `n`。

**示例 1：**

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6]。
合并结果是 [1,2,2,3,5,6]。
```

**示例 2：**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 []。
合并结果是 [1]。
```

**示例 3：**

```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组是 [] 和 [1]。
合并结果是 [1]。
注意，因为 m = 0 ，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。
```

**约束条件：**

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

**进阶：** 你可以设计实现一个时间复杂度为 `O(m + n)` 的算法解决此问题吗？

## 题目分析

**算法思路：** 如果从前往后合并，就必须先把 `nums1` 的有效元素搬到临时数组，否则写入结果时会覆盖尚未参与比较的元素。但题目已经保证 `nums1` 的长度为 `m+n`、末尾 `n` 个位置是空的——这正是为「从后往前填」留出的空间。于是自然想到：每次取出两个数组当前的最大值，放到合并结果的最后。这样处理过的位置不会再次被读，天然避免了覆盖问题。

具体使用三个指针：

- `p1` 指向 `nums1` 中尚未处理的有效元素末尾，初值 `m-1`；
- `p2` 指向 `nums2` 的末尾，初值 `n-1`；
- `tail` 指向合并后数组的末尾，初值 `m+n-1`。

每一轮比较 `nums1[p1]` 与 `nums2[p2]`，把较大者写入 `nums1[tail]`，对应指针前移，`tail` 前移。

**算法步骤：**

1. 初始化 `p1 = m-1`、`p2 = n-1`、`tail = m+n-1`。
2. 当 `p1 >= 0` 且 `p2 >= 0` 时循环：比较 `nums1[p1]` 与 `nums2[p2]`，较大者写入 `nums1[tail]`，该指针左移；`tail` 左移。
3. 循环结束后，若 `p2 >= 0`，把 `nums2` 的剩余元素依次写入 `nums1[tail]` 及更前的位置。
4. 若只剩 `nums1` 未处理，则它们本就在正确位置上，无需搬动。

**为什么正确：** 循环维护的不变量是「`nums1[tail+1 .. m+n-1]` 已经是全部 `m+n` 个元素中最大的若干个，并且按非递减顺序排列」。每轮之所以能直接取两个数组的末尾元素比较：因为 `nums1[0..p1]` 和 `nums2[0..p2]` 各自有序，各自的未处理前缀的最大值恰好在各自末尾，两者的较大者就是整个未处理集合的最大值，把它放到当前最大值应在的位置 `tail`，不变量保持。同时写入位置始终满足 `tail >= p1`：初始时 `tail - p1 = n >= 0`；每轮若选中 `nums1` 的元素，则 `p1` 与 `tail` 同时左移，差值不变；若选中 `nums2` 的元素，则只有 `tail` 左移，差值减 1，但不会降到 0 以下。因此 `tail` 永远停在 `p1` 的右侧，不会覆盖 `nums1` 中尚未比较的元素。循环终止时至少一个数组已取空：若 `nums2` 空，剩余 `nums1` 前缀本身有序且在正确位置；若 `nums1` 空，把 `nums2` 剩余前缀整体前移即可。两种情况都得到完整有序数组。

**时间复杂度：** O(m + n)。每轮循环 `tail` 恰好左移一次，总共执行 `m+n` 次写入（主循环 + 收尾拷贝），每个元素只被处理一次。

**空间复杂度：** O(1)，只用了三个下标变量，原地修改 `nums1`。

**易错点 / 边界情况：**

- `m = 0`：主循环一次都不执行，必须靠第 3 步把 `nums2` 整体拷入 `nums1`；漏掉这段收尾拷贝是本题最常见的错误。
- `n = 0`：`nums2` 为空，不应做任何拷贝；代码中 `p2 = -1`，`for p2 >= 0` 天然不执行。
- 循环条件必须同时判断两个下标（`p1 >= 0 && p2 >= 0`），只判断一个会越界。
- 相等元素时取 `nums1[p1]` 还是 `nums2[p2]` 都可以，结果仍然有序，不必纠结。
- 函数没有返回值，结果必须写在传入的 `nums1` 里，不能新建切片返回。
- 复杂度要求是 O(m+n)（进阶要求），若采用「先拼接再排序」会退化为 O((m+n)log(m+n))。

## Go 代码实现

```go
// merge 合并两个有序数组，结果存储在 nums1 中
// 使用逆向双指针，从后向前填充，避免覆盖未处理元素
func merge(nums1 []int, m int, nums2 []int, n int) {
    // p1 指向 nums1 有效元素的末尾
    // p2 指向 nums2 的末尾
    // tail 指向合并后数组的末尾
    p1, p2, tail := m-1, n-1, m+n-1

    // 当两个数组都还有元素时，比较并放入较大的元素
    for p1 >= 0 && p2 >= 0 {
        if nums1[p1] > nums2[p2] {
            nums1[tail] = nums1[p1]
            p1--
        } else {
            nums1[tail] = nums2[p2]
            p2--
        }
        tail--
    }

    // 如果 nums2 还有剩余元素，将其复制到 nums1 的前面
    // 注意：如果 nums1 还有剩余元素，它们已经在正确的位置，不需要处理
    for p2 >= 0 {
        nums1[tail] = nums2[p2]
        p2--
        tail--
    }
}
```
