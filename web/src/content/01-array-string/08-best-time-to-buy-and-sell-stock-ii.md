# 8. 买卖股票的最佳时机 II

## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候 **最多** 只能持有 **一股** 股票。你也可以先购买，然后在 **同一天** 出售。

返回 *你能获得的 **最大** 利润*。

**示例 1：**

```
输入：prices = [7,1,5,3,6,4]
输出：7
解释：在第 2 天（股票价格 = 1）的时候买入，在第 3 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。
随后，在第 4 天（股票价格 = 3）的时候买入，在第 5 天（股票价格 = 6）的时候卖出, 这笔交易所能获得利润 = 6 - 3 = 3。
最大总利润为 4 + 3 = 7。
```

**示例 2：**

```
输入：prices = [1,2,3,4,5]
输出：4
解释：在第 1 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 5）的时候卖出, 这笔交易所能获得利润 = 5 - 1 = 4。
最大总利润为 4。
```

**示例 3：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 交易无法获得正利润，所以不参与交易可以获得最大利润，最大利润为 0。
```

**约束条件：**

- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 题目分析

**算法思路：** 本题允许**无限次**交易（同一时刻最多持有一股），于是可以「低买高卖」反复赚取每一段上涨行情。关键观察来自利润的可拆分性：如果价格从第 `i` 天到第 `j` 天持续上涨，那么一次持有到底的利润 `prices[j] - prices[i]` 恰好等于中间每一小段差价之和：

```
prices[j] - prices[i] = (prices[i+1]-prices[i]) + (prices[i+2]-prices[i+1]) + ... + (prices[j]-prices[j-1])
```

而「每天持有、隔天卖出再买回」在本题规则下完全允许。因此与其去找交易的起止点，不如直接**把所有相邻两天的正差价累加**：只要今天比昨天高，就当作昨天买入今天卖出，赚下这段差价；只要今天比昨天低，就不参与，避免亏损。

**算法步骤：**

1. `totalProfit = 0`。
2. 从 `i = 1` 遍历到 `n-1`：若 `prices[i] > prices[i-1]`，则 `totalProfit += prices[i] - prices[i-1]`。
3. 返回 `totalProfit`。

**为什么贪心是正确的？** 从两个方向论证：

- **贪心解 ≤ 最优解**：第 2 步累加的每一段 `prices[i] - prices[i-1] > 0` 都对应一次合法操作——在第 `i-1` 天买入、第 `i` 天卖出（持有期仅为一天，且相邻两天不重叠，满足「任意时刻最多持有一股」）。因此贪心方案本身就是一套合法交易组合，其收益不可能超过最优收益。
- **最优解 ≤ 贪心解**：对任意合法交易方案，把每次交易 `[买 i, 卖 j]` 的利润按天拆成 `Σ (prices[k+1] - prices[k])`（`k = i..j-1`）。这个和不会超过「只累加为正的相邻差价」所得的和，因为把其中每个差价替换成 `max(差价, 0)` 只会让它变大或不变，而贪心的总和正是所有 `max(prices[i]-prices[i-1], 0)` 之和，故贪心解 ≥ 任意合法方案的收益，特别地 ≥ 最优解。

两个方向合起来说明贪心解 = 最优解。直观理解：下跌的差价（`prices[i] < prices[i-1]`）意味着持仓会亏，跳过不赚即可；上涨的差价全部落袋，不会有任何损失。

**时间复杂度：** O(n)，遍历一次数组。

**空间复杂度：** O(1)，只用一个累加变量。

**易错点 / 边界情况：**

- 判断条件用 `prices[i] > prices[i-1]` 即可；相等时差价为 0，写成 `>=` 结果也完全一样，只是 `>` 的语义更贴合「只有真正上涨才交易」。
- 单元素数组返回 0（循环不执行）；单调递减数组（示例 3）返回 0。
- 不要误以为需要维护持股状态或最低价——本题因为可以任意多次交易，直接累加正差价就够，这是与 121 题（只允许一次交易）最本质的区别。
- 交易不要求天数间隔，允许「同一天卖出后再买入」，这也正是把一次长持有拆成多段短交易的前提；题目已明确允许同一天买卖。
- 若题目改为限制交易次数 `k`，本贪心不再成立，需要改用动态规划。
- 按约束 `n <= 3*10^4`、价格 `<= 10^4`，答案上界约为 `3*10^8`，不会溢出 32 位整数，`int` 足够。

## Go 代码实现

```go
// maxProfit 计算可以多次交易股票能获得的最大利润
// 贪心策略：累加所有相邻两天的正差价
func maxProfit(prices []int) int {
    // totalProfit 累计总利润
    totalProfit := 0

    for i := 1; i < len(prices); i++ {
        // 如果今天价格高于昨天，就进行交易
        if prices[i] > prices[i-1] {
            totalProfit += prices[i] - prices[i-1]
        }
    }

    return totalProfit
}
```
