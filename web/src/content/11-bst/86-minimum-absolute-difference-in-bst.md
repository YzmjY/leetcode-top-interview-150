# 86. 二叉搜索树的最小绝对差

## 题目描述

给你一个二叉搜索树的根节点 `root`，返回 **树中任意两不同节点值之间的最小差值**。

差值是一个正数，其数值等于两值之差的绝对值。

**示例 1：**

```
输入：root = [4,2,6,1,3]
输出：1
```

**示例 2：**

```
输入：root = [1,0,48,null,null,12,49]
输出：1
```

**提示：**

- 树中节点的数目范围是 `[2, 10^4]`。
- `0 <= Node.val <= 10^5`

**注意**：本题与 LeetCode 530 相同。

## 题目分析

### 算法思路

**核心观察**：BST 的**中序遍历结果是升序序列**。题目要求「任意两个不同节点值之差的最小绝对值」，等价于在升序序列中找最小间隔。而升序序列里，最小间隔**一定出现在相邻的两个元素之间**——这样就不必枚举所有点对 `O(n^2)`，只需一次中序遍历、始终只比较「当前节点」与「中序前驱」即可。

**算法步骤**：

1. 用递归做中序遍历（左 -> 根 -> 右），用一个指针 `prev` 记录上一个访问过的节点值，初值为 `nil`。
2. 处理当前节点时，若 `prev != nil`，计算 `|node.Val - *prev|` 并更新 `minDiff`。
3. 把 `prev` 更新为当前节点，继续遍历右子树。
4. 遍历结束后 `minDiff` 即答案。题目保证节点数 ≥ 2，所以必然至少更新过一次。

**为什么用 `*int` 而不是哨兵整数？** 节点值域是 `[0, 10^5]`，用 `-1` 之类的哨兵也能跑通，但用指针表达「还没有前驱」更稳妥，也不依赖具体值域。

### 为什么正确

设中序遍历得到的升序序列为 `a[0] < a[1] < ... < a[n-1]`（BST 的定义保证中序升序：左子树所有值小于根、右子树所有值大于根，递归即得）。

对任意 `i < j`，有

```
a[j] - a[i] = (a[i+1]-a[i]) + (a[i+2]-a[i+1]) + ... + (a[j]-a[j-1]) ≥ min{ a[k+1]-a[k] }
```

因为每一项都是正数，求和不会比最小项更小。于是「所有点对差值的最小值」就等于「所有相邻差值的最小值」，即

```
min_{i<j} (a[j]-a[i]) = min_k (a[k+1]-a[k])
```

算法在中序遍历过程中恰好遍历了每一对相邻元素（当前节点与它的中序前驱），所以 `minDiff` 最终等于全局最小值。

### 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问一次，比较是 O(1) 的。
- **空间复杂度**：O(h)，递归栈深度，h 为树高；链状树时退化为 O(n)。

### 易错点 / 边界情况

- 本题**不能用「只比较节点与左右孩子的差值」的局部做法**：最小差可能出现在没有父子关系的两个节点之间。例如树 `[5,1,null,null,4]`（根 5，左孩子 1，1 的右孩子 4）的答案是 `1`，它来自 4 和 5 这一对祖孙节点，而两对父子差分别是 4 和 3。
- `prev` 必须在处理完当前节点后更新，且要放在「计算差值」之后，否则会拿自己和自己比。
- 中序序列严格升序，所以 `node.Val - *prev` 本身非负；代码里仍取了绝对值，只是防御性写法，不影响结果。
- `minDiff` 的初值要足够大（代码用 `1<<31 - 1`）；节点值最大 10^5，不会溢出。
- 题目保证节点数 ≥ 2，不必处理「只有一个节点」的返回约定；但递归要以 `node == nil` 作为出口。
- 深度可达 10^4，递归实现依赖 Go 的动态栈；若在递归深度受限的环境中需改成显式栈的迭代中序。
- 不要用 `prev = &node.Val` 之外的写法去保存「值拷贝」的地址，那样不会报错但语义容易混乱；`&node.Val` 指向的是存活节点，安全。

## Go 代码实现

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func getMinimumDifference(root *TreeNode) int {
    minDiff := 1<<31 - 1 // 初始化为最大值
    var prev *int

    var inorder func(*TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return
        }

        // 遍历左子树
        inorder(node.Left)

        // 处理当前节点
        if prev != nil {
            diff := node.Val - *prev
            if diff < 0 {
                diff = -diff
            }
            if diff < minDiff {
                minDiff = diff
            }
        }
        prev = &node.Val

        // 遍历右子树
        inorder(node.Right)
    }

    inorder(root)
    return minDiff
}
```
