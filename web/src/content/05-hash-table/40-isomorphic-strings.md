# 40. 同构字符串

## 题目描述

给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

**示例 1：**

```
输入：s = "egg", t = "add"
输出：true
```

**示例 2：**

```
输入：s = "foo", t = "bar"
输出：false
```

**示例 3：**

```
输入：s = "paper", t = "title"
输出：true
```

**约束条件：**

- `1 <= s.length <= 5 * 10^4`
- `t.length == s.length`
- `s` 和 `t` 由任意有效的 ASCII 字符组成

## 题目分析

### 算法思路

同构字符串要求建立 **双向的一一映射**，即：

1. `s` 中的每个字符只能映射到 `t` 中的一个固定字符。
2. `t` 中的每个字符也只能被 `s` 中的一个固定字符映射。

因此需要两张哈希表（或两个数组，因为 ASCII 共 128 个字符）分别记录两个方向的映射关系。

遍历字符串 `s` 和 `t` 的每个位置：
- 如果 `s[i]` 已经映射到了某个字符，检查它是否等于 `t[i]`，不等于则返回 `false`。
- 如果 `t[i]` 已经映射到了某个字符，检查它是否等于 `s[i]`，不等于则返回 `false`。
- 如果都没有映射过，则建立双向映射。

### 算法步骤

1. 建立两张大小为 128 的映射表 `s2t`、`t2s`，并全部初始化为 `-1` 表示「尚未建立映射」。**这里必须用 `-1` 而不能用 `0` 作哨兵**，因为 NUL 字符（编码 0）本身也是合法的 ASCII 字符，用 `0` 表示未映射会与「`s[i]` 映射到 NUL」混淆。
2. 从左到右同时遍历 `s`、`t`，取 `sc = int(s[i])`、`tc = int(t[i])`。
3. 若 `s2t[sc] != -1 && s2t[sc] != tc`，说明 `sc` 此前已映射到别的字符，违反「相同字符只能映射到同一个字符」，返回 `false`。
4. 若 `t2s[tc] != -1 && t2s[tc] != sc`，说明 `tc` 已被别的字符占用，违反「不同字符不能映射到同一个字符」，返回 `false`。
5. 两个方向都写入映射：`s2t[sc] = tc`、`t2s[tc] = sc`。
6. 遍历结束没有冲突，返回 `true`。

### 为什么正确

同构的定义等价于：存在一个双射 `f`，使 `t[i] = f(s[i])` 对每个 `i` 成立。`s2t` 检查的是**函数性**——每个 `s` 字符至多有一个像，一旦发现 `s[i]` 的像与当前 `t[i]` 不一致就冲突；`t2s` 检查的是**单射性**——不同 `s` 字符不能有相同像，一旦发现 `t[i]` 已对应别的 `s` 字符就冲突。两者同时成立，等价于「已确认的前缀存在一致的双射」。反之，若整个遍历都没有冲突，把已建立的映射按任意方式补全成双射，就能满足题目要求，所以返回 `true` 正确。

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是字符串长度。只需要遍历一次，每次映射查询是 O(1)。
- **空间复杂度**：O(1)，使用两个固定大小（128）的数组。

### 易错点 / 边界情况

- 两张表都必须检查：只查 `s2t` 会漏掉 `"ab" -> "aa"` 这类「不同字符映射到同一字符」的情况。
- 哨兵值必须避开合法字符值。用 `[128]byte` 且以 `0` 表示未映射的写法，在输入含 NUL 字符时漏检冲突（例如 `s = "aa"`、`t = "\x00\x01"` 会被错判为 `true`）；改用 `int` 数组配 `-1` 哨兵才严谨。
- 约束保证 `s` 与 `t` 等长；若调用方可能传入不等长输入，应先判断 `len(s) != len(t)` 返回 `false`，否则遍历 `s` 时会下标越界。
- 允许字符映射到自身（`"abc"` 与 `"abc"` 是同构的），不要误认为「每个字符都必须被替换」。
- 不能只建立单向映射后就认为完成，两个方向的约束缺一不可。
- 用 map 也能做，但固定字符集下用数组更快、更省内存。

## Go 代码实现

```go
func isIsomorphic(s string, t string) bool {
    // s -> t 的映射，-1 表示该字符尚未建立映射
    s2t := [128]int{}
    // t -> s 的映射，-1 表示该字符尚未建立映射
    t2s := [128]int{}
    for i := range s2t {
        s2t[i] = -1
        t2s[i] = -1
    }

    for i := 0; i < len(s); i++ {
        sc, tc := int(s[i]), int(t[i])

        // 检查 s[i] -> t[i] 的映射是否一致
        if s2t[sc] != -1 && s2t[sc] != tc {
            return false
        }
        // 检查 t[i] -> s[i] 的映射是否一致
        if t2s[tc] != -1 && t2s[tc] != sc {
            return false
        }

        // 建立双向映射
        s2t[sc] = tc
        t2s[tc] = sc
    }

    return true
}
```
