# 59. 合并两个有序链表

## 题目描述

将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**示例 1：**

```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2：**

```
输入：l1 = [], l2 = []
输出：[]
```

**示例 3：**

```
输入：l1 = [], l2 = [0]
输出：[0]
```

**约束条件：**

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列

## 题目分析

### 算法思路

**核心思路：** 这就是归并排序里「合并两个有序数组」那一步的链表版本。两个链表各自有序，意味着**每条链的当前头部就是该链剩余元素里最小的**。所以只要比较两条链的头部，把较小者摘下来接到结果链末尾，就能保证结果链始终非递减。整个过程只需要两个指针各走一遍。

由于结果链的头节点不是预先确定的，用一个 **dummy 哑节点** 当哨兵、用 `cur` 指向结果链末尾，可以避免「第一个节点要特殊处理」的麻烦，最后返回 `dummy.Next` 即可。

**算法步骤：**

1. `dummy := &ListNode{}`，`cur := dummy`。
2. 当两条链都非空时循环：比较两个头节点的值，把较小者接到 `cur.Next`，并让对应链的头指针前移；`cur` 也随之前移到新链尾。
3. 循环结束时至少一条链为空。把剩下那条非空链的**整段**直接接到 `cur.Next`（另一条为空时接 `nil`，代码里用一个 `if/else` 覆盖两种情况）。
4. 返回 `dummy.Next`。

**为什么正确：** 用循环不变量论证。**不变量：结果链已构造部分的最后一个元素 `x` 不大于两条输入链当前头部的值；并且已构造部分是非递减的。**

- 初始：已构造部分为空，不变量平凡成立。
- 归纳步：令 `x' = min(list1.Val, list2.Val)`。它是两条链当前头部的较小者，由不变量有 `x <= x'`，所以把 `x'` 接到末尾后已构造部分仍然非递减。摘下 `x'` 之后，该链的新头部不小于原来的头部（链表有序），另一个链的头部不变，因此新的「最后一个元素」`x'` 仍然不大于两个新头部的值，不变量保持。
- 终止：某条链走空后，另一条链的剩余部分是一个有序链，且它的头部不小于 `x`（不变量），把它整段接到末尾，整个结果链仍然非递减。遍历结束时所有节点都被摘用过一次，结果链长度恰好为 n + m，元素与原链一致。

因此输出是一个包含全部元素、保持非递减的链表，正是题目要求的升序合并结果。

### 复杂度分析

- **时间复杂度**：O(n + m)。每轮循环摘下一个节点，两个链表总共 n + m 个节点，每个节点只被访问一次。
- **空间复杂度**：O(1) 额外空间（不计结果链本身）。只用了 `dummy`、`cur` 和两个输入指针；结果链是通过重新串接原节点形成的，没有新建节点。

### 易错点 / 边界情况

- **要复用原节点，而不是新建节点**：题目要求「新链表是通过拼接给定的两个链表的所有节点组成的」，所以应该用 `cur.Next = list1` 这样的指针操作，而不是 `cur.Next = &ListNode{Val: list1.Val}`。新建节点的写法结果值也对，但多占用 O(n+m) 空间，不符合题意。
- **循环结束后要接上剩余的整段**：`cur.Next = list1`（或 `list2`）直接把剩下的所有节点一次接好，不要再用循环逐个搬运，也不要只写一个 `if` 而漏掉 `else` 分支。
- **空链表**：某一方为 `nil` 时，循环一次都不执行，最后把非空链整段接上即可，结果正确（示例 2、3）。代码不需要为空输入做特判。
- **比较用 `<=` 还是 `<`**：用 `<=` 时相等值会优先取 `list1` 的节点，结果更符合「保持稳定」的直觉；用 `<` 也完全正确，只是相等值时两链节点的相对次序会互换。本题不要求稳定性，两种写法都能通过。
- **别忘记前进指针**：摘下一个节点后，对应输入链的头指针和 `cur` 都要前移，否则会死循环。
- **不要在摘节点时破坏原链的结构**：`cur.Next = list1; list1 = list1.Next` 之后，原 `cur` 已经把该节点接管，不需要额外把它从输入链上断开（输入链本身就是靠头指针推进的）。
- **不要比较到头再判断**：把「两个都非空」作为循环条件，避免在循环内部反复判断 `nil`。

## Go 代码实现

```go
// ListNode 链表节点定义
type ListNode struct {
    Val  int
    Next *ListNode
}

func mergeTwoLists(list1 *ListNode, list2 *ListNode) *ListNode {
    // Dummy 节点简化边界处理
    dummy := &ListNode{}
    cur := dummy

    // 双指针遍历两个链表
    for list1 != nil && list2 != nil {
        if list1.Val <= list2.Val {
            cur.Next = list1
            list1 = list1.Next
        } else {
            cur.Next = list2
            list2 = list2.Next
        }
        cur = cur.Next
    }

    // 将剩余的节点直接连接（至多一个链表非空）
    if list1 != nil {
        cur.Next = list1
    } else {
        cur.Next = list2
    }

    return dummy.Next
}
```
