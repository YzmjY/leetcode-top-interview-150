# 135. Pow(x, n) (Pow(x, n))

## 题目描述

实现 `pow(x, n)`，即计算 `x` 的整数 `n` 次幂函数（即，`x^n`）。

**示例 1：**

```
输入：x = 2.00000, n = 10
输出：1024.00000
```

**示例 2：**

```
输入：x = 2.10000, n = 3
输出：9.26100
```

**示例 3：**

```
输入：x = 2.00000, n = -2
输出：0.25000
解释：2^(-2) = 1/(2^2) = 1/4 = 0.25
```

**约束条件：**

- `-100.0 < x < 100.0`
- `-2^31 <= n <= 2^31 - 1`
- `n` 是一个整数
- 要么 `x` 不为零，要么 `n > 0`
- `-10^4 <= x^n <= 10^4`

## 题目分析

### 算法思路

**朴素想法**：把 x 连乘 n 次，O(n)。n 可达 2^31，太慢。

**关键观察**：幂运算满足 `x^a · x^b = x^(a+b)`，可以把指数折半复用中间结果：先算出 `half = x^(n/2)`，则 `x^n = half * half`（n 为偶数）或 `half * half * x`（n 为奇数）。每层把指数减半，共 O(log n) 层。

**方法：快速幂（二分幂）**

- **递归写法**（代码中的 `fastPow`）：`n == 0` 返回 1（递归出口）；递归求出 `half = x^(n/2)`；n 为偶数返回 `half*half`，奇数再乘一个 x。
- **迭代写法**（`myPowIterative`）：利用指数的二进制展开 `n = Σ b_k·2^k`，于是 `x^n = Π (x^(2^k))`，只保留 `b_k = 1` 的项。代码维护底数 `x`（每轮自乘一次，依次变成 `x^2, x^4, ...`）和结果 `result`，从低位到高位扫描 `n` 的二进制：当前位为 1 就把当前的 x 乘进 result，然后把 n 右移一位。

**负指数**：`x^(-n) = 1 / x^n`。代码先判断 `n < 0`，把 `x` 换成 `1/x` 并把 `n` 取反，之后只需处理非负指数。

**为什么正确**：
- 递归写法对指数做数学归纳：n = 0 时 `x^0 = 1` 成立；假设对 ⌊n/2⌋ 成立，则偶数时 `half² = x^(n/2·2) = x^n`，奇数时 `half²·x = x^(n-1)·x = x^n`，成立。
- 迭代写法的循环不变量是「`result * x^n` 恒等于原始底数的原始指数次幂」（这里的 n 是剩余未处理的指数位）。每轮若最低位为 1，就把当前 `x`（恰为 `原始底数^(2^k)`）乘进 result；随后 `x` 平方、n 右移，不变量保持。循环结束时 n = 0，`result` 即答案。

### 复杂度分析

- **时间复杂度**：O(log n)。递归/迭代次数都是 n 的二进制位数，即 ⌈log₂(|n|+1)⌉。
- **空间复杂度**：递归写法 O(log n)（递归栈深度）；迭代写法 O(1)。

### 关键点

- 负指数要先把底数取倒数，再对指数取反。
- n 的取值含 `-2^31`：在 64 位平台上 Go 的 `int` 是 64 位，`-(-2^31) = 2^31` 不会溢出，所以 `n = -n` 是安全的；如果把这段代码移植到 `int` 为 32 位的平台，就需要先把 n 转成 `int64` 再取反。
- `n == 0` 时（包括 x = 0）返回 1，符合题目对 `x^0 = 1` 的约定。
- 递归深度约 31 层（|n| 最大 2^31），不会栈溢出。

## Go 代码实现

```go
package main

func myPow(x float64, n int) float64 {
    // 处理负指数
    if n < 0 {
        x = 1 / x
        n = -n
    }
    return fastPow(x, n)
}

// 递归快速幂
func fastPow(x float64, n int) float64 {
    if n == 0 {
        return 1.0
    }

    half := fastPow(x, n/2)

    if n%2 == 0 {
        return half * half
    }
    return half * half * x
}

// 迭代快速幂（备选方案）
func myPowIterative(x float64, n int) float64 {
    if n < 0 {
        x = 1 / x
        n = -n
    }

    result := 1.0
    for n > 0 {
        if n&1 == 1 { // n 的当前二进制位为 1
            result *= x
        }
        x *= x  // x = x^2
        n >>= 1 // n = n/2
    }
    return result
}
```
