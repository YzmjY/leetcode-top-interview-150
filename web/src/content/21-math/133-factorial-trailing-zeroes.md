# 133. 阶乘后的零 (Factorial Trailing Zeroes)

## 题目描述

给定一个整数 `n`，返回 `n!` 结果中尾随零的数量。

**提示：** n! = n * (n - 1) * (n - 2) * ... * 1

**示例 1：**

```
输入：n = 3
输出：0
解释：3! = 6，不含尾随 0。
```

**示例 2：**

```
输入：n = 5
输出：1
解释：5! = 120，有一个尾随 0。
```

**示例 3：**

```
输入：n = 0
输出：0
```

**约束条件：**

- `0 <= n <= 10^4`

**进阶：** 你能实现对数时间复杂度的解法吗？

## 题目分析

### 算法思路

**朴素想法**：先算出 n! 再数末尾 0。但 n 最大 10^4，n! 是一个几万位的巨大数字，即使用大整数也很浪费，题目「进阶」要求对数时间。

**核心洞察**：n! 的尾随零只能来自因子 10，而 10 = 2 × 5。把 n! 质因数分解后，每一对 (2, 5) 贡献一个尾随零。由于阶乘中偶数的个数远多于 5 的倍数，因子 2 的数量总是 ≥ 因子 5 的数量，所以尾随零的个数就等于 **n! 中因子 5 的个数**。

**如何数因子 5**：与其逐个分解 1..n，不如按「包含多少个 5」分层统计。某个数包含几个 5，就会被下面每一项各计一次：

- 5 的倍数有 ⌊n/5⌋ 个，每个至少贡献 1 个因子 5；
- 25 的倍数有 ⌊n/25⌋ 个，每个再多贡献 1 个；
- 125 的倍数有 ⌊n/125⌋ 个，每个再多贡献 1 个；
- ……

所以尾随零的数量 = `n/5 + n/25 + n/125 + ...`，直到除数大于 n。

**代码实现**：不必真的构造 5 的幂。循环里反复 `n /= 5` 再累加，等价于依次计算 ⌊n/5⌋、⌊n/25⌋、…：

```
count = 0
while n >= 5:
    n /= 5
    count += n
```

**举例：**

- n = 100：`100/5 = 20` 累加 20，`20/5 = 4` 累加 4，`4 < 5` 停止，得到 24
- n = 125：`125/5 = 25`、`25/5 = 5`、`5/5 = 1`，累加得到 `25 + 5 + 1 = 31`
- n = 5：`5/5 = 1`

**为什么正确**：对每个素数 p，n! 中 p 的指数是 ⌊n/p⌋ + ⌊n/p²⌋ + …（勒让德公式）。取 p = 5，又因为 2 的指数不小于 5 的指数，`min(指数₂, 指数₅) = 指数₅`，故尾随零数 = 指数₅。循环第 k 次迭代时 n 已是 ⌊n/5^(k-1)⌋，再除以 5 并累加正是 ⌊n/5^k⌋，所以累加和就是勒让德公式。

### 复杂度分析

- **时间复杂度**：O(log n)，每次迭代把 n 除以 5，迭代次数是以 5 为底的对数。
- **空间复杂度**：O(1)，只用了一个计数器。

### 关键点

- 尾随零只由因子 10 = 2 × 5 产生，而 5 比 2 稀缺，所以只数 5，不要数 2。
- 不要真的计算阶乘，n = 10^4 时 n! 会溢出任何定宽整数。
- 25、125、625 这些 5 的幂会被多层统计重复计入，这正是「每 25 个多一个」的来源；写成 `n/5 + n/25 + ...` 时容易漏掉高层。

## Go 代码实现

```go
package main

func trailingZeroes(n int) int {
    count := 0
    for n >= 5 {
        n /= 5
        count += n
    }
    return count
}
```
