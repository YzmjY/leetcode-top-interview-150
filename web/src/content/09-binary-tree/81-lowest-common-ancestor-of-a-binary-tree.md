# 81. 二叉树的最近公共祖先

## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为："对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。"

**示例 1：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3。
```

**示例 2：**

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5。因为根据定义，一个节点可以是它自己的祖先。
```

**示例 3：**

```
输入：root = [1,2], p = 1, q = 2
输出：1
```

**提示：**

- 树中节点数目在范围 `[2, 10^5]` 内。
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` **互不相同**。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

## 题目分析

### 算法思路

**核心思路**：LCA 有一个很好用的等价刻画——从当前节点往下看，如果 p、q 分别落在它的左、右两侧（或者它自己就是 p/q），那它就是把两者「分开」的那个分叉点，也就是 LCA；如果两者都在同一侧，就继续往那一侧找。于是可以自底向上递归：先问左右子树各自找到了什么，再根据两边的情况决定返回谁。

采用**后序遍历**递归。定义递归函数的返回值含义为：**「当前子树中 p、q 的最近公共祖先；如果该子树里只出现了其中一个，就返回那个节点；两个都没出现则返回 nil」**。

核心逻辑：
1. 如果当前节点为 nil，返回 nil。
2. 如果当前节点等于 p 或 q，直接返回当前节点（它可能是祖先，也可能是那一侧的唯一发现）。
3. 递归查找左右子树，得到 `left`、`right`。
4. 根据左右子树的返回值判断：
   - `left` 和 `right` 都非空 → p、q 分居两侧，当前节点就是最近公共祖先，返回当前节点。
   - 只有一侧非空 → p、q 都在这一侧（或只找到其中一个），返回该侧的结果。
   - 两侧都为空 → 返回 nil。

### 为什么正确

设 `f(u)` 表示对子树 `u` 的调用返回值，并采用上面的含义作为归纳命题。分类讨论：

- `u` 为空：没有目标节点，返回 nil，符合命题。
- `u == p`（`u == q` 同理，因 `p != q` 不会同时成立）：若 q 在 `u` 的子树中，则 `u` 是 q 的祖先，而任何比 `u` 更深的节点都不可能是 p 的祖先，所以 `u` 就是 LCA；若 q 不在 `u` 的子树中，则 `u` 子树只含一个目标节点，按含义应返回 `u`。两种情况都返回 `u`，正确。
- `u` 既不是 p 也不是 q：若 p、q 都在 `u` 中，则它们在 `u` 的左右子树中的分布只有三种：都在左、都在右、一边一个。前两种情况下，只有对应的一侧返回非空，另一侧为 nil，第 4 步返回非空的一侧，正是由归纳假设得到的该侧 LCA；第三种情况下两侧都非空，返回 `u`——此时 `u` 是 p、q 的公共祖先，而任何更深的节点都不可能同时是两者的祖先，故 `u` 是最近的。

题目保证 p、q 都存在于树中，因此根节点的答案必为二者的 LCA。

### 复杂度分析

- **时间复杂度**：O(n)，每个节点最多访问一次。
- **空间复杂度**：O(h)，递归栈深度，最坏 O(n)，平均 O(log n)。

### 易错点 / 边界情况

- 该算法依赖「p、q 都在树中」这一前提。若允许目标节点不存在，当只找到一个时返回的那个节点并不是真正的 LCA，需要额外判别。
- `root == p` 时直接返回，不再往下递归——这正是「节点可以是自己的祖先」的体现（示例 2：p=5、q=4，答案为 5）。
- 判定分支是「`left != nil && right != nil` 才返回 `root`」；只找到一侧时必须返回那一侧而不是 `root`。
- `p != q` 保证 `root == p || root == q` 不会同时命中同一个节点；若题目允许 p == q，应在入口先处理。
- 节点值范围 `[-10^9, 10^9]`，比较节点必须用**指针相等**（`root == p`）而不是比较值。
- 树深最坏可达 `10^5`，Go 的运行时栈会自动扩容，递归版本一般可行；对栈受限的语言需要改成迭代或先做父指针映射。
- 返回的节点指针可以直接通过 `.Val` 读取答案；题目要求返回节点本身而非值。

## Go 代码实现

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    // 递归终止条件：空节点或找到 p 或 q
    if root == nil || root == p || root == q {
        return root
    }

    // 递归查找左右子树
    left := lowestCommonAncestor(root.Left, p, q)
    right := lowestCommonAncestor(root.Right, p, q)

    // 左右子树分别找到 p 和 q，当前节点就是最近公共祖先
    if left != nil && right != nil {
        return root
    }

    // 只有一侧找到，返回该侧结果
    if left != nil {
        return left
    }
    return right
}
```
