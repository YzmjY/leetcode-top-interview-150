# 69. 相同的树

## 题目描述

给你两棵二叉树的根节点 `p` 和 `q`，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。

**示例 1：**

```
输入：p = [1,2,3], q = [1,2,3]
输出：true
```

**示例 2：**

```
输入：p = [1,2], q = [1,null,2]
输出：false
```

**示例 3：**

```
输入：p = [1,2,1], q = [1,1,2]
输出：false
```

**提示：**

- 两棵树上的节点数目都在范围 `[0, 100]` 内。
- `-10^4 <= Node.val <= 10^4`

## 题目分析

### 算法思路

**核心思路**：判断两棵树相同，等价于判断「根节点相同，并且左子树相同、右子树相同」——大问题被拆成两个结构相同的小问题。注意题目要求「结构相同**且**对应位置的值相同」，所以必须两棵树同时走，任何一处出现「一边有节点、另一边为空」就说明结构不同，可以立即返回 false。

采用递归（前序遍历）同时遍历两棵树，逐节点比较：

**算法步骤：**

1. **终止条件**：
   - 两个节点都为空，返回 true（走到同样的空位置，结构一致）。
   - 一个为空另一个不为空，返回 false（结构不同）。
2. **单层逻辑**：
   - 当前节点的值必须相等，否则返回 false。
   - 递归比较左子树和右子树，两者都相同才返回 true。

### 为什么正确

对两棵树的节点总数做归纳。基础情形由三个终止条件直接给出：都为空时两棵子树确实相同；一方为空时对应位置结构不同；值不等时显然不同。在值相等的前提下，两棵树相同当且仅当它们的左子树相同且右子树相同——因为一棵树的所有节点恰好由根、左子树、右子树三部分组成，对应关系只可能发生在同侧。由归纳假设，两个子调用分别正确判定左右子树，`&&` 的结果即整体判定。

### 复杂度分析

- **时间复杂度**：O(min(m, n))，其中 m、n 分别是两棵树的节点数。递归在任一方为空时终止，比较的节点对不超过较小树的节点数。
- **空间复杂度**：O(min(h1, h2))，递归栈的深度取决于较矮树的高度。

### 易错点 / 边界情况

- 只比较两棵树的节点值集合或某一种遍历会出错：示例 2 中两棵树的值都取自 `{1,2}`，但一个是「1 的左孩子是 2」、另一个是「1 的右孩子是 2」，结构并不相同。
- 「两个都为空返回 true」不能省略，否则无法判定叶子节点处的相同。
- `&&` 具有短路特性，左子树判定为 false 时不会访问右子树，这不是 bug，但若要统计访问节点数需注意。
- 两棵树都可能为空（节点数可以为 0），空树与空树应返回 true。
- 节点值可为负数，不要用 `-1` 之类的哨兵表示「空」。

## Go 代码实现

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func isSameTree(p *TreeNode, q *TreeNode) bool {
    // 两个都为空
    if p == nil && q == nil {
        return true
    }
    // 一个为空一个不为空
    if p == nil || q == nil {
        return false
    }
    // 值不相等
    if p.Val != q.Val {
        return false
    }
    // 递归比较左右子树
    return isSameTree(p.Left, q.Left) && isSameTree(p.Right, q.Right)
}
```
