# 70. 翻转二叉树

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

翻转二叉树是指将二叉树中每个节点的左右子节点进行交换。

**示例 1：**

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

**示例 2：**

```
输入：root = [2,1,3]
输出：[2,3,1]
```

**示例 3：**

```
输入：root = []
输出：[]
```

**提示：**

- 树中节点的数目在 `[0, 100]` 范围内。
- `-100 <= Node.val <= 100`

## 题目分析

### 算法思路

**核心思路**：翻转整棵树 = 交换根节点的左右子树，再分别翻转这两棵子树。因为「每个节点的左右孩子互换」这个要求对子树同样适用，问题自然递归。

采用递归（前序/后序遍历均可）完成翻转：

1. **终止条件**：当前节点为 nil，直接返回 nil。
2. **递归过程**（前序写法）：
   - 交换当前节点的左右子节点；
   - 递归翻转交换后的左、右子树；
   - 返回当前节点。

遍历顺序可以是前序（先交换再递归）或后序（先递归再交换），效果相同：交换操作只作用于当前这一层，递归只作用于下一层，两者互不干扰。

### 为什么正确

对树高做归纳。空树（nil）返回 nil 正确。对非空树，翻转后的树在每个节点上都要求左右孩子与原树相反。先交换根的两个孩子，此时根这一层已经满足要求；左、右位置上放的分别是原来的右子树和左子树，再由归纳假设，递归调用会把这两棵子树内部也完全翻转。子树内部翻转后，整棵树每个节点的左右孩子都与原树相反，即完成翻转。前序与后序的等价性在于：交换发生在其父节点层面，递归发生在子节点层面，交换的先后不影响最终每个节点的孩子关系。

### 复杂度分析

- **时间复杂度**：O(n)，每个节点被访问一次。
- **空间复杂度**：O(h)，递归栈深度，最坏 O(n)，平均 O(log n)。

### 易错点 / 边界情况

- 交换必须用 `root.Left, root.Right = root.Right, root.Left` 一次完成；若拆成 `root.Left = root.Right; root.Right = root.Left`，第二次读到的 `root.Left` 已经是刚写入的原右子树，结果两边都变成原右子树。
- 终止条件返回 nil，且空树调用应返回 nil。
- 前序写法要在交换**之后**递归，否则递归的是原左右子树（虽然对结果没有影响，但逻辑上要对齐「翻转子树」的含义）；不管哪种顺序，两棵子树都必须被递归到。
- 翻转是原地修改并返回根节点，不需要新建节点。

## Go 代码实现

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

// 前序遍历版本
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return nil
    }
    // 交换左右子节点
    root.Left, root.Right = root.Right, root.Left
    // 递归翻转子树
    invertTree(root.Left)
    invertTree(root.Right)
    return root
}
```
