# 56. 基本计算器

## 题目描述

给你一个字符串表达式 `s`，请你实现一个基本计算器来计算并返回它的值。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()`。

**示例 1：**

```
输入：s = "1 + 1"
输出：2
```

**示例 2：**

```
输入：s = " 2-1 + 2 "
输出：3
```

**示例 3：**

```
输入：s = "(1+(4+5+2)-3)+(6+8)"
输出：23
```

**约束条件：**

- `1 <= s.length <= 3 * 10^5`
- `s` 由数字、`'+'`、`'-'`、`'('`、`')'` 和 `' '` 组成
- `s` 表示一个有效的表达式
- `'+'` 不能用作一元运算（例如 `"+1"` 和 `"+(2 + 3)"` 无效）
- `'-'` 可以用作一元运算（例如 `"-1"` 和 `"-(2 + 3)"` 有效）
- 输入中不存在两个连续的运算符
- 每个数字和运行的计算都适合于一个有符号的 32 位整数

## 题目分析

### 算法思路

**核心思路：** 表达式中只有 `+`、`-`、`(`、`)`，没有 `*`、`/`，所以**不存在运算符优先级问题**，表达式天然可以从左到右累加计算。真正的难点只有两个：括号（子表达式要整体作为操作数参与运算）和一元负号（`-1`、`-(2+3)`）。

先想一元负号。把每个操作数前面的符号记为 `sign`（`+` 对应 `1`，`-` 对应 `-1`），那么「加一个操作数」这件事就统一成 `result += sign * 值`。这样一来，`2-1` 就是 `result += 1*2` 然后 `result += (-1)*1`；`-1` 就是初始 `sign = 1`，读到 `-` 后 `sign = -1`，最后 `result += (-1)*1`。**一元负号和二元减号被同一套机制处理，无需特判。**

再想括号。括号内的内容要「先算完，再作为整体乘以外面的符号」。这提示我们：遇到 `(` 时，把**括号外已经算出的结果**和**括号前的那个 `sign`** 保存起来（保存到栈里），然后清空现场、从零开始算括号内部；遇到 `)` 时，括号内部已经算完，把它乘上保存的 `sign` 再与保存的外层结果相加。每一层括号保存两个数，正好对应栈的「一层」。

**算法步骤：**

维护三个变量：`result`（当前括号层内已结算部分的值）、`num`（正在读取、尚未结算的数字）、`sign`（下一个操作数的符号），以及一个栈。遍历 `s` 的每个字符：

- **数字 `ch`**：`num = num*10 + int(ch-'0')`，逐位累积，支持多位数字。
- **`+`**：先结算 `result += sign * num`，然后 `num = 0`、`sign = 1`，准备读下一个操作数。
- **`-`**：先结算 `result += sign * num`，然后 `num = 0`、`sign = -1`。
- **`(`**：把当前层的 `result` 和 `sign` 依次压栈（先压 `result`、再压 `sign`），然后 `result = 0`、`sign = 1`，表示进入新的一层。
- **`)`**：先结算括号内最后一个数字 `result += sign * num`、`num = 0`；然后从栈顶弹出进入本层前保存的符号 `sign`，做 `result *= sign`；再弹出保存的外层结果，做 `result += 外层结果`。
- **空格**：不做任何事（`switch` 里没有对应分支，自然跳过）。

循环结束后，还要再执行一次 `result += sign * num`，把表达式末尾最后一个**没有被任何运算符结算过**的数字加上去，然后返回 `result`。

**为什么正确：** 用循环不变量论证。**不变量：处理到当前字符时，`result` 等于「当前括号层内、已经完整处理过的那部分表达式」的值，`sign` 是「紧接着要读取的那个操作数（数字或括号子表达式）的符号」，`num` 是「刚刚读完但还没结算的数字」。**

- 读到数字：只是延长 `num`，不改变已结算部分。
- 读到 `+`/`-`：该符号只作用于 `num` 和它后面的内容。把 `sign * num` 并入 `result` 相当于「结算完前一个操作数」，随后把 `sign` 换成新符号、`num` 清零，准备读下一个操作数，不变量保持。
- 读到 `(`：括号内的表达式即将开始，它的值会以「一个操作数」的身份乘上当前的 `sign`。因此把「外层已结算值」和「外层符号」保存在栈里，进入括号层后 `result = 0`、`sign = 1`，不变量在新的一层成立。
- 读到 `)`：此字符之前的字符恰好构成一个完整子表达式，先结算 `num` 得到括号内的完整值 `result`；把它乘上进入本层时的符号，等价于「这个操作数带着自己的符号参与外层运算」；再加上外层已结算的值，就回到了括号外的状态，不变量在上一层重新成立。

循环结束时最后一个数字尚未结算（它后面没有运算符来触发结算），补一次 `result += sign * num` 后，整个表达式恰好被完整求值，返回 `result` 正确。

### 复杂度分析

- **时间复杂度**：O(n)。每个字符只处理一次，栈操作都是 O(1)。
- **空间复杂度**：O(n)。栈的深度是括号嵌套层数，每层压入两个整数；最坏情况（如 `((((…1…))))`）深度为 n/2。

### 易错点 / 边界情况

- **`num` 要结算两次**：一是遇到 `)` 时先结算括号内最后一个数字，二是循环结束后结算整个表达式末尾的数字。漏掉任何一处都会少算。例如 `"(1)"` 若不结算就返回 0；`"1+1"` 若不结算末尾数字就返回 1。
- **弹栈顺序别弄反**：压栈顺序是「先 `result`、后 `sign`」，所以弹栈必须先弹 `sign`、再弹 `result`。代码里 `result *= stack[len(stack)-1]` 之后 `result += stack[len(stack)-1]`，两次都用栈顶、每次都 pop 一个，顺序上正好是先符号后结果。写成合成一个循环或先弹结果就会算错。
- **空格要忽略，但不要用它来分隔数字**：让 `switch` 的所有分支都不命中即可自然跳过。注意不要写成「遇到空格就结算 `num`」——空格只是排版，题面中的数字不会在中途被空格隔开，用空格触发结算属于多余的逻辑。
- **多位数字要逐位累积**：`num = num*10 + ...`，不能只取一位。
- **一元负号的两种情形**：表达式开头的 `-1`（此时 `sign` 是初值 1，被 `-` 翻转成 -1）和括号后的 `-(2+3)`（`sign` 在 `(` 处被压栈保存，括号内重新从 1 开始，`)` 时整体乘 -1）。两者都靠「累积符号」自然处理，不需要额外的特判分支。
- **`+` 不能作为一元运算符**：题面明确禁止 `"+1"`、`"+(2+3)"` 这类写法，所以不必为「开头是 `+`」做特殊处理；但即便真的出现，本算法也会按 `0 + 1` 处理，同样得到正确结果。
- **溢出**：题面保证每个数字与每一步计算都适合 32 位有符号整数。Go 在 64 位平台上 `int` 是 64 位，比要求更宽，因此不会溢出。
- **不要用 `eval` 之类的内置解析**：题目禁止使用把字符串当表达式求值的内置函数；本解法是真正逐字符解析。
- **约束中的「不存在两个连续运算符」** 保证了不会出现 `1--2` 这类歧义写法，因此每读到一个 `-` 都可以直接把它当作下一个操作数的符号。

## Go 代码实现

```go
func calculate(s string) int {
    stack := []int{} // 存储括号外的结果和符号
    result := 0      // 当前计算结果
    num := 0         // 当前解析的数字
    sign := 1        // 当前符号：1 表示正，-1 表示负

    for i := 0; i < len(s); i++ {
        ch := s[i]

        switch {
        case ch >= '0' && ch <= '9':
            // 累积数字
            num = num*10 + int(ch-'0')

        case ch == '+':
            // 完成前一个数字的处理
            result += sign * num
            num = 0
            sign = 1

        case ch == '-':
            // 完成前一个数字的处理
            result += sign * num
            num = 0
            sign = -1

        case ch == '(':
            // 将当前状态压入栈，开始新的子表达式
            stack = append(stack, result) // 保存括号外的结果
            stack = append(stack, sign)   // 保存括号外的符号
            result = 0
            sign = 1

        case ch == ')':
            // 完成括号内最后一个数字的处理
            result += sign * num
            num = 0
            // 弹出括号外的符号，乘以括号内的结果
            result *= stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            // 弹出括号外的结果，加到当前结果
            result += stack[len(stack)-1]
            stack = stack[:len(stack)-1]
        }
    }

    // 处理最后一个数字
    result += sign * num

    return result
}
```
