# 142. 三角形最小路径和 (Triangle)

## 题目描述

给定一个三角形 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。相邻的结点在这里指的是 **下标** 与上一层结点下标相同或者等于上一层结点下标 +1 的两个结点。也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i` 或 `i + 1`。

**示例 1：**

```
输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
解释：如下面简图所示：
   2
  3 4
 6 5 7
4 1 8 3
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。
```

**示例 2：**

```
输入：triangle = [[-10]]
输出：-10
```

**约束条件：**

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i-1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

**进阶：** 你可以只使用 O(n) 的额外空间（n 为三角形的总行数）来解决这个问题吗？

## 题目分析

### 算法思路

**关键观察：为什么要反过来算。** 一道「从顶点走到最底层」的题，直觉做法是从上往下走，但同一层的
`(i, j)` 可能被多条路径经过，站在某个位置时「已经走过的代价」是随路径变化的，无法只用一个数描述。
反过来想：**从 `(i, j)` 出发走到最底层的最优代价，只由 `(i, j)` 的位置决定，与怎么来到这个位置无关** ——
这就是 DP 要求的无后效性。因此把「以 `(i, j)` 为起点往下走」当作子问题，自底向上递推。

**方法一：自底向上 DP（推荐）**

- **状态定义**：`dp[i][j]` = 从位置 `(i, j)` 出发、一直走到最底层的最小路径和（包含 `triangle[i][j]` 本身）。
- **边界**：最后一行没有「下一行」，所以 `dp[n-1][j] = triangle[n-1][j]`。
- **状态转移**：从 `(i, j)` 出发的第一步只能到下一行的 `(i+1, j)` 或 `(i+1, j+1)`；这两个子问题的答案
  已经算好，取较小者，再加上当前格必付的值：
  `dp[i][j] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`
- **答案**：`dp[0][0]`（从顶点出发的最优值）。

**为什么正确（对行号归纳）。** 归纳假设：第 `i+1` 行的每个 `dp[i+1][j]` 都已经是「从该点到底层的最小路径和」。

1. 归纳基础：最后一行不存在「往下走」的选择，其最小路径和就是格子自身，成立。
2. 归纳步骤：从 `(i, j)` 出发的任意一条路径，第一步只有两种可能，分别落在 `(i+1, j)` 和 `(i+1, j+1)`；
   第一步之后是以对应格子为起点的子问题，由归纳假设其最优代价为 `dp[i+1][j]`、`dp[i+1][j+1]`。
   因此 `(i, j)` 的最小值就是 `triangle[i][j]` 加上两者的较小值（这也是最优子结构：
   整体最优路径的第一步，必然落在两条子问题最优解之一上）。

归纳成立，`dp[0][0]` 就是从顶点到底层的最小路径和。

**方法二：自顶向下 DP（对照理解）**

把状态改成 `dp[i][j]` = 从顶点走到 `(i, j)` 的最小路径和：

- `dp[0][0] = triangle[0][0]`；
- `dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])`，第一列没有左上方、每行最后一个没有正上方，
  需要单独判断；
- 答案取最后一行的最小值（因为不知道最优路径停在底层哪个位置）。

两者都可行，但自顶向下要多写一层「越界判断」，且答案还需要再扫一次最后一行，所以实现上更推荐自底向上。

**空间优化（一维滚动数组）**

计算第 `i` 行只用到第 `i+1` 行，所以可以让**同一个一维数组**先后扮演「下一行」和「当前行」：

```
dp[j] = triangle[i][j] + min(dp[j], dp[j+1])   // j 从 0 到 i
```

关键在覆盖顺序：进入第 `i` 行时，`dp[j]` 存的是 `dp[i+1][j]`、`dp[j+1]` 存的是 `dp[i+1][j+1]`，
正是转移需要的两个旧值；内层 `j` **从左到右**更新，写 `dp[j]` 时只用到尚未被修改的 `dp[j+1]`，
所以可以安全地原地覆盖。遍历完第 `i` 行后，数组前 `i+1` 个元素就变成了第 `i` 行的 dp 值。

### 复杂度分析

- **时间复杂度**：O(n²)。第 `i` 行有 `i+1` 个元素，总转移次数约为 `n²/2`，每次转移 O(1)。
- **空间复杂度**：O(n)（一维滚动数组）；若保留完整二维表则是 O(n²)。
  n ≤ 200 时两者都远未触及限制。

### 关键点

- 自底向上不需要判断「某一侧越界」，代码更短、更不容易写错；这是本题推荐它的主要原因。
- 一维滚动时内层循环方向是 `j` 从小到大：`dp[j+1]` 必须在被覆盖前使用。
- 数值范围：每层元素绝对值 ≤ 10⁴、最多 200 层，路径和的绝对值 ≤ 2×10⁶，`int` 完全够用。
- 边界：约束保证 `triangle.length >= 1`，代码里的 `n == 0` 只是防御性分支，实际不会触发。
- 三角形是「参差」的（第 `i` 行只有 `i+1` 个元素），一维数组长度为 `n` 而最后一行的元素数也是 `n`，
  正好够用；内层循环上界应写 `len(triangle[i])`，不要写成 `n`。

## Go 代码实现

```go
package main

func minimumTotal(triangle [][]int) int {
    n := len(triangle)
    if n == 0 {
        return 0
    }

    // dp 初始化为最后一行的值
    dp := make([]int, n)
    copy(dp, triangle[n-1])

    // 自底向上
    for i := n - 2; i >= 0; i-- {
        for j := 0; j < len(triangle[i]); j++ {
            dp[j] = triangle[i][j] + min(dp[j], dp[j+1])
        }
    }

    return dp[0]
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```
