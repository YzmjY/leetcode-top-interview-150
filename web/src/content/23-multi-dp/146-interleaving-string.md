# 146. 交错字符串 (Interleaving String)

## 题目描述

给定三个字符串 `s1`、`s2`、`s3`，请你帮忙验证 `s3` 是否是由 `s1` 和 `s2` **交错** 组成的。

两个字符串 `s` 和 `t` **交错** 的定义与过程如下，其中每个字符串会被分割成若干 **非空** 子字符串：

- `s = s1 + s2 + ... + sn`
- `t = t1 + t2 + ... + tm`
- `|n - m| <= 1`
- 交错 是 `s1 + t1 + s2 + t2 + s3 + t3 + ...` 或者 `t1 + s1 + t2 + s2 + t3 + s3 + ...`

**注意：** a + b 意味着字符串 a 和 b 连接。

**示例 1：**

```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出：true
```

**示例 2：**

```
输入：s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出：false
```

**示例 3：**

```
输入：s1 = "", s2 = "", s3 = ""
输出：true
```

**约束条件：**

- `0 <= s1.length, s2.length <= 100`
- `0 <= s3.length <= 200`
- `s1`、`s2` 和 `s3` 都由小写英文字母组成

**进阶：** 您能否仅使用 O(s2.length) 额外的内存空间来解决它？

## 题目分析

### 算法思路

**关键观察 1：把绕口的定义翻译成人话。** 题面用「把 s 和 t 各切成若干非空子串，再交替拼接」来定义交错。
但每次取一段时，段内部保持原序、段的先后也保持原序，所以合并结果中 **s1 的字符之间、s2 的字符之间
都保持原来的相对顺序**；反过来，任意满足「两串各自保序」的合并方式，都能按取段划分为交替形式。
因此题目等价于：**能否把 s1、s2 当作两个队列，按各自顺序取出字符合并成 s3。**

**关键观察 2：为什么状态只需要两个下标。** 决定「接下来能用哪些字符」的只有两件事：s1 用掉了前几个、
s2 用掉了前几个。而已经拼出的长度必然是两者之和，所以状态 `(i, j)` 足以完全描述当前局面，
不需要记录具体的拼接顺序（无后效性）。

- **状态定义**：`dp[i][j]` = 用 s1 的前 `i` 个字符与 s2 的前 `j` 个字符，能否交错组成 s3 的前 `i+j` 个字符。
- **状态转移**：`s3` 的第 `i+j` 个字符（下标 `i+j-1`）只能来自两处：
  - 来自 s1：需要 `s1[i-1] == s3[i+j-1]` 且 `dp[i-1][j]` 为真；
  - 来自 s2：需要 `s2[j-1] == s3[i+j-1]` 且 `dp[i][j-1]` 为真。

  满足其一即可：

  ```
  dp[i][j] = (s1[i-1] == s3[i+j-1] && dp[i-1][j]) ||
             (s2[j-1] == s3[i+j-1] && dp[i][j-1])
  ```
- **边界条件**：`dp[0][0] = true`（空串与空串交错得到空串）；
  `dp[i][0] = dp[i-1][0] && s1[i-1] == s3[i-1]`（只用 s1，逐字符比对）；
  `dp[0][j] = dp[0][j-1] && s2[j-1] == s3[j-1]`（只用 s2）。
- **答案**：`dp[m][n]`，其中 `m = len(s1)`、`n = len(s2)`。若 `m + n != len(s3)`，直接返回 `false`。

**为什么正确（对 `i+j` 归纳）。** 考虑拼出 `s3` 前 `i+j` 个字符的方案，看最后一个字符 `s3[i+j-1]` 来自哪里。
由于字符只可能由 s1 或 s2 提供，且每串内部按顺序取用，取到 s1 的第 `i` 个字符意味着 s1 的前 `i-1` 个
已经被使用，所以方案必然落入两类之一：最后一步取 s1 的第 `i` 个字符，或取 s2 的第 `j` 个字符。
前一情况下，去掉这个字符后的前缀必须由 s1 前 `i-1` 个与 s2 前 `j` 个交错拼成，即要求 `dp[i-1][j]`；
后一情况下要求 `dp[i][j-1]`。两类穷尽了所有可能，因此 `||` 的转移式既不遗漏也不重复。
边界情况（某串为空）由递推式自然覆盖，归纳可得 `dp[m][n]` 即为答案。

**空间优化（一维滚动数组，代码实现）。** 第 `i` 行只依赖第 `i-1` 行和本行左边一格，因此可以只用一个长度 `n+1` 的数组：

- 进入第 `i` 行时 `dp[j]` 还是 `dp[i-1][j]`，而 `dp[j-1]` 已被本行更新为 `dp[i][j-1]`；
- `i == 0 && j == 0`：`dp[0] = true`；
- `i == 0, j > 0`：`dp[j] = dp[j-1] && s2[j-1] == s3[j-1]`（只靠 s2，从左往右传递）；
- `j == 0, i > 0`：`dp[0] = dp[0] && s1[i-1] == s3[i-1]`（只靠 s1，沿用上一行的旧值）；
- 其余：`dp[j] = (dp[j] && s1[i-1] == s3[i+j-1]) || (dp[j-1] && s2[j-1] == s3[i+j-1])`。

### 复杂度分析

- **时间复杂度**：O(m·n)，共 `(m+1)(n+1)` 个状态，每个状态 O(1) 次比较。m, n ≤ 100 时最多约 10⁴ 个状态。
- **空间复杂度**：O(n)，一维滚动数组（n 取较短串的长度可实现 O(min(m, n))）；完整二维表为 O(m·n)。

### 关键点

- 先做长度判定 `len(s1)+len(s2) == len(s3)`，长度不符时直接返回 `false`，可提前挡掉大量用例。
- 「交错」的实质是**保序合并**，理解这一点后转移式就非常自然：最后一个字符要么来自 s1、要么来自 s2。
- `s1[i-1]` 与 `s2[j-1]` 可能相同，此时两个分支都要尝试（用 `||` 连接）；只贪心地匹配其中一串会漏解。
- 一维滚动时 `dp[j]` 是上一行的旧值、`dp[j-1]` 是本行的新值，顺序写反会得到错误结果。
- 边界：s1 或 s2 为空时退化为「另一个串是否等于 s3 的前缀」；三个都为空返回 `true`。
- 该算法与「编辑距离」「最长公共子序列」同属双序列 DP，都是 `(i, j)` 表示两串前缀的状态。

## Go 代码实现

```go
package main

func isInterleave(s1 string, s2 string, s3 string) bool {
    m, n, t := len(s1), len(s2), len(s3)

    // 长度必须匹配
    if m+n != t {
        return false
    }

    // dp[j] 表示 s1 的前 i 个字符与 s2 的前 j 个字符能否组成 s3 的前 i+j 个字符
    dp := make([]bool, n+1)

    for i := 0; i <= m; i++ {
        for j := 0; j <= n; j++ {
            if i == 0 && j == 0 {
                dp[j] = true
            } else if i == 0 {
                // 只用 s2 匹配
                dp[j] = dp[j-1] && s2[j-1] == s3[j-1]
            } else if j == 0 {
                // 只用 s1 匹配
                dp[j] = dp[j] && s1[i-1] == s3[i-1]
            } else {
                dp[j] = (dp[j] && s1[i-1] == s3[i+j-1]) ||
                        (dp[j-1] && s2[j-1] == s3[i+j-1])
            }
        }
    }

    return dp[n]
}
```
