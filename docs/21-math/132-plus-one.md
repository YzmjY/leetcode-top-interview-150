# 132. 加一 (Plus One)

## 题目描述

给定一个由 **整数** 组成的 **非空** 数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储单个数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

**示例 1：**

```
输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123。
```

**示例 2：**

```
输入：digits = [4,3,2,1]
输出：[4,3,2,2]
解释：输入数组表示数字 4321。
```

**示例 3：**

```
输入：digits = [9]
输出：[1,0]
解释：输入数组表示数字 9。加 1 得到 10。
```

**约束条件：**

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` 不包含任何前导 0，除了数字 0 本身。

## 题目分析

### 算法思路

**方法：从末尾开始模拟加法**

从数组的最后一位开始逐位加一，处理进位：

1. 从末位开始遍历，如果当前位加一后小于 10，直接加一并返回。
2. 如果当前位加一后等于 10，将当前位设为 0，进位继续传递到下一位。
3. 如果遍历完所有位后仍有进位（即原数字全是 9），需要创建一个新数组，首位为 1，其余位为 0。

例如：`[9,9,9]` -> `[1,0,0,0]`

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是数组长度。最坏情况下需要遍历所有位。
- **空间复杂度**：O(1)。除了可能的输出数组外，不需要额外空间。当全是 9 时需要创建新数组，但这是输出所需。

### 关键点

- 从后往前遍历，找到第一个不为 9 的位置。
- 全 9 的情况需要扩展数组。

## Go 代码实现

```go
package main

func plusOne(digits []int) []int {
    n := len(digits)

    // 从末位开始遍历
    for i := n - 1; i >= 0; i-- {
        if digits[i] < 9 {
            digits[i]++
            return digits
        }
        // digits[i] == 9，置为0，进位继续
        digits[i] = 0
    }

    // 能走到这里说明所有位都是9，需要扩展数组
    result := make([]int, n+1)
    result[0] = 1
    return result
}
```
