# 132. 加一 (Plus One)

## 题目描述

给定一个由 **整数** 组成的 **非空** 数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储单个数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

**示例 1：**

```
输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123。
```

**示例 2：**

```
输入：digits = [4,3,2,1]
输出：[4,3,2,2]
解释：输入数组表示数字 4321。
```

**示例 3：**

```
输入：digits = [9]
输出：[1,0]
解释：输入数组表示数字 9。加 1 得到 10。
```

**约束条件：**

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` 不包含任何前导 0，除了数字 0 本身。

## 题目分析

### 算法思路

**方法：从末尾开始模拟加法**

**朴素想法**：把数组当成十进制数还原成整数再加一。但数组长度可达 100，远超任何定宽整数的表示范围，不可行；正确做法是像手算竖式一样从最低位（数组末尾）开始模拟进位。

**算法步骤**：

1. 令 `i` 从 `n-1` 递减到 0：
   - 若 `digits[i] < 9`，说明这一位加一后不会进位，直接 `digits[i]++` 并返回 `digits`（更高位完全不变）；
   - 若 `digits[i] == 9`，加一后变成 10，本位留下 0、进位传给下一位：`digits[i] = 0`，继续循环。
2. 如果循环跑完仍没有返回，说明每一位都是 9、每一位都被置成了 0，且还有一次进位溢出到最高位之外。此时答案比原数多一位：新建长度 `n+1` 的数组，`result[0] = 1`，其余默认为 0，返回它。

举例：`[1,9,9]` → 末位 9 置 0，中间 9 置 0，首位 1 加一得 2 → `[2,0,0]`；`[9,9,9]` → 全部置 0，最后补一个前导 1 → `[1,0,0,0]`。

**为什么正确**：十进制加一的结果由「从最低位开始，连续的一段 9 全部进位变成 0，第一个小于 9 的位加一，更高位不变」唯一确定。循环恰好从最低位开始找这一段连续的 9：遇到第一个 `< 9` 的位就加一并返回，此时比它低的位已经全部变成 0，正是正确的进位结果；若找不到，则所有位都是 9，正确结果就是 1 后面跟 n 个 0。两种出口覆盖了所有情况。

### 复杂度分析

- **时间复杂度**：O(n)，其中 n 是数组长度。最坏情况（全 9）遍历整个数组，最好情况只访问末位；这里按最坏计为 O(n)。
- **空间复杂度**：O(1) 额外空间（返回的数组不计入额外空间）。一般情况原地修改并返回入参数组；只有全 9 时才新建一个长度 n+1 的输出数组。

### 关键点

- 从后往前遍历，一旦某一位 `< 9` 就立刻返回，不必再处理更高位。
- 全 9 是唯一需要扩展数组长度的边界，容易漏掉。
- 代码会**原地修改**传入的 `digits`（全 9 时除外），如果调用方还需要原数组，应先自行拷贝。

## Go 代码实现

```go
package main

func plusOne(digits []int) []int {
    n := len(digits)

    // 从末位开始遍历
    for i := n - 1; i >= 0; i-- {
        if digits[i] < 9 {
            digits[i]++
            return digits
        }
        // digits[i] == 9，置为0，进位继续
        digits[i] = 0
    }

    // 能走到这里说明所有位都是9，需要扩展数组
    result := make([]int, n+1)
    result[0] = 1
    return result
}
```
