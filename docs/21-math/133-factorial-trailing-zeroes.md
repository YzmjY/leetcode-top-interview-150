# 133. 阶乘后的零 (Factorial Trailing Zeroes)

## 题目描述

给定一个整数 `n`，返回 `n!` 结果中尾随零的数量。

**提示：** n! = n * (n - 1) * (n - 2) * ... * 1

**示例 1：**

```
输入：n = 3
输出：0
解释：3! = 6，不含尾随 0。
```

**示例 2：**

```
输入：n = 5
输出：1
解释：5! = 120，有一个尾随 0。
```

**示例 3：**

```
输入：n = 0
输出：0
```

**约束条件：**

- `0 <= n <= 10^4`

**进阶：** 你能实现对数时间复杂度的解法吗？

## 题目分析

### 算法思路

**核心洞察**：尾随零由因子 10 产生，而 10 = 2 x 5。在 n! 的质因数分解中，2 的数量总是多于 5 的数量，因此尾随零的数量等于 n! 中因子 5 的个数。

**计算因子 5 的个数：**

对于 n!，每 5 个数出现一个 5，每 25 个数多一个额外的 5（因为 25 = 5^2），每 125 个数再多一个（因为 125 = 5^3），以此类推。

因此，尾随零的数量 = `n/5 + n/25 + n/125 + ...`，直到除数大于 n。

**举例：**

- n = 100：`100/5 + 100/25 = 20 + 4 = 24`
- n = 5：`5/5 = 1`

### 复杂度分析

- **时间复杂度**：O(log n)，每次迭代除数乘以 5。
- **空间复杂度**：O(1)。

### 关键点

- 本质是数论问题：统计因子 5 的个数。
- 不需要真正计算阶乘（会溢出）。

## Go 代码实现

```go
package main

func trailingZeroes(n int) int {
    count := 0
    for n >= 5 {
        n /= 5
        count += n
    }
    return count
}
```
