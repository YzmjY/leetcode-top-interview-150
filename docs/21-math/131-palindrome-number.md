# 131. 回文数 (Palindrome Number)

## 题目描述

给你一个整数 `x`，如果 `x` 是一个回文整数，返回 `true`；否则，返回 `false`。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

**示例 1：**

```
输入：x = 121
输出：true
```

**示例 2：**

```
输入：x = -121
输出：false
解释：从左向右读, 为 -121 。 从右向左读, 为 121- 。因此它不是一个回文数。
```

**示例 3：**

```
输入：x = 10
输出：false
解释：从右向左读, 为 01 。因此它不是一个回文数。
```

**约束条件：**

- `-2^31 <= x <= 2^31 - 1`

**进阶：** 你能不将整数转为字符串来解决这个问题吗？

## 题目分析

### 算法思路

**朴素想法**：把整数转成字符串，判断字符串是否回文。这需要 O(log n) 的额外空间，也被题目「进阶」所禁止。

**方法一：反转一半数字**

回文数的核心特征是以中点为中心前后对称：如果反转整个数字后与原数相等，它就是回文数。但反转整个数字有两个问题：一是可能溢出（32 位平台上反转 `2147483647` 会溢出），二是做了多余的工作。关键观察是：只要反转**后一半**数字，再与**前一半**比较就够了。

设 `x` 保存还没处理的高位部分，`reversed` 保存已经反转的低位部分，循环做的事就是「弹出 `x` 的最低位，追加到 `reversed` 末尾」：

1. 负数直接返回 `false`（负号只出现在最左边，不可能对称）；末尾为 0 的非零数直接返回 `false`（最高位不可能是 0，所以形如 `10`、`100` 一定不对称）。注意 `0` 本身是回文数，因此判断末尾 0 时必须加上 `x != 0`。
2. 循环条件写成 `x > reversed`，含义是「已反转的部分还没有超过剩下的部分」，也就是「还没处理到一半」。它保证循环结束时 `reversed` 的位数恰好覆盖了原数的后一半。
3. 循环退出后分两种情况：
   - 原数有偶数位：`x` 是前半段，`reversed` 是后半段的逆序，回文等价于 `x == reversed`；
   - 原数有奇数位：`reversed` 比 `x` 多一位（中间那位被反转进来了），去掉它再比较，即 `x == reversed / 10`。

**算法步骤**（对应代码）：
1. 若 `x < 0 || (x%10 == 0 && x != 0)`，返回 `false`；
2. `reversed = 0`；
3. 当 `x > reversed` 时：`reversed = reversed*10 + x%10; x /= 10`；
4. 返回 `x == reversed || x == reversed/10`。

**为什么正确**：把原数记为 N。每次迭代从 `x` 拿走最低位并把它变成 `reversed` 的最高位，因此任意时刻都有「`reversed` 恰好是 N 的低若干位的逆序」。循环在 `x <= reversed` 时停下，此时 `reversed` 的位数要么等于 `x` 的位数（N 为偶数位），要么比 `x` 多一位（N 为奇数位）。偶数位时，N 回文当且仅当前半段等于后半段的逆序，即 `x == reversed`；奇数位时，去掉中间位后同理。两种情况都被覆盖，所以判断是充要的。

### 复杂度分析

- **时间复杂度**：O(log n)，其中 n 是输入整数。每次迭代把 `x` 除以 10，循环次数是十进制位数的一半。
- **空间复杂度**：O(1)，只使用 `x`、`reversed` 两个变量。

### 关键点

- 只需要反转一半，天然避免了大数反转导致的溢出（反转整个数字时，32 位平台上 `2147483647` 会溢出）。
- `0` 是回文数，末尾 0 的判断必须写成 `x%10 == 0 && x != 0`，漏掉 `x != 0` 会把 0 误判为非回文。
- 奇数位与偶数位的比较方式不同，奇数位要先用 `reversed/10` 去掉中间的数字。

## Go 代码实现

```go
package main

func isPalindrome(x int) bool {
    // 负数和以0结尾的非0数不是回文数
    if x < 0 || (x%10 == 0 && x != 0) {
        return false
    }

    reversed := 0
    for x > reversed {
        reversed = reversed*10 + x%10
        x /= 10
    }

    // 偶数位: x == reversed
    // 奇数位: x == reversed/10 (去掉中间的数字)
    return x == reversed || x == reversed/10
}
```
