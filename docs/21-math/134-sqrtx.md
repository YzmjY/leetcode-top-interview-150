# 134. x 的平方根 (Sqrt(x))

## 题目描述

给你一个非负整数 `x`，计算并返回 `x` 的 **算术平方根**。

由于返回类型是整数，结果只保留 **整数部分**，小数部分将被舍去。

**注意：** 不允许使用任何内置指数函数和算符，例如 `pow(x, 0.5)` 或者 `x ** 0.5`。

**示例 1：**

```
输入：x = 4
输出：2
```

**示例 2：**

```
输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。
```

**约束条件：**

- `0 <= x <= 2^31 - 1`

## 题目分析

### 算法思路

**朴素想法**：从 0 开始逐个尝试 k，直到 k² > x，答案就是 k-1。这是 O(√x)，x 可达 2^31，太慢。

**关键观察**：函数 f(k) = k² 在非负整数上单调递增，而我们要找的是满足 k² ≤ x 的最大 k，即「最后一个满足条件的值」。这类「单调条件下的边界查找」正是二分查找的用武之地。

**方法一：二分查找**

- 先缩小范围：x = 0 或 1 时答案就是 x 本身，直接返回，顺便避开 x < 2 时 `x/2 = 0` 的退化区间；x ≥ 2 时答案落在 `[2, x/2]` 内（对 x ≥ 4 有 `(x/2)² ≥ x`，x = 2、3 时区间为空，循环不进入、返回 right = 1 仍然正确）。
- 循环维持不变量：答案一定在闭区间 `[left, right]` 内。
  - `mid * mid == x`：恰好找到精确平方根，直接返回 `mid`；
  - `mid * mid < x`：`mid` 及其左侧都不可能是答案，`left = mid + 1`；
  - `mid * mid > x`：`mid` 及其右侧都不满足，`right = mid - 1`。
- 循环结束时 `left = right + 1`，所有候选都已被排除，`right` 就是「最后一个满足 `k² ≤ x` 的 k」。

**为什么正确**：每次迭代都保持「答案在 `[left, right]` 内」，且区间严格收缩（`mid` 被排除，left 或 right 至少移动一位），所以循环必然终止。终止时区间为空，答案落在 right 上，因此返回 `right` 正确。

**方法二：牛顿迭代法（进阶）**

把求平方根看作解方程 `f(y) = y² - x = 0`，牛顿迭代公式为 `y_{n+1} = y_n - f(y_n)/f'(y_n) = (y_n + x/y_n) / 2`。从 `y = x` 出发迭代，序列单调下降并快速收敛到 √x；当 `y*y <= x` 时 `y` 就是向下取整的结果。收敛是二次的，迭代次数约为 O(log log x)，比二分更快，但要额外处理浮点误差与溢出。

（下面的代码实现采用方法一。）

### 复杂度分析

- **时间复杂度**：O(log x)，二分查找每次把区间长度减半。
- **空间复杂度**：O(1)。

### 关键点

- **溢出问题**：本节代码直接比较 `mid * mid`。由于 x ≤ 2^31 - 1 且 Go 在 64 位平台上 `int` 为 64 位，`mid ≤ x/2 < 2^30`，`mid * mid < 2^60`，不会溢出。若把同样的写法移植到 `int` 为 32 位的平台，或把数据范围放大，就应改用除法 `mid > x / mid`（注意除法做除数时 x 不能为 0，代码已提前返回）。
- 边界条件：x = 0 返回 0，x = 1 返回 1，x = 2、3 都应返回 1。
- 二分结束时返回 `right` 而不是 `left`：`right` 才是最后一个满足 `k² ≤ x` 的下标。

## Go 代码实现

```go
package main

func mySqrt(x int) int {
    if x < 2 {
        return x
    }

    left, right := 2, x/2
    var mid int

    for left <= right {
        mid = left + (right-left)/2
        square := mid * mid

        if square == x {
            return mid
        } else if square < x {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }

    // 循环结束时 right < left，right 就是向下取整的平方根
    return right
}
```
