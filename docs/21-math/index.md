# 第21章 数学 (Math)

## 章节概述

数学类题目是 LeetCode 面试中的常见题型，主要考察候选人对基本数学原理的理解和灵活运用能力。这类题目通常不依赖复杂的数据结构（如树、图），而是侧重于数学思维和算法设计。

## 常见数学题型

### 1. 数论 (Number Theory)
- **回文数判断**：通过反转数字或逐位比较来判断一个整数是否为回文数。
- **阶乘后的零**：统计 n! 末尾零的个数，本质是统计因子 5 的个数。
- **大数运算**：处理加法、乘法等运算时可能出现的溢出问题。

### 2. 数值计算
- **平方根计算**：使用二分查找或牛顿迭代法求解平方根。
- **快速幂**：使用二分思想实现 O(log n) 时间复杂度的幂运算 (Pow(x, n))。
- **加一操作**：模拟数组形式的整数加法，处理进位。

### 3. 几何 (Geometry)
- **直线上最多的点数**：利用斜率和哈希表统计共线点数，需要考虑精度问题和重复点。

## 核心技巧

1. **二分查找**：在数值计算中广泛使用（如平方根、快速幂）。
2. **数学归纳**：从数学角度推导规律，减少不必要的计算。
3. **哈希表**：用于记录中间结果（如斜率统计）。
4. **溢出处理**：使用更大的数据类型或提前判断来避免整数溢出。

## 复杂度速查

- 回文数：时间 O(log n)，空间 O(1)
- 加一：时间 O(n)，空间 O(1)
- 阶乘后的零：时间 O(log n)，空间 O(1)
- x 的平方根：时间 O(log x)，空间 O(1)
- Pow(x, n)：时间 O(log n)，空间 O(log n)（递归栈）
- 直线上最多的点数：时间 O(n^2)，空间 O(n)
