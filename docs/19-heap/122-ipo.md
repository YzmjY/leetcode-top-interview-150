# 122. IPO

## 题目描述

假设力扣（LeetCode）即将开始**IPO**。为了以更高的价格将股票卖给风险投资公司，力扣希望在 IPO 之前开展一些项目以增加其资本。由于资源有限，它只能在 IPO 之前完成最多 `k` 个不同的项目。帮助力扣设计完成最多 `k` 个不同项目后获得最大总资本的方式。

给你 `n` 个项目。对于每个项目 `i`，它都有一个纯利润 `profits[i]`，和启动该项目需要的最小资本 `capital[i]`。

最初，你的资本为 `w`。当你完成一个项目时，你将获得纯利润，且利润将被添加到你的总资本中。

总而言之，从给定项目中选择**最多** `k` 个不同项目的列表，以**最大化最终资本**，并输出最终可获得的最多资本。

答案保证在 32 位有符号整数范围内。

### 示例 1

```
输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
输出：4
解释：
由于你的初始资本为 0，你仅可以从 0 号项目开始（需要最小资本 0）。
在完成 0 号项目后，你将获得 1 的利润，你的总资本将变为 1。
此时你可以选择开始 1 号或 2 号项目（需要的最小资本都是 1）。
由于你最多可以选择两个项目，所以你需要完成 2 号项目以获得最大的资本。
因此，输出最后最大化的资本，为 0 + 1 + 3 = 4。
```

### 示例 2

```
输入：k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
输出：6
```

### 约束条件

- `1 <= k <= 10^5`
- `0 <= w <= 10^9`
- `n == profits.length`
- `n == capital.length`
- `1 <= n <= 10^5`
- `0 <= profits[i] <= 10^4`
- `0 <= capital[i] <= 10^9`

## 题目分析

### 算法思路

本题是典型的**贪心 + 大顶堆**问题。核心思路：

1. 将项目按照所需资本从小到大排序。
2. 每次迭代，将所有**当前资本能够启动**的项目加入大顶堆（按利润排序）。
3. 从堆中选择利润最大的项目执行，资本增加对应利润。
4. 重复上述步骤最多 k 次（或堆为空）。

这种贪心策略的正确性在于：在每一轮中，我们总是选择当前可执行项目中利润最大的，因为资本只会增加，不会减少，已可执行的项目在后续轮次中依然可执行。

### 复杂度分析

- **时间复杂度**：O(n log n + k log n)。
  - 排序：O(n log n)
  - 每个项目最多入堆一次、出堆一次：O(n log n)
- **空间复杂度**：O(n)，用于存储排序后的项目和堆。

### 关键点

- 使用大顶堆（按利润排序）从可执行项目中选择最优。
- 用指针 `idx` 追踪已入堆的项目，避免重复入堆。
- 当堆为空时说明没有更多可执行项目，提前终止。

## Go 代码实现

```go
package main

import (
    "container/heap"
    "fmt"
    "sort"
)

// MaxHeap 大顶堆（按利润）
type MaxHeap []int

func (h MaxHeap) Len() int           { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i] > h[j] } // 大顶堆
func (h MaxHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *MaxHeap) Push(x any) {
    *h = append(*h, x.(int))
}

func (h *MaxHeap) Pop() any {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func findMaximizedCapital(k int, w int, profits []int, capital []int) int {
    n := len(profits)

    // 将项目打包并按所需资本排序
    type Project struct {
        capital int
        profit  int
    }
    projects := make([]Project, n)
    for i := 0; i < n; i++ {
        projects[i] = Project{capital[i], profits[i]}
    }
    sort.Slice(projects, func(i, j int) bool {
        return projects[i].capital < projects[j].capital
    })

    h := &MaxHeap{}
    heap.Init(h)
    idx := 0 // 当前能入堆的项目的起始索引

    for i := 0; i < k; i++ {
        // 将所有当前资本可启动的项目加入堆
        for idx < n && projects[idx].capital <= w {
            heap.Push(h, projects[idx].profit)
            idx++
        }

        // 如果没有可执行的项目，提前终止
        if h.Len() == 0 {
            break
        }

        // 执行利润最大的项目
        w += heap.Pop(h).(int)
    }

    return w
}

func main() {
    fmt.Println(findMaximizedCapital(2, 0,
        []int{1, 2, 3}, []int{0, 1, 1})) // 4
    fmt.Println(findMaximizedCapital(3, 0,
        []int{1, 2, 3}, []int{0, 1, 2})) // 6
    fmt.Println(findMaximizedCapital(1, 0,
        []int{1, 2, 3}, []int{1, 1, 2})) // 0
}
```
