# 45. 快乐数

## 题目描述

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：

- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程，直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为 1**，那么这个数就是快乐数。

如果 `n` 是 **快乐数** 就返回 `true`；不是，则返回 `false`。

**示例 1：**

```
输入：n = 19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1
```

**示例 2：**

```
输入：n = 2
输出：false
```

**约束条件：**

- `1 <= n <= 2^31 - 1`

## 题目分析

### 算法思路

本题的关键在于识别"无限循环"：如果一个数不是快乐数，那么平方和的计算过程会进入一个**循环**。

因此可以使用 **哈希集合** 来判断是否存在循环：

1. 创建一个 `map[int]bool`（或 `set`），记录所有出现过的中间结果。
2. 不断计算当前数的各位数字平方和。
3. 如果结果为 1，返回 `true`。
4. 如果结果已经存在于集合中，说明进入了循环，返回 `false`。
5. 否则将结果加入集合并继续循环。

**进阶思路（快慢指针）**：
也可以在本题使用快慢指针（Floyd 判圈算法），将空间复杂度降为 O(1)：
- 慢指针每次算一次平方和。
- 快指针每次算两次平方和。
- 如果相遇且不为 1，则不是快乐数。

### 算法步骤

以哈希集合法为例：

1. 建立集合 `seen`（`map[int]bool`）。
2. 当 `n != 1` 时循环：
   - 若 `seen[n]` 为真，说明该数已经出现过，后续必然重复，返回 `false`；
   - 把 `n` 标记为已出现；
   - 计算 `n = getSquareSum(n)`（各位数字平方和）。
3. 循环结束（即 `n == 1`），返回 `true`。

### 为什么正确

定义后继函数 `f(x) = x 各位数字的平方和`。从 `n` 出发生成序列 `n, f(n), f(f(n)), ...`。这个序列只有两种命运：要么某一步变成 1（由定义即为快乐数），要么进入一个不包含 1 的循环——因为 `f` 是确定性的，且状态空间有限（一旦数值降到某个界以下，平方和不可能无限增大），「首次出现重复值」就意味着之前走过的路径会原样重复，永远到不了 1。哈希集合正是用来检测这个「首次重复」：命中即说明进入循环，返回 `false` 正确；能走到 1 则返回 `true` 正确。

### 复杂度分析

- **时间复杂度**：O(log n)，每次计算平方和需要遍历 `n` 的数位（`log n` 位）；进入循环前经过的不同数值个数有界，整体规模很小。
- **空间复杂度**：O(log n)，哈希集合最多存储循环中出现的不同数字（用快慢指针可降为 O(1)）。

### 易错点 / 边界情况

- 检测重复必须在「把当前值加入集合」之前进行，且当前值（包括初始的 `n`）也要加入集合，否则无法检测回到起点的循环。
- 不要用「迭代固定次数就停」的写法，必须真正做环检测。
- `getSquareSum` 用 `n > 0` 作循环条件即可；约束保证输入是正整数。
- `n = 1` 时循环不执行，直接返回 `true`，正确。
- 快慢指针版本要处理两种终止条件：快指针到达 1（快乐数），以及快慢指针相遇且值不为 1（进入循环）。
- 不会溢出：`n` 最大为 `2^31 - 1`，其平方和最大约 260，远小于 `int` 上限。
- 已知所有非快乐数最终都会落入包含 4 的循环，也可以用「值等于 4 时返回 false」来特判，但通用性不如集合或快慢指针。

## Go 代码实现

```go
func isHappy(n int) bool {
    // 哈希集合记录出现过的数字，用于检测循环
    seen := make(map[int]bool)

    for n != 1 {
        // 如果当前数字已经出现过，说明进入循环，返回 false
        if seen[n] {
            return false
        }
        seen[n] = true
        // 计算各位数字的平方和
        n = getSquareSum(n)
    }

    return true
}

// getSquareSum 计算数字 n 各位数字的平方和
func getSquareSum(n int) int {
    sum := 0
    for n > 0 {
        digit := n % 10      // 取个位数
        sum += digit * digit  // 累加平方
        n /= 10               // 去掉个位
    }
    return sum
}
```
