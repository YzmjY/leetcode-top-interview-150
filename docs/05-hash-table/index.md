# 第五章 哈希表

## 哈希表简介

哈希表（Hash Table，又称散列表）是一种根据键（Key）直接访问在内存存储位置的数据结构。它通过一个哈希函数将键映射到表中的一个位置来访问记录，以加快查找速度。一个理想的哈希函数应当满足：

- **确定性**：相同的键总是产生相同的哈希值。
- **高效性**：计算速度快。
- **均匀分布**：键被均匀地映射到哈希表的不同位置上。
- **低碰撞率**：不同的键产生相同哈希值的概率尽可能低。

### 哈希碰撞的处理方式

1. **链地址法（Separate Chaining）**：每个哈希桶存放一个链表，所有哈希值相同的元素被放在同一个链表中。Go 语言的 `map` 底层采用此方式。
2. **开放地址法（Open Addressing）**：发生碰撞时，按照某种探查方法（线性探查、二次探查、双重哈希等）寻找下一个空位置。

### Go 中的哈希表

Go 语言内置的 `map` 类型就是哈希表的实现，使用非常简洁：

```go
// 声明并初始化
m := make(map[string]int)
m["key"] = 1
value, exists := m["key"]
delete(m, "key")
```

## 哈希表的应用场景

- **查找问题**：判断元素是否存在、出现次数、位置索引。
- **映射关系**：建立一一对应或一对多的映射。
- **去重与频次统计**：例如统计单词出现次数、判断重复元素。
- **分组**：将具有相同特征的元素分组。
- **缓存（LRU）**：哈希表 + 双向链表实现高效的缓存淘汰策略。

## 常见题型

1. **字符频率统计**：如赎金信、有效字母异位词。
2. **映射关系建立**：如同构字符串、单词规律。
3. **查找与索引**：如两数之和、存在重复元素 II。
4. **分组问题**：如字母异位词分组。
5. **哈希集合应用**：如快乐数、最长连续序列。
