# 47. 最长连续序列

## 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

**示例 1：**

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**

```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**约束条件：**

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 题目分析

### 算法思路

要在 O(n) 时间复杂度内解决此问题，不能使用排序（排序至少 O(n log n)）。

核心思路：**使用哈希集合对每个元素进行 O(1) 的查找**，并且只从连续段的起点开始展开计数，避免重复扫描。

### 算法步骤

1. 将所有数字放入哈希集合 `numSet`，顺便完成去重，以便 O(1) 判断某个数字是否存在。
2. 遍历 **集合中的每个数字**（而不是原数组）`num`：
   - 若 `numSet[num-1]` 为真，说明 `num` 不是所在连续段的最小值，**跳过**（从 `num-1` 开始计数会得到更长的序列）；
   - 否则 `num` 是一个连续段的起点，从它出发不断检查 `num+1`、`num+2`、… 是否在集合中，统计这一段长度；
   - 用该长度更新全局最大值。
3. 返回全局最大值。

**关键优化**：只从每个连续段的起点开始计数（`num-1` 不存在于集合中），保证每个数字最多被展开访问一次，从而实现 O(n)。

### 为什么正确

设 `x` 是某个极大连续段 `[x, x+L-1]` 的最小值，则 `x-1` 不在集合中，算法会从 `x` 出发把该段的长度 `L` 完整数出来，因此不会漏掉任何段。反过来，任何满足 `num-1` 不在集合中的 `num` 必然是某个极大连续段的最小值，其向右侧的延伸恰好到段尾为止，不会跨段。又因为不同连续段互不相交，且只有段的最小值会真正启动延伸，所以所有延伸访问的数值总量不超过不同数字的个数；若去重后有 `m` 个不同值，总工作量是 O(m) <= O(n)。故算法既不会漏解，也满足 O(n)。

### 复杂度分析

- **时间复杂度**：O(n)。建集合 O(n)；遍历集合的每个不同值 O(m)；所有延伸循环加起来最多访问每个不同值一次，合计 O(m)。总体 O(n)。
- **空间复杂度**：O(n)，哈希集合存储所有元素（去重后不超过 n 个）。

### 易错点 / 边界情况

- 必须遍历**集合**（去重后的不同值），不能遍历原数组：如果数组里有大量重复的最小值（例如 5 万个 `1` 后面接 `2,3,...,50001`），遍历原数组会把同一条长连续段反复展开，退化成 O(n^2)。
- 起点判据是 `numSet[num-1]` 为真则跳过，不能反过来从每个元素向两侧扩展，那样同样是 O(n^2)。
- 不能先排序再扫描：排序解法是 O(n log n)，不满足题目「O(n)」的要求。
- 重复元素不影响答案，集合天然去重；延伸时也只依赖集合的存在性。
- 空数组返回 0；单元素数组返回 1。
- 极值（`-10^9`、`10^9`）和负数都安全，`num-1`/`num+1` 在 64 位平台不会溢出。
- 代码不修改输入数组，只是读取。

## Go 代码实现

```go
func longestConsecutive(nums []int) int {
    // 将所有数字放入哈希集合（同时完成去重）
    numSet := make(map[int]bool, len(nums))
    for _, num := range nums {
        numSet[num] = true
    }

    longest := 0

    // 遍历集合而非原数组：每个不同的值只处理一次，保证每个数字最多被展开一次
    for num := range numSet {
        // 如果 num-1 存在于集合中，说明 num 不是序列起点，跳过
        if numSet[num-1] {
            continue
        }

        // num 是序列起点，向右侧延伸
        curNum := num
        curLen := 1
        for numSet[curNum+1] {
            curNum++
            curLen++
        }

        // 更新最长长度
        if curLen > longest {
            longest = curLen
        }
    }

    return longest
}
```
