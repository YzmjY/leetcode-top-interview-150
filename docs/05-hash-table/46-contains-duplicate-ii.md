# 46. 存在重复元素 II

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在两个 **不同的索引** `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。

**示例 1：**

```
输入：nums = [1,2,3,1], k = 3
输出：true
```

**示例 2：**

```
输入：nums = [1,0,1,1], k = 1
输出：true
```

**示例 3：**

```
输入：nums = [1,2,3,1,2,3], k = 2
输出：false
```

**约束条件：**

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `0 <= k <= 10^5`

## 题目分析

### 算法思路

本题需要判断是否存在两个相等的元素，且它们的下标之差不超过 `k`。

使用哈希表记录每个元素**最近一次出现的位置**：

1. 遍历数组，对于当前元素 `nums[i]`：
   - 检查该元素是否已经在哈希表中出现过。
   - 如果出现过，计算当前位置与上一次出现位置的差值 `i - lastIndex`。
   - 如果差值 `<= k`，说明找到了满足条件的两个元素，返回 `true`。
   - 无论是否满足条件，更新该元素的最新位置为 `i`。

注意事项：即使当前差值 `> k`，也应该更新位置为当前 `i`，因为后续可能出现更近的重复元素。

### 复杂度分析

- **时间复杂度**：O(n)，只需遍历数组一次。
- **空间复杂度**：O(min(n, k))，哈希表最多存储 k+1 个不同元素（因为超过 k 范围的历史记录不会再被用到）。但实际上为了简洁，可以存储所有元素，也是 O(n)。

## Go 代码实现

```go
func containsNearbyDuplicate(nums []int, k int) bool {
    // 哈希表：元素值 -> 最近一次出现的下标
    lastIndex := make(map[int]int)

    for i, num := range nums {
        // 检查该元素之前是否出现过
        if idx, ok := lastIndex[num]; ok {
            // 下标差是否在 k 以内
            if i-idx <= k {
                return true
            }
        }
        // 更新该元素的最新位置
        lastIndex[num] = i
    }

    return false
}
```
