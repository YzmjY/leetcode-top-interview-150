# 128. 只出现一次的数字

## 题目描述

给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

### 示例 1

```
输入：nums = [2,2,1]
输出：1
```

### 示例 2

```
输入：nums = [4,1,2,1,2]
输出：4
```

### 示例 3

```
输入：nums = [1]
输出：1
```

### 约束条件

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

## 题目分析

### 算法思路

**朴素想法**：用哈希表统计每个数的出现次数，再找频次为 1 的元素。时间 O(n) 但空间 O(n)，不满足题目「常量额外空间」的要求。

**关键观察**：题目条件很特殊——除一个元素外，其余每个元素都恰好出现两次。而**异或（XOR）**恰好具备我们需要的三条性质：

1. **任何数与 0 异或等于自身**：`a ^ 0 = a`（0 是异或的单位元）；
2. **任何数与自身异或等于 0**：`a ^ a = 0`（相同的数互相抵消）；
3. **异或满足交换律和结合律**：`a ^ b = b ^ a`，`(a ^ b) ^ c = a ^ (b ^ c)`。

于是把数组所有元素异或起来：出现两次的元素两两抵消为 0，最终只剩那个只出现一次的元素。

**算法步骤**：

1. `result = 0`。
2. 从左到右遍历 `nums`，执行 `result ^= num`。
3. 返回 `result`。

**为什么正确**：由交换律与结合律，异或的顺序可以任意重排。把每个数的两次出现两两配对：

```
(a ^ a) ^ (b ^ b) ^ ... ^ x = 0 ^ 0 ^ ... ^ x = x
```

其中 `x` 是只出现一次的那个元素，因此最终结果必然是 `x`。异或按位运算，在补码表示下对负数同样成立，不需要任何特判。

### 复杂度分析

- **时间复杂度**：O(n)，只需一次线性遍历，每次 O(1)。
- **空间复杂度**：O(1)，只使用了一个累积变量。

### 关键点

- 异或的交换律和结合律使得元素的出现顺序无关紧要，这是能一次遍历完成的关键。
- 初值必须取 0（异或的单位元）；写 1 会把 1 混进结果。
- 不能用「求和再减去两倍某值」之类的算术技巧代替：那需要额外信息，且会被 0 或负数干扰。
- 负数直接参与异或即可，`a ^ a == 0` 对负数同样成立。
- 数组长度为 1 时循环执行一次，直接返回该元素。
- 题目要求 O(1) 额外空间，因此不要用哈希表计数（虽然结果正确，但不满足复杂度要求）。

## Go 代码实现

```go
package main

import "fmt"

func singleNumber(nums []int) int {
    result := 0
    for _, num := range nums {
        result ^= num
    }
    return result
}

func main() {
    testCases := [][]int{
        {2, 2, 1},
        {4, 1, 2, 1, 2},
        {1},
    }

    for _, nums := range testCases {
        fmt.Printf("nums = %v, 只出现一次的数字 = %d\n",
            nums, singleNumber(nums))
    }
}
```
