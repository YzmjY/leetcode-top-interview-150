# 127. 位1的个数

## 题目描述

编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 `1` 的个数（也被称为汉明重量）。

### 示例 1

```
输入：n = 00000000000000000000000000001011
输出：3
解释：输入的二进制串 00000000000000000000000000001011 中，共有三位为 '1'。
```

### 示例 2

```
输入：n = 00000000000000000000000010000000
输出：1
解释：输入的二进制串 00000000000000000000000010000000 中，共有一位为 '1'。
```

### 示例 3

```
输入：n = 11111111111111111111111111111101
输出：31
解释：输入的二进制串 11111111111111111111111111111101 中，共有 31 位为 '1'。
```

### 约束条件

- 输入必须是长度为 `32` 的二进制串。

## 题目分析

### 算法思路

**方法一：Brian Kernighan 算法**

核心技巧：`n & (n - 1)` 可以消除 `n` 的二进制表示中**最低位的 1**。

```
例如：n = 101100
     n - 1 = 101011
     n & (n-1) = 101000  （最低位的 1 被消除了）
```

每次执行 `n &= n - 1`，消除一个 `1`，同时计数器加 1。当 `n == 0` 时结束。

这种方法的好处是：**只需执行与 1 的个数相等次数的循环**，而非固定的 32 次。

**方法二：逐位检查**

循环 32 次，每次检查最低位是否为 1：`count += n & 1; n >>= 1`。

### 复杂度分析

- **时间复杂度**：O(k)，其中 k 为 1 的个数。Brian Kernighan 算法最坏 O(32)。
- **空间复杂度**：O(1)。

### 关键点

- `n & (n - 1)` 是位运算中最常用的技巧之一。
- 该技巧还可用于判断一个数是否为 2 的幂：`n > 0 && n & (n - 1) == 0`。

## Go 代码实现

```go
package main

import "fmt"

// 方法一：Brian Kernighan 算法
func hammingWeight(num uint32) int {
    count := 0
    for num != 0 {
        num &= num - 1 // 消除最低位的 1
        count++
    }
    return count
}

// 方法二：逐位检查
func hammingWeight2(num uint32) int {
    count := 0
    for i := 0; i < 32; i++ {
        count += int(num & 1)
        num >>= 1
    }
    return count
}

func main() {
    testCases := []uint32{
        0b00000000000000000000000000001011, // 3
        0b00000000000000000000000010000000, // 1
        0b11111111111111111111111111111101, // 31
    }

    for _, n := range testCases {
        fmt.Printf("n = %032b, 1的个数 = %d\n", n, hammingWeight(n))
    }
}
```
