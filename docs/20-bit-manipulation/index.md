# 第20章：位运算

## 概述

位运算（Bit Manipulation）是直接对整数的二进制表示进行操作的技巧。在算法题中，位运算常用于优化空间复杂度、实现 O(1) 额外空间的特殊操作，以及处理与二进制相关的计数问题。

## 常见位运算操作

### 基本运算符

| 运算符 | 符号 | 说明 | 示例 |
|--------|------|------|------|
| 按位与 | `&` | 两位都为 1 时结果为 1 | `5 & 3 = 1` (101 & 011 = 001) |
| 按位或 | `\|` | 至少一位为 1 时结果为 1 | `5 \| 3 = 7` (101 \| 011 = 111) |
| 按位异或 | `^` | 两位不同时结果为 1 | `5 ^ 3 = 6` (101 ^ 011 = 110) |
| 按位取反 | `~` | 0 变 1，1 变 0 | `~5 = -6`（补码表示） |
| 左移 | `<<` | 各二进制位全部左移若干位 | `5 << 1 = 10` (101 << 1 = 1010) |
| 右移 | `>>` | 各二进制位全部右移若干位 | `5 >> 1 = 2` (101 >> 1 = 10) |

### 常用技巧

#### 1. 异或 (XOR) 的性质

```go
x ^ 0 = x       // 与 0 异或不变
x ^ x = 0       // 与自己异或得 0
x ^ y = y ^ x   // 交换律
(x ^ y) ^ z = x ^ (y ^ z) // 结合律
```

**经典应用**：
- 找出数组中唯一出现一次的数字（其余都出现两次）：全异或即可。
- 交换两个数（不使用临时变量）：`a ^= b; b ^= a; a ^= b;`

#### 2. 获取/设置/清除位

```go
// 获取第 i 位（从 0 开始）
bit := (num >> i) & 1

// 设置第 i 位为 1
num |= (1 << i)

// 清除第 i 位（设为 0）
num &= ^(1 << i)

// 翻转第 i 位
num ^= (1 << i)
```

#### 3. 最低位的 1

```go
// 获取最低位的 1：num & (-num)
// 清除最低位的 1：num & (num - 1)
// 判断是否是 2 的幂：num > 0 && num & (num - 1) == 0
```

#### 4. 统计 1 的个数（Brian Kernighan 算法）

```go
count := 0
for num != 0 {
    num &= num - 1 // 消除最低位的 1
    count++
}
```
