# 90. 被围绕的区域

## 题目描述

给你一个 `m x n` 的矩阵 `board`，由若干字符 `'X'` 和 `'O'` 组成，**捕获**所有被围绕的区域：

- **连接：** 一个单元格与水平或垂直方向上相邻的单元格连接。
- **区域：** 连接所有 `'O'` 的单元格连接形成一个区域。
- **围绕：** 如果你可以用 `'X'` 单元格连接这个区域，并且区域中没有任何单元格与边缘 `'O'` 相连，则该区域被围绕。

通过将被围绕的区域中的所有 `'O'` 转换为 `'X'` 来捕获。

**示例 1：**

```
输入：board = [
  ["X","X","X","X"],
  ["X","O","O","X"],
  ["X","X","O","X"],
  ["X","O","X","X"]
]
输出：[
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","O","X","X"]
]
```

**示例 2：**

```
输入：board = [["X"]]
输出：[["X"]]
```

**约束条件：**

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 200`
- `board[i][j]` 为 `'X'` 或 `'O'`

## 题目分析

本题的关键在于**逆向思维**。直接判断某个 `'O'` 是否被围绕并不容易——需要确认它所在区域的所有格子都被 `'X'` 包围、且没有任何格子触到边界。但反过来看非常容易：**只要一个 `'O'` 区域碰到矩阵的边界，它就一定不会被围绕**（题目原文也强调区域中不能有单元格与边缘 `'O'` 相连）。于是：

> 会被捕获的 `'O'` = 所有 `'O'` 中减去「与边界连通」的那些

**算法思路（图的染色/洪泛）：**

1. 遍历四条边界上的所有格子。凡是 `'O'` 的，以它为起点做 DFS/BFS，把整个与边界连通的区域**临时标记成 `'#'`**（也可以理解成给「免死区域」染色）。DFS 对四邻接扩展，遇到非 `'O'` 就停止。
2. 遍历整个矩阵做一次统一处理：
   - 仍是 `'O'` 的格子：它既不与边界连通（没被染成 `'#'`），所以属于被围绕的区域，改成 `'X'`；
   - 是 `'#'` 的格子：它是免死区域，恢复回 `'O'`。
3. 原地修改矩阵，不返回任何值。

**为什么正确：**

- **免死区域确实不该被捕获**：若某 `'O'` 与边界上的 `'O'` 四连通，则它所在的区域触到了边界，不是「被 `'X'` 完全包围」的区域，题目要求保留。步骤 1 恰好标记了所有这类格子（DFS 沿连通关系传播，必然覆盖整个区域，且边界循环覆盖了所有边界入口）。
- **其余 `'O'` 确实该被捕获**：若某 `'O'` 不与任何边界 `'O'` 连通，那么从它出发无法走出矩阵，它所在的整个区域都被 `'X'` 包围，必须改成 `'X'`。
- **标记与还原不会互相干扰**：`'#'` 是临时状态，它不与 `'O'` 混淆，因此步骤 2 中「`'O'` → `'X'`」的判定不会误伤免死区域；最后把 `'#'` 还原成 `'O'` 保证免死区域原样保留。同一区域只被标记一次（标记后不再是 `'O'`，DFS 立即返回），所以不会重复访问。

**时间复杂度：** O(m * n)。每个格子被边界循环检查常数次，被 DFS 访问至多一次（访问后立刻变成 `'#'`），最后的统一扫描又是一遍。

**空间复杂度：** O(m * n)，最坏情况下递归栈深度等于网格大小（例如整块 200×200 的 `'O'` 与边界连通时，递归深度 40000）。改用 BFS 或显式栈可把空间变成队列长度。

**易错点 / 边界情况：**

- 边界循环要**四条边都做**：左右两列用 `for i`，上下两行用 `for j`。只做左右两列会漏掉上下边界上的 `'O'`；四条边在角点会重复检查，但因为已经变成 `'#'`（`!= 'O'`），重复调用是无害的。
- 步骤 2 里两个分支的顺序要写对：先判断 `'#'` 还原为 `'O'`，否则该格子已经被改成 `'X'` 了。或者反过来先处理 `'O' → 'X'`、再处理 `'#' → 'O'`，只要不把 `'#'` 卷进 `'O'` 分支即可。
- **单行或单列的矩阵**：每个格子都在边界上，所以所有 `'O'` 都应保留。例如 `[["O"]]` 输出仍是 `[["O"]]`，不要因为「矩阵很小」就误以为它被围绕。
- 全为 `'X'` 的矩阵不需要任何改动；`board` 为空或首行为空时要直接返回（代码里 `len(board) == 0 || len(board[0]) == 0` 的保护）。
- 递归深度可达 40000（200×200 的规模），Go 的动态栈没问题，但换语言时要注意栈溢出。
- 题目要求**原地**修改，不要返回新矩阵；面试中如果返回新矩阵通常会被认为没有满足要求。

## Go 代码实现

```go
package main

import "fmt"

// solve 捕获被围绕的区域（DFS 实现）
func solve(board [][]byte) {
    if len(board) == 0 || len(board[0]) == 0 {
        return
    }
    m, n := len(board), len(board[0])

    var dfs func(i, j int)
    dfs = func(i, j int) {
        if i < 0 || i >= m || j < 0 || j >= n || board[i][j] != 'O' {
            return
        }
        board[i][j] = '#' // 临时标记为不可捕获
        dfs(i+1, j)
        dfs(i-1, j)
        dfs(i, j+1)
        dfs(i, j-1)
    }

    // 从边界 'O' 出发，标记所有与边界相连的 'O'
    for i := 0; i < m; i++ {
        if board[i][0] == 'O' {
            dfs(i, 0)
        }
        if board[i][n-1] == 'O' {
            dfs(i, n-1)
        }
    }
    for j := 0; j < n; j++ {
        if board[0][j] == 'O' {
            dfs(0, j)
        }
        if board[m-1][j] == 'O' {
            dfs(m-1, j)
        }
    }

    // 处理标记
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if board[i][j] == '#' {
                board[i][j] = 'O'
            } else if board[i][j] == 'O' {
                board[i][j] = 'X'
            }
        }
    }
}

func main() {
    board := [][]byte{
        {'X', 'X', 'X', 'X'},
        {'X', 'O', 'O', 'X'},
        {'X', 'X', 'O', 'X'},
        {'X', 'O', 'X', 'X'},
    }
    solve(board)
    for _, row := range board {
        fmt.Println(string(row))
    }
}
```
