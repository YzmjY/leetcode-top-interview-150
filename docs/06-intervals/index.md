# 第六章 区间

## 区间问题简介

区间（Interval）是算法题中常见的数据概念，通常表示为一个二元组 `[start, end]`，表示从 `start` 到 `end` 的连续范围。在算法题中，区间通常以 `[start, end]` 或 `{start, end}` 的形式出现。

### 核心操作

1. **排序**：大多数区间问题需要先对区间按照起点（或终点）进行排序，这是解题的第一步。
2. **遍历与合并**：在排序后的区间列表上遍历，根据当前区间与上一个区间的关系进行判断（重叠、包含、分离）。
3. **贪心**：许多区间问题都可以用贪心策略解决，如选择结束最早的区间、箭数最少等。

### 常见区间关系

- **重叠（Overlap）**：`interval1.end >= interval2.start`
- **包含（Contain）**：`interval1.start <= interval2.start && interval1.end >= interval2.end`
- **分离（Disjoint）**：`interval1.end < interval2.start`

## 常见题型

1. **汇总区间**：将有序的数值列表表示为区间形式。
2. **合并区间**：将重叠的区间合并为更大的区间。
3. **插入区间**：在有序且不重叠的区间列表中插入一个新区间。
4. **贪心区间问题**：如用最少数量的箭引爆气球（本质是最小化区间选点）。
