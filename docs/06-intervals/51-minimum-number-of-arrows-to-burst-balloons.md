# 51. 用最少数量的箭引爆气球

## 题目描述

有一些球形气球贴在一堵用 XY 平面表示的墙面上。墙面上的气球记录在整数数组 `points`，其中 `points[i] = [x_start, x_end]` 表示水平直径在 `x_start` 和 `x_end` 之间的气球。你不知道气球的确切 y 坐标。

一支弓箭可以沿着 x 轴从不同点 **完全垂直** 地射出。在坐标 `x` 处射出一支箭，若有一个气球的直径的开始和结束坐标为 `x_start, x_end`，且满足 `x_start <= x <= x_end`，则该气球会被 **引爆**。可以射出的弓箭的数量 **没有限制**。弓箭一旦被射出之后，可以无限地前进。

给你一个数组 `points`，返回引爆所有气球所必须射出的 **最小** 弓箭数。

**示例 1：**

```
输入：points = [[10,16],[2,8],[1,6],[7,12]]
输出：2
解释：气球可以用2支箭来爆破:
- 在 x = 6 处射出箭，击破气球 [2,8] 和 [1,6]
- 在 x = 11 处射出箭，击破气球 [10,16] 和 [7,12]
```

**示例 2：**

```
输入：points = [[1,2],[3,4],[5,6],[7,8]]
输出：4
解释：每个气球需要射出一支箭，总共需要 4 支箭
```

**示例 3：**

```
输入：points = [[1,2],[2,3],[3,4],[4,5]]
输出：2
解释：气球可以用2支箭来爆破:
- 在 x = 2 处射出箭，击破气球 [1,2] 和 [2,3]
- 在 x = 4 处射出箭，击破气球 [3,4] 和 [4,5]
```

**约束条件：**

- `1 <= points.length <= 10^5`
- `points[i].length == 2`
- `-2^31 <= x_start < x_end <= 2^31 - 1`

## 题目分析

### 算法思路

**核心思路：** 换个角度看：每支箭是一个 x 坐标 `x`，它能引爆所有满足 `x_start <= x <= x_end` 的气球。所以问题等价于**用最少的点去「刺穿」所有区间**（区间选点覆盖问题）。

朴素想法是：从左往右扫描，遇到一个还没被引爆的气球就补一箭。剩下的唯一问题就是——**这一箭射在哪里？**

关键观察：在还未引爆的气球中，**右端点最小的那个最“紧迫”**，因为它最早结束。任何能引爆它的箭都必须落在它的区间内，也就是说，能同时引爆它的那些候选位置中，最靠右的无非就是它自己的右端点。把箭放在那里，既保证了能引爆它，又尽可能多地覆盖后面（右端点更大）的气球。这就是贪心选择。

**算法步骤：**

1. 把所有气球按**右端点** `x_end` 升序排序。
2. 用第一支箭射在第一个气球的右端点：`arrows = 1`、`arrowPos = points[0][1]`。
3. 依次考察后续每个气球：
   - 若 `points[i][0] > arrowPos`，说明这支箭落在该气球左边、打不到它，必须新射一箭。新箭同样射在该气球的右端点上：`arrows++`、`arrowPos = points[i][1]`；
   - 否则 `points[i][0] <= arrowPos`，而排序保证 `points[i][1] >= arrowPos`，即 `arrowPos` 落在该气球区间内，它已被引爆，无需处理。
4. 返回 `arrows`。

**为什么正确（贪心选择性质 + 交换论证）：**

先证明一个引理：**设 `I₀ = [s₀, e₀]` 是所有气球中右端点最小的那个，则存在一个最优解，其中有一支箭正好射在 `e₀`。**

任何可行解都必须有箭打中 `I₀`，设这支箭位于 `x* ∈ [s₀, e₀]`。现在把 `x*` 移动到 `e₀`，考察原本被 `x*` 打中的任意气球 `J = [s, e]`。由 `J` 被打中有 `s <= x* <= e`，于是 `s <= x* <= e₀`，即 `s <= e₀`；另一方面 `I₀` 的右端点最小，所以 `e >= e₀`。两者合起来恰好说明 `e₀ ∈ [s, e]`，即 `J` 依然被打中。移动只可能让这支箭打中不减少的目标，所以移动后的解仍然可行且箭数不变，引理得证。

由此得到归纳结构：确定第一支箭射在 `e₀` 后，所有左端点 `<= e₀` 的气球（它们的右端点都 `>= e₀`）都被这一箭解决，剩下的都是左端点 `> e₀`、完全位于右侧的气球。这些剩余气球构成一个规模严格更小的同类子问题，可以递归地使用同样的贪心。算法的循环正是这个递归的迭代实现：`arrowPos` 就是上一支箭的位置，第一个满足 `points[i][0] > arrowPos` 的气球（排序后它也是未引爆气球中右端点最小的那个）触发下一支箭，箭的位置取它的右端点。由归纳法，每支箭都是「当前子问题的最优选择」，总箭数最少。

### 复杂度分析

- **时间复杂度**：O(n log n)。排序是瓶颈；之后的遍历是 O(n)。
- **空间复杂度**：O(log n)，来自排序的递归栈（不计输入输出）。排序之外的额外变量是常数个。

### 易错点 / 边界情况

- **要按右端点排序，不是左端点**：按左端点排序后「箭射在右端点最小处」这个贪心论证不再成立，容易写出反例。
- **判据必须是严格大于**：`points[i][0] > arrowPos` 才需要新箭。写成 `>=` 会把仅共享端点的气球误判为打不到；而示例 3 中 `[1,2]` 与 `[2,3]` 正是靠 `x = 2` 一箭双雕，答案是 2 而不是 3。
- **不要做加减法**：坐标可以取到 `±2^31 - 1`，任何 `x_end + 1`、`x_start - 1` 之类的写法都可能溢出。本解法只做比较，所以安全。
- **空输入**：约束保证 `n >= 1`，但代码仍保留了 `len(points) == 0 → 0` 的保护，避免 `points[0]` 越界。
- **返回的是箭的数量**，不是箭的位置；题目也不要求给出位置。
- **重复的区间**：例如 `[[1,2],[1,2]]`，排序后一支箭就能同时覆盖两个区间，结果是 1；`arrowPos` 的含义是「最后一支箭的位置」，而不是「当前气球组的数量」。
- **不要把 `arrows` 初始化成 0 再在循环里自增**：第一支箭在进入循环前就已经射出（射在第一个气球的右端点），因此初值为 1。若想写成 0，则需要额外处理空输入的边界。

## Go 代码实现

```go
import "sort"

func findMinArrowShots(points [][]int) int {
    if len(points) == 0 {
        return 0
    }

    // 按照右边界升序排列
    sort.Slice(points, func(i, j int) bool {
        return points[i][1] < points[j][1]
    })

    // 第一支箭射在第一个气球的右边界
    arrows := 1
    arrowPos := points[0][1]

    for i := 1; i < len(points); i++ {
        // 如果当前气球的左边界大于箭的位置，需要新射一支箭
        if points[i][0] > arrowPos {
            arrows++
            arrowPos = points[i][1]
        }
    }

    return arrows
}
```
