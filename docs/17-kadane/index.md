# 第17章：Kadane 算法

## 概述

Kadane 算法是一种用于求解**最大子数组和**问题的动态规划算法，由 Jay Kadane 于 1984 年提出。该算法以 O(n) 的时间复杂度和 O(1) 的空间复杂度高效地解决了经典问题。

## 核心思想

Kadane 算法的核心在于**以某个位置结尾的子数组和**这个状态定义：

- 定义 `dp[i]` 表示以第 `i` 个元素结尾的子数组的最大和。
- 对于每个位置 `i`，我们有两种选择：
  1. 将当前元素 `nums[i]` 接在前面的子数组后面（`dp[i-1] + nums[i]`）
  2. 从当前元素 `nums[i]` 重新开始一个子数组
- 因此状态转移方程为：`dp[i] = max(nums[i], dp[i-1] + nums[i])`
- 最终答案 = `max(dp[0], dp[1], ..., dp[n-1])`

由于 `dp[i]` 只依赖于 `dp[i-1]`，我们可以将空间优化为 O(1)：

```go
maxEndingHere := nums[0]
maxSoFar := nums[0]
for i := 1; i < len(nums); i++ {
    maxEndingHere = max(nums[i], maxEndingHere+nums[i])
    maxSoFar = max(maxSoFar, maxEndingHere)
}
```

## 关键洞察

- **"以某个位置结尾"** 这个状态定义是算法的精髓。它保证了子数组的连续性。
- 如果 `maxEndingHere` 变为负数，下一个元素会"重新开始"，因为负数只会拖累后续的和。
- 算法天然处理了全负数数组的情况（取最大的单个元素）。

## 变体与扩展

Kadane 算法的思想可以扩展到多种变体：

1. **环形子数组的最大和**：将环形数组拆分为两种情况——最大子数组在中间（普通 Kadane），或最大子数组跨越边界（总和减最小子数组）。
2. **最大子数组乘积**：需要同时维护最大值和最小值（因为负数乘负数可能变成正数）。
3. **二维最大子矩阵和**：将二维压缩为一维后应用 Kadane。
