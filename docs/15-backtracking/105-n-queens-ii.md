# 105. N 皇后 II

## 题目描述

**n 皇后问题**研究的是如何将 `n` 个皇后放置在 `n x n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回 **n 皇后问题** 不同的解决方案的数量。

皇后可以攻击同一行、同一列、同一正对角线（左上到右下）、同一反对角线（右上到左下）上的棋子。

**示例 1：**

```
输入：n = 4
输出：2
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：1
```

**约束条件：**

- `1 <= n <= 9`

## 题目分析

### 算法思路

**核心思路**：N 皇后是「逐行放置 + 冲突检测」的典型回溯。关键观察有两个：其一，每行恰好放一个皇后，所以按行递归就自动满足了「不同行」；其二，列和对角线的冲突都可以用**常量表达式**刻画，从而用 O(1) 的布尔数组判断，不需要每次去扫描棋盘。

**约束条件的等价表示：**

- 不同列：用 `cols[col]` 记录第 `col` 列是否已占用。
- 正对角线（左上→右下）：同一条线上 `row - col` 为常量，索引 `row - col + n - 1` 把取值平移成 `0 ~ 2n-2`，用 `diag1` 记录。
- 反对角线（右上→左下）：同一条线上 `row + col` 为常量，取值范围本身就是 `0 ~ 2n-2`，用 `diag2` 记录。

**算法步骤：**

1. 分配 `cols`、`diag1`、`diag2` 三个长度分别为 `n`、`2n-1`、`2n-1` 的布尔数组，计数器 `count = 0`。
2. `backtrack(row)`：若 `row == n`，说明 n 行都放好了，`count++` 并返回。
3. 对 `col := 0..n-1` 计算 `d1 = row - col + n - 1`、`d2 = row + col`；三者中任一为 true 则 `continue`（冲突）。
4. 否则把三个标记置 true → 递归 `backtrack(row+1)` → 递归返回后把三个标记置回 false（回溯）。
5. 返回 `count`。

### 为什么正确

- **状态含义完备**：`row` 表示「前 `row` 行已经各放了一个互不攻击的皇后」。递归到 `row == n` 时，`n` 个皇后已经全部放下且两两不冲突，因此是一个合法解。
- **三个标记的等价性**：两个皇后冲突当且仅当同行、同列、同正对角线或同反对角线。行冲突由「每行只放一个」排除；列用 `col` 相等判定；正对角线用 `row-col` 相等判定；反对角线用 `row+col` 相等判定。所以 `cols[col] || diag1[d1] || diag2[d2]` 为 false 当且仅当新皇后与已放置的皇后都不冲突。
- **不重不漏**：每一行的每一列都会被循环枚举一次，递归结构覆盖了「每行选一列」的全部 `n^n` 种组合；不合法的分支被提前剪掉，剩下的恰好是所有合法解，且每个解由「每行的列号序列」唯一确定，只被计数一次。
- **回溯恢复现场**：递归返回后清空三个标记，保证兄弟分支看到的是「只剩当前行之前的皇后」的状态。

### 复杂度分析

- **时间复杂度：** O(n!)，搜索树的节点数随 n 呈阶乘级增长（每多放一行，可选列数就减少），实际因剪枝远小于上界。n ≤ 9 时最大的 n=9 也能很快跑完。
- **空间复杂度：** O(n)，三个标记数组分别占 `n`、`2n-1`、`2n-1`，递归栈深度为 n。

### 易错点 / 边界情况

- **对角线索引别写反**：正对角线用 `row - col + n - 1`（必须加偏移保证非负），反对角线用 `row + col`；两者数组长度都是 `2n-1`，写小了会下标越界。
- **`diag1` 的偏移量是 `n-1`**：`row-col` 的取值范围是 `-(n-1) ~ n-1`，加 `n-1` 后正好落到 `0 ~ 2n-2`。
- **回溯必须恢复三个标记**：只恢复 `cols` 而漏掉对角线，会让后续分支误判为冲突而漏解。
- **`n = 1`**：`2n-1 = 1`，`d1 = d2 = 0`，返回 1，数组不会越界。
- **`n = 2、3`**：无解，必须返回 0 而不是 panic，这也检验了冲突判断与剪枝是否正确。
- **本题只要求方案数**：不需要保存棋盘，因此可以省去构造 `[]string` 的开销；若改写成「N 皇后 I」需要在 `row == n` 时把棋盘快照存入结果。
- **已知解数序列**：1,0,0,2,10,4,40,92,352（n=1..9），可以用它自测。
- **计数用值传递还是闭包？** Go 中用闭包捕获 `count` 即可，不要用计数器切片之类的绕路写法。

## Go 代码实现

```go
package main

import "fmt"

// totalNQueens 返回 N 皇后的解法总数
func totalNQueens(n int) int {
    cols := make([]bool, n)        // 列标记
    diag1 := make([]bool, 2*n-1)   // 正对角线 (row - col + n - 1)
    diag2 := make([]bool, 2*n-1)   // 反对角线 (row + col)
    count := 0

    var backtrack func(row int)
    backtrack = func(row int) {
        if row == n {
            count++
            return
        }

        for col := 0; col < n; col++ {
            d1 := row - col + n - 1 // 正对角线索引
            d2 := row + col         // 反对角线索引

            if cols[col] || diag1[d1] || diag2[d2] {
                continue // 冲突，跳过
            }

            // 做选择
            cols[col] = true
            diag1[d1] = true
            diag2[d2] = true

            backtrack(row + 1)

            // 撤销选择
            cols[col] = false
            diag1[d1] = false
            diag2[d2] = false
        }
    }

    backtrack(0)
    return count
}

func main() {
    fmt.Println(totalNQueens(4)) // 2
    fmt.Println(totalNQueens(1)) // 1
    fmt.Println(totalNQueens(8)) // 92
}
```
