# 77. 求根节点到叶节点数字之和

## 题目描述

给你一个二叉树的根节点 `root`，树中每个节点都存放有一个 `0` 到 `9` 之间的数字。

每条从根节点到叶节点的路径都代表一个数字：

- 例如，从根节点到叶节点的路径 `1 -> 2 -> 3` 表示数字 `123`。

计算从根节点到叶节点生成的 **所有数字之和**。

**叶节点** 是指没有子节点的节点。

**示例 1：**

```
输入：root = [1,2,3]
输出：25
解释：
从根到叶子节点路径 1->2 代表数字 12
从根到叶子节点路径 1->3 代表数字 13
因此，数字总和 = 12 + 13 = 25
```

**示例 2：**

```
输入：root = [4,9,0,5,1]
输出：1026
解释：
从根到叶子节点路径 4->9->5 代表数字 495
从根到叶子节点路径 4->9->1 代表数字 491
从根到叶子节点路径 4->0 代表数字 40
因此，数字总和 = 495 + 491 + 40 = 1026
```

**提示：**

- 树中节点的数目在范围 `[1, 1000]` 内。
- `0 <= Node.val <= 9`
- 树的深度不超过 10。

## 题目分析

### 算法思路

**核心思路**：一条根到叶的路径对应一个数字，而数字的构造天然是「前缀递推」的：走到深度 d 时的前缀数字 `cur`，走到下一层就变成 `cur*10 + 子节点值`。因此在 DFS 过程中携带一个 `cur` 参数即可，不需要额外保存路径。

采用 DFS（前序遍历），在递归过程中维护从根到当前节点的数字值。

**核心思想**：每下降一层，将当前数字乘以 10 再加上当前节点值。

递归过程：
1. 空节点返回 0（对求和没有贡献）。
2. 更新当前路径数字：`cur = cur*10 + node.Val`。
3. 如果到达叶子节点，返回 `cur`（这条路径对应的数字）。
4. 否则返回左右子树的递归结果之和。

### 为什么正确

对树高做归纳，考察 `dfs(node, cur)` 的含义：「以 `cur` 为前缀、从 `node` 出发到其所有叶子的数字之和」。若 `node` 为空，没有路径，返回 0。若 `node` 是叶子，从它出发只有一条路径，构造出的数字是 `cur*10 + node.Val`，返回它即正确。若 `node` 非叶子，从它出发的所有根到叶路径按第一步走向分成两类：进入左子树的和进入右子树，两类的数字前缀都是 `cur*10 + node.Val`，由归纳假设两个子调用分别给出两类的和，相加即全部路径之和。因此根节点的返回值就是所有根到叶数字之和。

### 复杂度分析

- **时间复杂度**：O(n)，每个节点访问一次。
- **空间复杂度**：O(h)，递归栈深度（h 为树高，题目保证 h ≤ 10）。

### 易错点 / 边界情况

- 空节点要返回 0，不能返回当前 `cur`，否则同一条路径会被重复计入。
- 只有叶子才产生数字，中途节点不返回 `cur`。
- 根节点为 0（或路径中出现 0）时，`cur*10 + 0` 天然处理前导零，例如 `4 -> 0` 表示 40，不需要特判。
- 单节点树返回该节点值本身（包括 0）。
- **数值范围**：深度 ≤ 10、每位 0~9 时单个数字最大可达约 10 位（如 9999999999），求和结果更大，会超出 32 位 `int` 的范围。Go 的 `int` 在常见平台上是 64 位，足够；若改写成 C/C++/Java，需要用 `long`/`long long`。
- 用返回值相加而非全局累加变量，能避免忘记在叶子处重置状态。

## Go 代码实现

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func sumNumbers(root *TreeNode) int {
    var dfs func(*TreeNode, int) int
    dfs = func(node *TreeNode, cur int) int {
        if node == nil {
            return 0
        }
        // 更新当前路径数字
        cur = cur*10 + node.Val
        // 到达叶子节点，返回当前数字
        if node.Left == nil && node.Right == nil {
            return cur
        }
        // 递归求和左右子树的路径数字
        return dfs(node.Left, cur) + dfs(node.Right, cur)
    }
    return dfs(root, 0)
}
```
