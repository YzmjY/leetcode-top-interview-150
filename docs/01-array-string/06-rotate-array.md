# 6. 轮转数组

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**

```
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]
```

**示例 2：**

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释:
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]
```

**约束条件：**

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

**进阶：**
- 尽可能想出更多的解决方案，至少有 **三种** 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 `O(1)` 的 **原地** 算法解决这个问题吗？

## 题目分析

**算法思路：** 使用数组翻转法（三次翻转）。这是原地 O(1) 空间的最优解法。

1. 首先对 `k` 取模：`k = k % n`（当 `k > n` 时避免无效操作）
2. 翻转整个数组：`[1,2,3,4,5,6,7]` -> `[7,6,5,4,3,2,1]`
3. 翻转前 `k` 个元素：`[7,6,5]` -> `[5,6,7]`，得 `[5,6,7,4,3,2,1]`
4. 翻转后 `n-k` 个元素：`[4,3,2,1]` -> `[1,2,3,4]`，得 `[5,6,7,1,2,3,4]`

**时间复杂度：** O(n)，每个元素被翻转两次。

**空间复杂度：** O(1)，原地操作。

## Go 代码实现

```go
// rotate 将数组向右轮转 k 个位置，使用三次翻转法
func rotate(nums []int, k int) {
    n := len(nums)
    // k 可能大于 n，取模避免无效操作
    k = k % n
    if k == 0 {
        return
    }

    // 辅助函数：翻转 nums[l:r+1] 区间
    reverse := func(l, r int) {
        for l < r {
            nums[l], nums[r] = nums[r], nums[l]
            l++
            r--
        }
    }

    // 1. 翻转整个数组
    reverse(0, n-1)
    // 2. 翻转前 k 个元素
    reverse(0, k-1)
    // 3. 翻转后 n-k 个元素
    reverse(k, n-1)
}
```
