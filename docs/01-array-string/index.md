# 第一章：数组/字符串

## 数据结构与算法背景

数组（Array）是最基础且最重要的数据结构之一，它在内存中连续存储相同类型的元素，支持 O(1) 时间复杂度的随机访问。字符串（String）本质上可以看作是一种特殊的字符数组。数组/字符串相关题目在面试中占比极高，是考察基本编程能力和算法思维的核心题型。

### 常见题型

1. **双指针技术**：对撞指针、快慢指针，广泛应用于数组去重、合并、移动元素等场景
2. **前缀和**：用于快速求解子数组和问题
3. **贪心算法**：跳跃游戏、股票买卖等最优化问题
4. **哈希表辅助**：用于 O(1) 查找，常用于两数之和变体
5. **原地操作**：要求空间复杂度 O(1) 的数组修改
6. **字符串处理**：模拟题、字符串匹配、格式转换

### 解题关键

- 充分利用数组的索引特性
- 注意边界条件（空数组、单元素、全相同元素）
- 优先考虑原地算法以减少空间复杂度
- 对于字符串问题，注意不可变性（Go 中需转为 `[]rune` 或 `[]byte`）
