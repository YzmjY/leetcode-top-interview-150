# 9. 跳跃游戏

## 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的 **第一个下标**。数组中的每个元素代表你在该位置可以跳跃的**最大长度**。

判断你是否能够到达最后一个下标，如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**

```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
```

**示例 2：**

```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0，所以永远不可能到达最后一个下标。
```

**约束条件：**

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

## 题目分析

**算法思路：** 朴素想法是枚举所有跳法（回溯），但跳法数量随数组长度指数增长，不可行。关键观察是：我们并不需要知道「具体走了哪几步」，只需要知道「最远能覆盖到哪个下标」——因为从位置 `j` 可以落到区间 `[j, j+nums[j]]` 中的任意位置，所以可达位置一定构成一段连续前缀 `[0, maxReach]`，中间不会出现空洞。于是只需维护一个变量 `maxReach`：遍历到下标 `i` 时先检查它是否落在可达前缀内（`i <= maxReach`），若可达就用 `i + nums[i]` 尝试把 `maxReach` 推得更远。

**算法步骤：**

1. 令 `maxReach = 0`（初始站在下标 0，最远可达下标 0）。
2. 从左到右枚举 `i = 0, 1, ..., n-1`：
   - 若 `i > maxReach`：下标 `i` 已超出当前可达范围，其后的下标只会更远，直接返回 `false`；
   - 否则 `i` 可达，更新 `maxReach = max(maxReach, i + nums[i])`；
   - 若此时 `maxReach >= n-1`，已经能到终点，提前返回 `true`。
3. 循环正常结束仍未返回，说明终点落在可达范围内，返回 `true`。

**为什么正确（可达前缀不变量）：** 循环保持不变量——`maxReach` 等于所有已确认可达的下标 `j < i` 中 `j + nums[j]` 的最大值。由此可以推出「可达位置恰好是前缀区间 `[0, maxReach]`」：一方面，任何可达的 `j` 都能一步跳到 `j..j+nums[j]`，所以区间内每个位置都可达；另一方面，任何可达位置必然由某个可达的 `j` 跳来，其下标不会超过当时的 `maxReach`。既然可达集合是连续前缀，按顺序扫描时第一次遇到 `i > maxReach` 就说明它及之后的位置不可达（返回 `false` 正确）；反过来，若能扫完或 `maxReach` 已覆盖 `n-1`，终点就可达（返回 `true` 正确）。

**时间复杂度：** O(n)，每个元素只处理一次，更新 `maxReach` 是 O(1) 操作。

**空间复杂度：** O(1)，只用了 `maxReach` 等常数个变量。

**易错点：**

- 判据是 `i > maxReach` 而不是 `i >= maxReach`：`i == maxReach` 时下标 `i` 恰好是可达区间的最右端，仍然可以落脚。
- 必须先判断 `i` 是否可达，再用 `i + nums[i]` 更新 `maxReach`；顺序颠倒会把不可达位置的长度也算进来，凭空把范围推远。
- 提前返回的条件是 `maxReach >= n-1`（下标从 0 开始），写成 `>= n` 会漏掉终点恰好是最后一个下标的情形。
- 数组中的 `0` 不一定导致失败：只要还有别的可达位置能越过它即可，例如 `[2,0,0]` 返回 `true`。
- 边界：`n == 1` 时起点即终点，返回 `true`；`nums[0] == 0` 且 `n > 1` 时返回 `false`。

## Go 代码实现

```go
// canJump 判断是否能从第一个下标跳到最后一个下标
// 贪心策略：维护当前能到达的最远位置
func canJump(nums []int) bool {
    // maxReach 记录当前能够到达的最远下标
    maxReach := 0
    n := len(nums)

    for i := 0; i < n; i++ {
        // 如果当前位置已经超出了能到达的最远范围，无法继续
        if i > maxReach {
            return false
        }
        // 更新能到达的最远位置
        if i+nums[i] > maxReach {
            maxReach = i + nums[i]
        }
        // 如果已经能到达或超过最后一个下标，提前返回
        if maxReach >= n-1 {
            return true
        }
    }
    return true
}
```
