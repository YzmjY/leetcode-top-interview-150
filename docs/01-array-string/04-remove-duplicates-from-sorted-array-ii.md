# 4. 删除有序数组中的重复项 II

## 题目描述

给你一个有序数组 `nums`，请你 **原地** 删除重复出现的元素，使得出现次数超过两次的元素**只出现两次**，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 **原地** 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

**示例 1：**

```
输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3]
解释：函数应返回新长度 length = 5，并且原数组的前五个元素被修改为 1, 1, 2, 2, 3。
不需要考虑数组中超出新长度后面的元素。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3]
解释：函数应返回新长度 length = 7，并且原数组的前七个元素被修改为 0, 0, 1, 1, 2, 3, 3。
不需要考虑数组中超出新长度后面的元素。
```

**约束条件：**

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按升序排列

## 题目分析

**算法思路：** 这是上一题「每个元素只保留一次」的推广：每个值最多保留两次。仍然利用数组有序、相同元素相邻的性质，但「与前一个保留值比较是否相等」已经不够了——它只能判断重复，无法区分「第 2 次出现」和「第 3 次出现」。

关键观察：因为有序，**同一个值的多次出现是连续的**。如果我们始终维护结果前缀 `nums[0..slow-1]`，那么某个值能否被保留，只取决于结果前缀里已经写入了它的几次。由于连续出现，判断条件可以精简为：当前元素 `nums[fast]` 与结果前缀倒数第二个元素 `nums[slow-2]` 比较——若相等，说明结果里已经有该值的两次出现，当前是第 3 次及以后，必须丢弃；若不等，说明结果里该值最多出现一次，可以安全地追加。

**算法步骤：**

1. 若 `n <= 2`，任何值都不可能超过两次，直接返回 `n`。
2. `slow = 2`（前两个元素无条件保留，作为结果前缀的初始内容）。
3. `fast` 从 2 到 `n-1`：若 `nums[fast] != nums[slow-2]`，则 `nums[slow] = nums[fast]; slow++`。
4. 返回 `slow`。

**为什么正确：** 循环维护的不变量是「`nums[0..slow-1]` 恰好是 `nums[0..fast-1]` 的合法结果：每个值至多出现两次、保持非递减顺序」。考察 `nums[fast]`：

- 若 `nums[fast] == nums[slow-2]`：由于 `nums[0..slow-1]` 有序且 `nums[slow-1] >= nums[slow-2]`，而 `nums[fast]` 不小于结果前缀的最后一个值（原数组有序，且从前往后处理），只能有 `nums[slow-1] == nums[slow-2] == nums[fast]`，即结果里该值已经出现两次，丢弃它不变量保持；
- 若 `nums[fast] != nums[slow-2]`：结果里该值出现次数不超过 1 次，追加后也不会超过两次，且由于 `nums[fast] >= nums[slow-1]`，追加位置 `slow` 保持了非递减顺序。

另外 `slow <= fast` 恒成立（每轮 `slow` 至多自增 1，而 `fast` 前进一步），因此 `nums[slow] = nums[fast]` 不会覆盖尚未检查的元素。循环结束时 `slow` 即合法长度。

**时间复杂度：** O(n)，`fast` 遍历一次数组。

**空间复杂度：** O(1)，原地修改，只用常数个下标变量。

**易错点 / 边界情况：**

- `n <= 2` 必须提前返回 `n`。否则 `slow = 2` 在 `n < 2` 时已经超出数组长度，且任何情况下都会直接返回 2——对 `n = 0`、`n = 1` 都是错误答案（`n = 2` 恰好正确，不能因此省略判断）。
- 比较对象是 `nums[slow-2]` 而不是 `nums[slow-1]`：用后者只能实现「相邻不重复」，会把所有重复都删掉。
- 返回 `slow` 而非 `slow+1`：本题 `slow` 从一开始就表示「已保留个数」，与上一题的含义不同，切勿照搬上一题的 `+1`。
- 全部元素相同（如 `[2,2,2,2,2]`）应返回 2；只有两个元素时应全部保留。
- 数组有序这一前提不可省略，无序时连续出现的假设不成立。
- 一般化：若允许每个值最多出现 `k` 次，条件就变成 `nums[fast] != nums[slow-k]`，初始 `slow = min(k, n)`。

## Go 代码实现

```go
// removeDuplicates 原地删除有序数组中重复超过两次的元素，返回新数组长度
// 使用快慢指针，利用 nums[fast] != nums[slow-2] 判断是否允许保留
func removeDuplicates(nums []int) int {
    n := len(nums)
    if n <= 2 {
        return n
    }

    // slow 指向下一个可放置的位置，前两个元素无条件保留
    slow := 2
    // fast 从第 3 个元素开始遍历
    for fast := 2; fast < n; fast++ {
        // 如果当前元素不等于 slow-2 位置的元素，
        // 说明当前元素不会导致出现 3 次重复
        if nums[fast] != nums[slow-2] {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```
