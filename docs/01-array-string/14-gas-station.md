# 14. 加油站

## 题目描述

在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的汽车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 `gas` 和 `cost`，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 `-1`。如果存在解，则 **保证** 它是 **唯一** 的。

**示例 1：**

```
输入: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出: 3
解释:
从 3 号加油站(索引为 3 处)出发，可获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 4 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
开往 0 号加油站，此时油箱有 8 - 2 + 1 = 7 升汽油
开往 1 号加油站，此时油箱有 7 - 3 + 2 = 6 升汽油
开往 2 号加油站，此时油箱有 6 - 4 + 3 = 5 升汽油
开往 3 号加油站，你需要消耗 5 升汽油，正好足够你返回到 3 号加油站。
因此，3 可为起始索引。
```

**示例 2：**

```
输入: gas = [2,3,4], cost = [3,4,3]
输出: -1
解释:
你不能从 0 号或 1 号加油站出发，因为没有足够的汽油可以让你行驶到下一个加油站。
我们从 2 号加油站出发，可以获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 0 号加油站，此时油箱有 4 - 3 + 2 = 3 升汽油
开往 1 号加油站，此时油箱有 3 - 3 + 3 = 3 升汽油
你无法返回 2 号加油站，因为返程需要消耗 4 升汽油，但是你的油箱只有 3 升汽油。
因此，无论怎样，你都不可能绕环路行驶一周。
```

**约束条件：**

- `n == gas.length == cost.length`
- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`

## 题目分析

**算法思路：** 使用贪心算法。核心思路：如果从 A 出发无法到达 B，那么 A 和 B 之间的任何加油站都无法到达 B（因为在 A 和 B 之间出发汽油更少）。

具体步骤：
1. 计算总汽油量 `totalGas` 和总消耗量 `totalCost`，如果 `totalGas < totalCost`，返回 `-1`
2. 从 0 开始遍历，维护当前油箱 `tank`。当 `tank < 0` 时，说明从当前起点出发无法到达当前加油站，将起点设为下一个加油站并将油箱清零
3. 遍历结束后返回起点即可

**时间复杂度：** O(n)，一次遍历。

**空间复杂度：** O(1)。

## Go 代码实现

```go
// canCompleteCircuit 找到可以绕环路行驶一周的起始加油站编号
// 贪心策略：如果从某站出发到不了下一站，则中间的站作为起点也不行
func canCompleteCircuit(gas []int, cost []int) int {
    n := len(gas)
    // totalGas 和 totalCost 用于判断是否存在解
    totalGas, totalCost := 0, 0
    for i := 0; i < n; i++ {
        totalGas += gas[i]
        totalCost += cost[i]
    }
    // 总汽油量小于总消耗量，不可能完成环路
    if totalGas < totalCost {
        return -1
    }

    // start 记录当前尝试的起点
    // tank 记录当前油箱中的汽油量
    start := 0
    tank := 0

    for i := 0; i < n; i++ {
        // 从当前加油站出发：加油，消耗到下一站
        tank += gas[i] - cost[i]
        // 如果油箱为负，说明从当前起点无法到达 i+1
        if tank < 0 {
            // 尝试从下一个加油站重新出发
            start = i + 1
            tank = 0
        }
    }

    return start
}
```
