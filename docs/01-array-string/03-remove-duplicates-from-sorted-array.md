# 3. 删除有序数组中的重复项

## 题目描述

给你一个 **非严格递增排列** 的数组 `nums`，请你 **原地** 删除重复出现的元素，使每个元素 **只出现一次**，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致**。然后返回 `nums` 中唯一元素的个数。

考虑 `nums` 的唯一元素的数量为 `k`，你需要做以下事情确保你的题解可以通过：

- 更改数组 `nums`，使 `nums` 的前 `k` 个元素包含唯一元素，并按照它们最初在 `nums` 中出现的顺序排列。`nums` 的其余元素与 `nums` 的大小无关。
- 返回 `k`。

**示例 1：**

```
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应该返回新的长度 2，并且原数组 nums 的前两个元素被修改为 1, 2。
不需要考虑数组中超出新长度后面的元素。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4]
解释：函数应该返回新的长度 5，并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4。
不需要考虑数组中超出新长度后面的元素。
```

**约束条件：**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` 已按非严格递增排列

## 题目分析

**算法思路：** 最直接的想法是用一个集合记录出现过的值，但那样需要 O(n) 额外空间，而题目要求原地。关键观察是：**数组已经有序，所以相同的元素必然相邻**。因此只要顺序扫描，把「和上一个已保留元素不同」的值留下即可，不需要记住全部历史。

用快慢指针实现：

- `slow` 指向最后一个已确认保留的元素下标，`nums[0..slow]` 就是当前去重后的结果前缀；
- `fast` 从 1 遍历到 `n-1`。

当 `nums[fast] != nums[slow]` 时，说明 `nums[fast]` 是一个新的、之前没出现过的值（因为有序，后面的元素只会更大或相等），把它写到 `slow+1` 处并令 `slow++`；否则说明 `nums[fast]` 与当前保留的最后一个值相同，是重复项，直接跳过。

**算法步骤：**

1. 若 `n == 0` 直接返回 0（约束下不会出现，属于防御性判断）。
2. `slow = 0`。
3. `fast` 从 1 到 `n-1`：若 `nums[fast] != nums[slow]`，则 `slow++; nums[slow] = nums[fast]`。
4. 返回 `slow + 1`。

**为什么正确：** 循环维护的不变量是「`nums[0..slow]` 恰好是 `nums[0..fast-1]` 中的所有不同值，且按首次出现的顺序排列」。`fast` 前进一位时：

- 若 `nums[fast] == nums[slow]`：`nums[slow]` 是已保留结果中的最大值（结果保持原序，故非递减），而由数组有序知 `nums[fast] >= nums[slow]`。又 `nums[fast]` 一旦大于结果中的最大值，就不可能已出现过，所以相等即表示该值已在结果中出现过，是重复项，跳过不变量保持；
- 若不等，则有 `nums[fast] > nums[slow]`，而所有更早的值都 `<= nums[slow]`，故 `nums[fast]` 是一个从未出现过的新值，把它写到 `slow+1` 处，结果仍按原序排列。

此外 `slow <= fast - 1 < fast` 恒成立，写到 `slow+1 <= fast` 的位置不会覆盖尚未检查的元素（最坏情况也只是自赋值）。循环结束时 `fast == n`，前缀即全部不同值，长度为 `slow+1`。

**时间复杂度：** O(n)，`fast` 遍历一次数组。

**空间复杂度：** O(1)，只用两个下标变量，原地修改。

**易错点 / 边界情况：**

- 返回值是 `slow + 1` 而不是 `slow`，这是最典型的一处差一错误。
- 单元素数组 `[1]`：`fast` 从 1 开始，循环不执行，返回 1，正确。
- 数组全部相同：返回 1，且 `nums[0]` 保持不变。
- 判断必须写成 `nums[fast] != nums[slow]` 而不是 `nums[fast] != nums[fast-1]`。两者在本题中恰好等价（因为 `nums[slow]` 就是上一个保留值），但用 `slow` 的写法更能体现「与已保留结果比较」的语义，也便于迁移到「最多保留两次」的变体。
- 不需要额外判断数组越界；`fast` 从 1 起步已隐含处理了 `n >= 1` 的情况。
- 不要用额外的 map/set 去重，那样空间复杂度会变成 O(n)，不满足要求。

## Go 代码实现

```go
// removeDuplicates 原地删除有序数组中的重复项，返回新数组长度
// 使用快慢指针，利用数组有序的特性
func removeDuplicates(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }

    // slow 指向最后一个不重复元素的位置
    slow := 0
    // fast 遍历数组，寻找新的不重复元素
    for fast := 1; fast < n; fast++ {
        if nums[fast] != nums[slow] {
            // 发现新的不重复元素，放置到 slow+1 位置
            slow++
            nums[slow] = nums[fast]
        }
    }
    // slow 是索引，长度需要 +1
    return slow + 1
}
```
