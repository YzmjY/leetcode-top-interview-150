# 20. 最长公共前缀

## 题目描述

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

**示例 1：**

```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

**示例 2：**

```
输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。
```

**约束条件：**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 题目分析

**算法思路：** 纵向扫描法。以第一个字符串为基准，逐个字符与其余所有字符串在相同位置的字符比较。如果某个位置不匹配，或者某个字符串长度不够，则返回当前已匹配的前缀。

**算法步骤：**

1. 若 `strs` 为空，返回 `""`（防御性处理）。
2. 取 `first = strs[0]`，令 `i = 0, 1, …` 依次枚举 `first` 的每个下标。
3. 对每个 `i`，与 `strs[1..]` 的第 `i` 个字符比较：若 `i >= len(strs[j])`（该串更短）或 `strs[j][i] != first[i]`，说明公共前缀到 `i` 为止，立即返回 `first[:i]`。
4. 若所有字符串都通过了全部下标的比较，说明 `first` 本身就是公共前缀，返回 `first`。

**为什么正确：**

任何公共前缀都必须是 `strs[0]` 的前缀，所以答案一定是某个 `first[:k]`。算法按 `i` 递增的顺序检查"所有字符串的第 `i` 位是否都等于 `first[i]`"：只要前 `i` 位全部通过，`first[:i]` 就是一个公共前缀。一旦在位置 `i` 上出现不匹配或长度不足，长度大于 `i` 的前缀都不可能成立，因此 `first[:i]` 恰好是最长的公共前缀，不会多也不会少。

**时间复杂度：** O(S)，其中 S 是所有字符串的字符总数。最坏情况是所有字符串完全相同，此时每个字符恰好被检查一次；更紧的上界是 O(n·L)，L 为最短字符串长度，同样不超过 S。

**空间复杂度：** O(1)。只用常数个下标变量；返回的 `first[:i]` 是原字符串的切片，与 `first` 共享底层数组，不产生新的字符存储。

**易错点 / 边界情况：**

- 需要 `len(strs) == 0` 的防御分支，否则取 `strs[0]` 会越界（题目约束下不会出现空数组）。
- 判断顺序必须先检查 `i >= len(strs[j])` 再访问 `strs[j][i]`，否则遇到更短的字符串会越界 panic。
- 数组中含空串时答案应为 `""`：若 `first` 为空串，外层循环不执行直接返回 `""`；若 `first` 非空而某个元素为空，会在 `i = 0` 处因长度不足返回 `""`。
- 不匹配时要返回 `first[:i]` 而不是 `first`。
- 边界用例：只有一个字符串、数组含空串、首串恰好是公共前缀、200 个长度为 200 的串。

## Go 代码实现

```go
// longestCommonPrefix 查找字符串数组中的最长公共前缀
// 使用纵向扫描，逐字符比较
func longestCommonPrefix(strs []string) string {
    if len(strs) == 0 {
        return ""
    }

    // 以第一个字符串为基准
    first := strs[0]
    // 遍历第一个字符串的每个字符
    for i := 0; i < len(first); i++ {
        ch := first[i]
        // 与其余每个字符串的同一位置比较
        for j := 1; j < len(strs); j++ {
            // 如果超出长度或字符不匹配，返回当前前缀
            if i >= len(strs[j]) || strs[j][i] != ch {
                return first[:i]
            }
        }
    }

    // 第一个字符串全部匹配，它就是最长公共前缀
    return first
}
```
