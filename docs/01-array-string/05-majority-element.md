# 5. 多数元素

## 题目描述

给定一个大小为 `n` 的数组 `nums`，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `n / 2` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**约束条件：**

- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 题目分析

**算法思路：** 最直接的做法是排序后取中位数，或哈希计数取出现次数超过 `n/2` 的值，但前者 O(n log n)、后者 O(n) 空间。进阶要求 O(n) 时间、O(1) 空间，于是考虑**在线抵消**：把多数元素看作「正方」，其余元素看作「反方」，每次让一个正方和一个反方同归于尽。由于多数元素的数量严格超过其余元素的总和，即使其他所有元素都联合起来抵消它，最后也必然至少剩下一个多数元素。这就是 Boyer-Moore 摩尔投票算法。

维护两个变量：候选元素 `candidate` 和计数器 `count`。

**算法步骤：**

1. 初始化 `candidate = 0`、`count = 0`。
2. 遍历数组中的每个元素 `num`：
   - 若 `count == 0`，说明此前所有候选人都已被完全抵消，令 `candidate = num`；
   - 若 `num == candidate`，`count++`（为候选人投赞成票）；否则 `count--`（投反对票，互相抵消）。
3. 遍历结束后 `candidate` 即为多数元素。

**为什么正确：** 用不变量来论证。对已处理的前缀做如下操作：反复删除其中任意一对**值不同**的元素，直到剩下的元素全部相同。由于删除两个不同的值不改变「谁的数量最多」，最终剩下的元素是什么、剩几个，与删除顺序无关。

循环维护的不变量是：**处理完前 `i` 个元素后，把它们的值两两抵消（每次消去一对不同的值）直到不能再消，剩下的元素全部等于 `candidate`，且剩下 `count` 个。**

归纳验证：

- `count == 0` 时遇到 `num`：此前前缀已能完全抵消殆尽，加入 `num` 后只剩它一个，于是令 `candidate = num`、`count = 1`，不变量成立；
- `num == candidate`：新增一个与剩余元素同值的元素，抵消后剩余数量 +1，`count++` 正确；
- `num != candidate`：新增元素与剩余的一个 `candidate` 配对消去，剩余数量 -1 且仍全为 `candidate`，`count--` 正确（`count > 0` 时必有剩余可消）。

由于多数元素 `x` 出现 `c` 次、满足 `c > n - c`，把其余 `n - c` 个元素全部用来与 `x` 配对也只能消掉 `n - c` 个，还剩 `c - (n - c) > 0` 个 `x`；由「结果与抵消顺序无关」，最终剩余的必然是 `x`（若剩余的是别的值，把 `x` 全部消完是不可能的），即 `candidate == x`。题目保证多数元素存在，因此**不需要**第二遍遍历去验证候选人的真实出现次数（若题目不保证，则必须补一遍计数校验，因为 `candidate` 可能只是「众数」的候选而非真正的多数元素）。

**时间复杂度：** O(n)，只遍历一次数组，每次迭代做常数次操作。

**空间复杂度：** O(1)，只用了 `candidate` 和 `count` 两个变量。

**易错点 / 边界情况：**

- `count == 0` 的判断必须放在比较之前，否则会先执行 `count--` 变成负数。正确顺序是「先决定是否换候选人，再比较计数」。
- 单元素数组 `[5]` 返回 5：`count == 0`，候选人设为 5，随后 `count++`。
- 当题目**不保证**多数元素存在时，这套算法只会给出「最可能的候选」，必须再遍历一遍统计 `candidate` 的实际出现次数，超过 `n/2` 才返回，否则返回 -1。本代码因题目保证存在而省略了这步。
- 初始 `candidate` 取 0 只是一个占位值，不影响结果，因为第一次循环 `count == 0` 会立即覆盖它。
- 不要把 `count` 理解为「候选人出现次数」，它是净胜票数，这是理解该算法的关键。

## Go 代码实现

```go
// majorityElement 使用摩尔投票算法找出数组中的多数元素
// 多数元素是指在数组中出现次数大于 n/2 的元素
func majorityElement(nums []int) int {
    // candidate 为候选多数元素，count 为计数器
    candidate := 0
    count := 0

    for _, num := range nums {
        // 当计数器为 0 时，重新选举候选元素
        if count == 0 {
            candidate = num
        }
        // 如果当前元素等于候选元素，增加计数；否则减少计数
        if num == candidate {
            count++
        } else {
            count--
        }
    }

    // 由于题目保证一定存在多数元素，直接返回 candidate
    return candidate
}
```
