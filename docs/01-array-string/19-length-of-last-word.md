# 19. 最后一个单词的长度

## 题目描述

给你一个字符串 `s`，由若干单词组成，单词前后用一些空格字符隔开。返回字符串中 **最后一个** 单词的长度。

**单词** 是指仅由字母组成、不包含任何空格字符的最大子字符串。

**示例 1：**

```
输入：s = "Hello World"
输出：5
解释：最后一个单词是"World"，长度为 5。
```

**示例 2：**

```
输入：s = "   fly me   to   the moon  "
输出：4
解释：最后一个单词是"moon"，长度为 4。
```

**示例 3：**

```
输入：s = "luffy is still joyboy"
输出：6
解释：最后一个单词是长度为 6 的"joyboy"。
```

**约束条件：**

- `1 <= s.length <= 10^4`
- `s` 仅有英文字母和空格 `' '` 组成
- `s` 中至少存在一个单词

## 题目分析

**算法思路：** 从字符串末尾向前遍历。首先跳过末尾的空格，然后从第一个非空格字符开始计数，直到遇到空格或到达字符串开头为止。

**算法步骤：**

1. 令 `index = len(s) - 1`、`length = 0`。
2. 第一个循环：只要 `index >= 0 && s[index] == ' '` 就 `index--`，跳过尾随空格。
3. 第二个循环：只要 `index >= 0 && s[index] != ' '` 就 `length++`、`index--`，统计最后一个单词的字符数。
4. 返回 `length`。

**为什么正确：**

第一个循环结束后，`index` 指向最后一个非空格字符，也就是最后一个单词的最后一个字母（题目保证至少有一个单词，因此该字符必定存在）。第二个循环从右向左连续计数，遇到空格（单词的左边界）或下标越界（单词延伸到串首）立即停止。由于"单词"定义为不含空格的最大连续子串，这段连续的非空格字符恰好就是题目要找的最后一个单词，计数值即其长度。整个过程只读取字符、不修改输入。

**时间复杂度：** O(n)，最坏情况（整串只有一个单词）遍历整个字符串；每个字符至多被两个循环之一访问一次。

**空间复杂度：** O(1)，只用两个整型变量。

**易错点 / 边界情况：**

- 两个循环都必须带 `index >= 0` 条件，否则纯空格串会越界（虽然约束保证至少有一个单词，防御性条件仍不可省）。
- 尾随空格可能不止一个（示例 2 末尾有两个），必须循环跳过，不能只 `index--` 一次。
- 单词之间可能有多余空格，但第二个循环一遇到空格就停止计数，不受影响。
- 边界用例：`"a"`、`" a"`、`"a "`、`"    a    "`、整个串只有一个单词、长度为 10⁴ 的输入。

## Go 代码实现

```go
// lengthOfLastWord 返回字符串中最后一个单词的长度
// 从后向前遍历，跳过末尾空格后开始计数
func lengthOfLastWord(s string) int {
    // index 从字符串末尾开始
    index := len(s) - 1
    length := 0

    // 跳过末尾的空格
    for index >= 0 && s[index] == ' ' {
        index--
    }

    // 从最后一个单词的末尾向前计数，直到遇到空格
    for index >= 0 && s[index] != ' ' {
        length++
        index--
    }

    return length
}
```
