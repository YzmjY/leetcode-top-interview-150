# 13. 除自身以外数组的乘积

## 题目描述

给你一个整数数组 `nums`，返回 数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。

题目数据 **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内。

请 **不要使用除法**，且在 `O(n)` 时间复杂度内完成此题。

**示例 1：**

```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
```

**示例 2：**

```
输入: nums = [-1,1,0,-3,3]
输出: [0,0,9,0,0]
```

**约束条件：**

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- **保证** 数组 `nums` 之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内

**进阶：** 你可以在 `O(1)` 的额外空间复杂度内完成这个题目吗？（出于对空间复杂度分析的目的，输出数组 **不被视为** 额外空间。）

## 题目分析

**算法思路：** 对每个位置都重新累乘其余元素是 O(n²)，不可取。观察 `answer[i]` 的构成：它等于「`i` 左侧所有元素的乘积」乘上「`i` 右侧所有元素的乘积」，而这两部分分别可以用一次前缀扫描和一次后缀扫描求出。更进一步，题目允许把输出数组当作工作空间：先把前缀积直接写进 `answer`，再用一个变量滚动保存后缀积乘回 `answer[i]`，额外空间就降到了 O(1)。

**算法步骤：**

1. 第一次从左到右计算前缀积：`answer[0] = 1`（位置 0 左侧没有元素，空前缀积为 1）；对 `i = 1..n-1`，`answer[i] = answer[i-1] * nums[i-1]`。此时 `answer[i] = nums[0] * ... * nums[i-1]`。
2. 第二次从右到左计算后缀积：用一个变量 `suffix` 存储右侧乘积，初始 `suffix = 1`（位置 n-1 右侧没有元素）；对 `i = n-1..0`，先 `answer[i] *= suffix`，再 `suffix *= nums[i]`。
3. 返回 `answer`。

**为什么正确（循环不变量）：** 第二次遍历保持不变量——处理下标 `i` 之前，`suffix == nums[i+1] * ... * nums[n-1]`。初始 `i = n-1` 时后缀为空，空积为 1，成立；每轮结束后把 `suffix` 乘上 `nums[i]`，于是下一轮处理 `i-1` 时它正好等于 `nums[i] * ... * nums[n-1]`，不变量得证。因此 `answer[i] = (nums[0]*...*nums[i-1]) * (nums[i+1]*...*nums[n-1])`，恰是「除自身外所有元素的乘积」。整个过程没有使用除法，天然规避了元素为 0 时的除零问题。

**时间复杂度：** O(n)，两次线性遍历，每次 O(1) 工作。

**空间复杂度：** O(1) 额外空间（输出数组不计入），除返回的 `answer` 外只用了一个 `suffix` 变量。

**易错点：**

- 第二次遍历中「先乘 `suffix`，再更新 `suffix`」的顺序不能颠倒，否则 `answer[i]` 会把自己也乘进去。
- `answer[0]` 要初始化为 1，`suffix` 也要从 1 开始；写成 0 会让整行结果全为 0。
- 数组中的 0 不需要特判：前缀积/后缀积会自然传播 0，结果仍然正确（如 `[-1,1,0,-3,3]` 得到 `[0,0,9,0,0]`）。
- 题目保证任意前缀积与后缀积都在 32 位整数范围内，所以用 `int` 即可，但不要用更窄的类型存放中间结果。
- 约束保证 `n >= 2`，因此不必特判单元素数组；代码中 `answer[0]` 之后总有元素可写。

## Go 代码实现

```go
// productExceptSelf 计算除自身以外数组的乘积
// 使用前缀积 + 后缀积，两次遍历
func productExceptSelf(nums []int) []int {
    n := len(nums)
    // answer 数组先用于存储前缀积，最终存储结果
    answer := make([]int, n)

    // 第一次遍历：计算前缀积
    // answer[i] = nums[0] * nums[1] * ... * nums[i-1]
    answer[0] = 1 // 索引 0 左侧没有元素，前缀积为 1
    for i := 1; i < n; i++ {
        answer[i] = answer[i-1] * nums[i-1]
    }

    // 第二次遍历：乘以后缀积
    // suffix 记录 nums[i+1] * ... * nums[n-1]
    suffix := 1 // 索引 n-1 右侧没有元素，后缀积为 1
    for i := n - 1; i >= 0; i-- {
        answer[i] *= suffix
        suffix *= nums[i]
    }

    return answer
}
```
