# 第三章：滑动窗口

## 数据结构与算法背景

滑动窗口（Sliding Window）是一种在数组或字符串上维护一个可变大小窗口的算法技巧。它本质上是对暴力枚举的优化，通过避免重复计算来降低时间复杂度。

### 常见题型

1. **定长窗口**：窗口大小固定，只需维护窗口内的统计信息
2. **变长窗口**：窗口大小可变，通常需要满足某个条件（如和 >= target、无重复字符等）
3. **最小覆盖子串**：寻找覆盖目标的最小子串，通常结合哈希表统计字符频率

### 解题关键

- 明确窗口的扩张条件和收缩条件
- 使用哈希表或数组维护窗口内的字符/元素统计
- 双指针：`left` 收缩窗口，`right` 扩张窗口
- 常见框架：`for right < n { 加入nums[right]; while(条件满足) { 更新结果; 移除nums[left]; left++ } right++ }`
