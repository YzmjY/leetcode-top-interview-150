# 149. 买卖股票的最佳时机 IV (Best Time to Buy and Sell Stock IV)

## 题目描述

给你一个整数数组 `prices` 和一个整数 `k`，其中 `prices[i]` 是某支给定的股票在第 `i` 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 `k` 笔交易。也就是说，你最多可以买 `k` 次，卖 `k` 次。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**

```
输入：k = 2, prices = [2,4,1]
输出：2
解释：在第 1 天 (股票价格 = 2) 的时候买入，在第 2 天 (股票价格 = 4) 的时候卖出，这笔交易所能获得利润 = 4-2 = 2 。
```

**示例 2：**

```
输入：k = 2, prices = [3,2,6,5,0,3]
输出：7
解释：在第 2 天 (股票价格 = 2) 的时候买入，在第 3 天 (股票价格 = 6) 的时候卖出, 这笔交易所能获得利润 = 6-2 = 4 。
     随后，在第 5 天 (股票价格 = 0) 的时候买入，在第 6 天 (股票价格 = 3) 的时候卖出, 这笔交易所能获得利润 = 3-0 = 3 。
```

**约束条件：**

- `1 <= k <= 100`
- `1 <= prices.length <= 1000`
- `0 <= prices[i] <= 1000`

## 题目分析

### 算法思路

**关键观察。** 把第 148 题（最多 2 笔）的四状态状态机直接推广：把「第几笔交易」变成数组下标 `j`，
`buy[j]` / `sell[j]` 分别表示「完成第 `j` 次买入 / 第 `j` 次卖出后」能获得的最大利润。
每天用当天的价格 `p` 把 `j = 1..k` 全部更新一遍：

- `buy[j] = max(buy[j], sell[j-1] - p)`：第 `j` 次买入必须发生在第 `j-1` 次卖出之后，
  所以从「已完成 `j-1` 笔」的空仓状态 `sell[j-1]` 转移，花费 `p`；
- `sell[j] = max(sell[j], buy[j] + p)`：在第 `j` 次买入的状态上卖出，赚 `p`。

**初始值**：`sell[j] = 0`（「一笔都不做」始终合法，也充当 `sell[0]` 的角色）；
`buy[j] = -∞`（代码用 `math.MinInt32`），表示还没买入时不能直接卖出。
**答案**：`sell[k]`（`sell[j]` 关于 `j` 单调不减，取 `j = k` 即为最优）。

**为什么正确。** 与 148 相同，转移式是「按当天动作分类」的结果：`sell[j]` 的最优值要么来自更早的某个卖出日
（保持），要么今天就是第 `j` 次卖出的日子（由 `buy[j] + p` 转移）；`buy[j]` 同理。
每天按 `j` 从 1 到 `k`、且每个 `j` 内先 `buy` 后 `sell` 的顺序更新，使得同一天可以先卖后买
（`sell[j-1]` 已是当天的新值），这与题目允许的「卖出当天再买入」一致；
当日买卖收益为 0，不会虚增利润。对天数和交易次数归纳，遍历结束后 `sell[k]` 即为「最多 `k` 笔」的最优解。

**k 很大时的退化处理。** `n` 天内真正有意义的交易笔数不超过 `⌊n/2⌋`：把价格序列按极大非递减段切分，
每段用一次交易「段首买、段尾卖」即可拿到该段全部涨幅，而每个盈利段的长度至少为 2 且各段互不重叠，
所以最多 `⌊n/2⌋` 笔就能达到「交易次数不限」的最优解。因此当 `k >= n/2` 时，问题退化为第 122 题
（买卖股票 II），用贪心在 O(n) 内解决：**累加所有 `prices[i] > prices[i-1]` 的正差值**。
代码里的 `if k >= n/2 { ... }` 就是这个剪枝。

贪心的正确性：一次「先买后卖」的收益可以拆成相邻交易日价差之和，
上涨日的每个正差值都恰好被计入一次；反过来，每个正差值都对应「昨天买、今天卖」这一动作
（相邻动作可以拼成更长的交易），所以贪心值是可达的上界，即为最优。

### 复杂度分析

- **时间复杂度**：O(n·min(k, ⌊n/2⌋))。`k >= n/2` 时退化到 O(n)；否则每天更新 `k` 个交易状态。
  在 k ≤ 100、n ≤ 1000 的约束下最多约 10⁵ 次内层操作。
- **空间复杂度**：O(k)，`buy`、`sell` 各一个长度 `k+1` 的数组。
- 数值范围：单次价格 ≤ 1000、最多 k ≤ 100 笔，利润上界约 10⁵，`int` 足够，不会溢出。

### 关键点

- `buy[j]` 必须初始化为 `-∞`（`math.MinInt32`）而不是 0：买入态用 0 初始化等于「白赚」，答案会偏大。
- `sell[0] = 0` 是转移的关键：它表示「第一次买入之前的空仓状态」，让 `buy[1] = max(-∞, 0 - p) = -p`。
- 内层循环顺序（`j` 递增、每个 `j` 先 `buy` 后 `sell`）使同一天可以先卖出再买入，与题目规则一致
  （与 148 同类：即使改成「卖出后隔天才买」，最优值也不变）。
- 大 `k` 的退化阈值是 `k >= n/2`（`n` 为天数），前提是 `n` 天内最多完成 `⌊n/2⌋` 笔有意义的交易。
- 「最多 `k` 笔」允许不足 `k` 笔：`sell[j]` 初值 0 已隐含「不交易」，无需凑满。
- 边界：只有一天、或价格单调下跌时答案为 0；代码里的 `n == 0 || k == 0` 是防御性分支
  （按约束 `k >= 1`、`n >= 1`，实际不会触发）。
- 本题是股票系列的通用模板：令 `k = 1` 得到第 121 题，`k = 2` 得到第 148 题，
  `k >= n/2` 退化为第 122 题。

## Go 代码实现

```go
package main

import "math"

func maxProfit(k int, prices []int) int {
    n := len(prices)
    if n == 0 || k == 0 {
        return 0
    }

    // 如果 k 大于 n/2，相当于可以无限交易（Stock II）
    if k >= n/2 {
        maxProfit := 0
        for i := 1; i < n; i++ {
            if prices[i] > prices[i-1] {
                maxProfit += prices[i] - prices[i-1]
            }
        }
        return maxProfit
    }

    // 初始化 buy 和 sell 数组
    buy := make([]int, k+1)
    sell := make([]int, k+1)
    for i := 0; i <= k; i++ {
        buy[i] = math.MinInt32
    }

    for _, price := range prices {
        for j := 1; j <= k; j++ {
            buy[j] = max(buy[j], sell[j-1]-price)
            sell[j] = max(sell[j], buy[j]+price)
        }
    }

    return sell[k]
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```
