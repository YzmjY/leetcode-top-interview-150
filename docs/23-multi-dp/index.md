# 第23章 多维动态规划 (Multi-dimensional Dynamic Programming)

## 章节概述

多维动态规划是一维 DP 的扩展，适用于需要多个维度来描述状态的复杂问题。本章涵盖了 LeetCode 面试中最常见的多维 DP 题型，包括网格 DP、字符串 DP 和股票 DP 等。

## 常见多维 DP 题型

### 1. 网格 DP (Grid DP)

状态用二维数组 `dp[i][j]` 表示到达网格位置 `(i, j)` 的最优解。

- **三角形最小路径和**：从上到下逐层递推，注意边界处理。
- **最小路径和**：`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`
- **不同路径 II**：处理障碍物，`dp[i][j] = dp[i-1][j] + dp[i][j-1]`（无障碍时）。
- **最大正方形**：`dp[i][j]` 表示以 `(i, j)` 为右下角的最大正方形边长。

### 2. 字符串 DP (String DP)

状态通常涉及两个字符串的索引，是经典的"双序列"问题。

- **最长回文子串**：中心扩展法或二维 DP（`dp[i][j]` 表示 `s[i:j]` 是否为回文）。
- **交错字符串**：`dp[i][j]` 表示 s1 的前 i 个字符与 s2 的前 j 个字符能否交错组成 s3 的前 i+j 个字符。
- **编辑距离**：`dp[i][j]` 表示 word1 的前 i 个字符转换为 word2 的前 j 个字符的最少操作数。

### 3. 股票 DP (Stock DP)

股票买卖问题通常需要多维状态来表示持有/不持有股票、交易次数等。

- **买卖股票的最佳时机 III**：最多 2 笔交易，需记录 `(天, 交易次数, 是否持有)` 三维状态。
- **买卖股票的最佳时机 IV**：最多 k 笔交易，是 III 的泛化版本。

## 核心技巧

1. **状态维度的选择**：根据问题的约束选择恰当的状态维度，常见维度包括索引、长度、计数、是否持有等。
2. **空间优化**：多维 DP 通常可以降维（如二维 -> 一维，使用滚动数组）。
3. **初始化**：多维 DP 的初始化更为复杂，尤其注意首行、首列和边界情况。
4. **遍历顺序**：根据状态依赖关系确定正确的遍历顺序（如行优先、对角线等）。

## 复杂度速查

- 三角形最小路径和：时间 O(n^2)，空间 O(n^2) 或 O(n)（空间优化）
- 最小路径和：时间 O(mn)，空间 O(mn) 或 O(n)；直接在 `grid` 上原地递推可做到 O(1) 额外空间（本仓库代码即此写法）
- 不同路径 II：时间 O(mn)，空间 O(mn) 或 O(n)
- 最长回文子串：时间 O(n^2)（DP）/ O(n^2)（中心扩展），空间 O(n^2) / O(1)
- 交错字符串：时间 O(mn)，空间 O(mn) 或 O(n)
- 编辑距离：时间 O(mn)，空间 O(mn) 或 O(n)
- 买卖股票 III：时间 O(n)，空间 O(1)
- 买卖股票 IV：时间 O(nk)，空间 O(k)
- 最大正方形：时间 O(mn)，空间 O(mn) 或 O(n)
