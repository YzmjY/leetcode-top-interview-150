# 145. 最长回文子串 (Longest Palindromic Substring)

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

如果字符串的反序与原始字符串相同，则该字符串称为回文字符串。

**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```

**约束条件：**

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 题目分析

### 算法思路

**关键观察。** 暴力做法是枚举全部 O(n²) 个子串、每个再花 O(n) 判断是否回文，总复杂度 O(n³)。
要优化，需要换一个角度：回文串有一个很强的结构特征 —— **它由中心唯一确定**。
一个回文的中心要么是某个字符（奇数长度），要么是相邻两字符之间的空隙（偶数长度），
一共 `2n-1` 个中心。从中心向两侧对称扩展，遇到不相等的字符就必须停下（再往外不可能还是回文）。
于是对每个中心扩展一次，就能把所有回文串都「枚举」出来。

**方法一：中心扩展法（推荐，也是下方 Go 代码的做法）**

1. 对每个下标 `i`，分别以 `(i, i)`（奇数长度中心）和 `(i, i+1)`（偶数长度中心）为中心做扩展；
2. `expandAroundCenter` 在 `s[left] == s[right]` 时不断 `left--; right++`，越界或字符不等时停止；
   退出循环时 `left`/`right` 已经多走了一步，返回前要回退，返回 `left+1, right-1`（即最后一对合法边界）；
3. 由边界算出长度 `r-l+1`（当 `l > r` 时长度为 0，表示该中心没有回文），与当前最优比较并更新起点与长度；
4. 遍历结束返回 `s[start : start+maxLen]`。

**为什么正确。** 任意回文子串 `s[l..r]` 都对应一个中心：`r-l` 为偶数时中心是字符 `(l+r)/2`，
为奇数时中心是空隙 `((l+r)/2, (l+r)/2+1)`。以该中心扩展时，在到达 `l`、`r` 之前不会停下——
因为 `s[l..r]` 是回文，所有对称位置都相等。所以该中心至少能产出长度 `r-l+1` 的回文，
算法不会漏掉任何回文串；反过来扩展产生的每个结果都是真正的回文串，也不会多算。
既然所有回文串都被某个中心覆盖，取长度最大者就是答案。

**方法二：区间 DP（本页交互演示所用的方法）**

- **状态定义**：`dp[i][j]` = `s[i..j]` 是否为回文子串（只用到 `j >= i` 的上三角）。
- **状态转移**：`dp[i][j] = (s[i] == s[j]) && (j-i < 3 || dp[i+1][j-1])`。
  两端字符必须相等；若长度 ≤ 3（`j-i < 3`），中间至多一个字符，必然回文；否则要求内部子串 `s[i+1..j-1]` 是回文。
- **遍历顺序**：转移依赖更短的区间 `dp[i+1][j-1]`，所以按**子串长度从小到大**枚举（长度 1 → 2 → 3 …）。
  等价地，按 `i` 从大到小、`j` 从小到大枚举也可以，本质是同一个拓扑序。
- **答案**：所有 `dp[i][j] == true` 中 `j-i` 最大者。

### 复杂度分析

**中心扩展法（Go 代码）：**
- 时间复杂度：O(n²)。共 `2n-1` 个中心，每个中心最多向外扩展 O(n) 步。
- 空间复杂度：O(1)，只用若干个下标变量。

**区间 DP（交互演示）：**
- 时间复杂度：O(n²)，填充约 `n²/2` 个状态，每次转移 O(1)。
- 空间复杂度：O(n²)。

### 关键点

- 中心共有 **`2n-1`** 个（n 个单字符中心 + n-1 个空隙中心），漏掉偶数中心会错失 `"bb"` 这类答案。
- `expandAroundCenter` 返回的是「回退后」的边界；写成 `return left, right` 会把最后一对不匹配（甚至越界）的
  下标也算进去，是最典型的差一错误。
- 长度计算公式是 `r-l+1`，别写成 `r-l`。
- 题目允许多个等长答案（如 `"babad"` 返回 `"bab"` 或 `"aba"` 都可以），代码保留先遇到的更优者。
- 边界：`len(s) < 2` 时直接返回 `s`（空串返回空串，单字符返回自身）。
- 题目保证 `s` 只含数字和英文字母，按字节处理即可，不存在多字节字符被切坏的问题。
- 两种方法对比：中心扩展空间 O(1)、常数更小，更实用；区间 DP 空间 O(n²)，但能顺带回答
  「任意区间是否回文」的查询，适合作为区间 DP 的入门练习。
- 本页交互演示展示的是**方法二（区间 DP）**的填表过程，Go 代码实现的则是**方法一（中心扩展）**，两者结果一致。

## Go 代码实现

```go
package main

func longestPalindrome(s string) string {
    if len(s) < 2 {
        return s
    }

    start, maxLen := 0, 0

    for i := 0; i < len(s); i++ {
        // 奇数长度回文（单中心）
        l1, r1 := expandAroundCenter(s, i, i)
        // 偶数长度回文（双中心）
        l2, r2 := expandAroundCenter(s, i, i+1)

        // r-l+1 才是回文子串的长度（l > r 时长度为 0）
        if length := r1 - l1 + 1; length > maxLen {
            start, maxLen = l1, length
        }
        if length := r2 - l2 + 1; length > maxLen {
            start, maxLen = l2, length
        }
    }

    return s[start : start+maxLen]
}

// expandAroundCenter 从中心向两边扩展，返回回文子串的左右边界索引
func expandAroundCenter(s string, left, right int) (int, int) {
    for left >= 0 && right < len(s) && s[left] == s[right] {
        left--
        right++
    }
    // 退出循环时 left 和 right 多走了一步，回退
    return left + 1, right - 1
}
```
