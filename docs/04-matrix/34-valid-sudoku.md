# 34. 有效的数独

## 题目描述

请你判断一个 `9 x 9` 的数独是否有效。只需要 **根据以下规则**，验证已经填入的数字是否有效即可。

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。（请参考示例图）

**注意：**
- 一个有效的数独（部分已被填充）不一定是可解的。
- 只需要根据以上规则，验证已经填入的数字是否有效即可。
- 空白格用 `'.'` 表示。

**示例 1：**

```
输入：board =
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

**示例 2：**

```
输入：board =
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：除了第一行的第一个数字从 5 改为 8 以外，空格内其他数字均与示例1相同。
但由于位于左上角的 3x3 宫内有两个 8 存在，因此这个数独是无效的。
```

**约束条件：**

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是一位数字（`1-9`）或者 `'.'`

## 题目分析

**算法思路：** 题目要同时校验「行、列、3x3 宫」三类约束，而每一类约束本质上都是「同一组内数字不能重复」。最直接的做法是为每条行、每条列、每个宫各维护一个集合；由于数字只有 `1-9`，可以用布尔数组代替集合，把数字减一后作为下标，得到 O(1) 的查重。关键观察是：三类约束彼此独立，读到某个数字时一次性检查它所属的行、列、宫三处即可，不需要额外结构。

**算法步骤：**

1. 建立三个 `9 x 9` 布尔数组 `rows`、`cols`、`boxes`，其中 `rows[i][d]` 表示第 `i` 行是否已出现数字 `d+1`（用 `0-8` 编码 `1-9`）。
2. 从上到下、从左到右遍历每个格子 `(i, j)`。
3. 遇到 `'.'` 直接跳过，空格不参与任何约束。
4. 计算数字索引 `num = board[i][j] - '1'`，以及所属宫 `boxIdx = (i/3)*3 + j/3`。
5. 若 `rows[i][num] || cols[j][num] || boxes[boxIdx][num]` 任一为真，说明该数字在行、列或宫中重复，立即返回 `false`。
6. 否则把三处对应位置都置为 `true`，继续扫描。
7. 全部格子扫描完仍未冲突，返回 `true`。

**为什么正确：** 循环维护的不变量是「已扫描过的格子互相之间在行、列、宫三个维度上都不冲突，且 `rows`、`cols`、`boxes` 精确记录了这些格子中每个数字的占用情况」。处理一个新数字时：若三处都没被占用，说明它与已扫描部分无冲突，标记后不变量保持；若任一处已被占用，说明存在两个同行/同列/同宫且数字相同的格子，违反规则，返回 `false` 正确。因此扫描结束仍未返回 `false`，说明整盘合法。

**小宫格索引计算：** 对于位置 `(i, j)`，其所属的 3x3 宫格索引为 `(i/3)*3 + (j/3)`（取值 `0-8`）。可以理解为把 9 个宫按行优先编号：行方向分 3 段、列方向分 3 段。

**时间复杂度：** O(1)，固定 9x9 棋盘，共 81 个格子，每格常数次操作。

**空间复杂度：** O(1)，三个 9x9 布尔数组大小固定。

**易错点 / 边界情况：**

- 数字转下标用 `ch - '1'`（得到 0-8），写成 `ch - '0'` 会让字符 `'9'` 算出下标 9 而数组越界。
- 宫索引是 `(i/3)*3 + j/3`，注意 `j/3` 前面不能再乘 3。
- 空格 `'.'` 必须跳过，不能当作数字参与标记。
- 顺序不能颠倒：必须先判断是否重复，通过后再标记；先标记会漏掉自身的重复判断。
- 三个数组互相独立，同一个数字可以在不同的行、列、宫中重复出现，只要不违反各自的约束。
- 题目只要求验证当前填充是否满足三条规则，不要求可解；一个合法但无解的局面应返回 `true`。
- 不需要为 `boxIdx` 单独做边界处理，`i`、`j` 在 `0-8` 内时它必然落在 `0-8`。

## Go 代码实现

```go
// isValidSudoku 判断 9x9 数独棋盘是否有效
// 使用三个布尔数组分别记录行、列、宫的占用情况
func isValidSudoku(board [][]byte) bool {
    // rows[i][num] 表示第 i 行是否已出现数字 num
    // cols[j][num] 表示第 j 列是否已出现数字 num
    // boxes[k][num] 表示第 k 个 3x3 宫是否已出现数字 num
    var rows, cols, boxes [9][9]bool

    for i := 0; i < 9; i++ {
        for j := 0; j < 9; j++ {
            ch := board[i][j]
            if ch == '.' {
                continue
            }

            // 将字符转为数字索引 (0-8)
            num := ch - '1'

            // 计算小宫格索引
            boxIdx := (i/3)*3 + j/3

            // 检查是否重复
            if rows[i][num] || cols[j][num] || boxes[boxIdx][num] {
                return false
            }

            // 标记为已出现
            rows[i][num] = true
            cols[j][num] = true
            boxes[boxIdx][num] = true
        }
    }

    return true
}
```
