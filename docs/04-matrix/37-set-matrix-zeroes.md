# 37. 矩阵置零

## 题目描述

给定一个 `m x n` 的矩阵，如果一个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。请使用 **原地** 算法。

**示例 1：**

```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]
```

**示例 2：**

```
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

**约束条件：**

- `m == matrix.length`
- `n == matrix[0].length`
- `1 <= m, n <= 200`
- `-2^31 <= matrix[i][j] <= 2^31 - 1`

**进阶：**

- 一个直观的解决方案是使用 `O(mn)` 的额外空间，但这并不是一个好的解决方案。
- 一个简单的改进方案是使用 `O(m + n)` 的额外空间，但这仍然不是最好的解决方案。
- 你能想出一个仅使用常量空间的解决方案吗？

## 题目分析

**算法思路：** 最直观的做法是先扫描一遍，把所有含 0 的行号和列号记录下来，再统一置零，这需要 O(m + n) 额外空间。题目要求常数空间，关键观察是：**矩阵的第一行和第一列本身就可以充当「行标记数组」和「列标记数组」**——令 `matrix[i][0] = 0` 表示第 `i` 行要清零，`matrix[0][j] = 0` 表示第 `j` 列要清零。这样标记信息就寄存在输入矩阵里，不需要额外数组。

唯一的问题是：第一行、第一列自身也可能含 0，如果不加区分，它们的原始状态会与「行/列需要清零」的标记混淆，也无法判断它们是否需要整体清零。解决办法是用两个布尔变量 `firstRowZero`、`firstColZero` 在改动之前把第一行、第一列的原始状态保存下来，最后单独处理它们。

**算法步骤：**

1. 用两个布尔变量 `firstRowZero`、`firstColZero` 记录第一行、第一列本身是否需要置零。
2. 遍历 `i >= 1, j >= 1` 的格子，若 `matrix[i][j] == 0`，则置 `matrix[i][0] = 0`（标记第 `i` 行）、`matrix[0][j] = 0`（标记第 `j` 列）。
3. 再次遍历 `i >= 1, j >= 1` 的格子，若 `matrix[i][0] == 0 || matrix[0][j] == 0`，则置 `matrix[i][j] = 0`。
4. 若 `firstRowZero`，把第一行全部置零；若 `firstColZero`，把第一列全部置零。

**为什么正确：** 第 2 步把「第 `i` 行含零」编码进 `matrix[i][0]`，把「第 `j` 列含零」编码进 `matrix[0][j]`；行标记全部落在第 0 列、列标记全部落在第 0 行，两类标记互不干扰，第一列自身是否需要清零则由 `firstColZero` 单独保存。第 3 步对 `i, j >= 1` 的每个格子判断：行标记为 0 表示该行含零，列标记为 0 表示该列含零，二者有一个成立就置零，恰好实现「含零行与含零列的并集置零」。第 4 步用第一步保存的原始状态处理第一行/第一列，避免了「第一行先被置零导致第一列判断被污染」的问题，因此不会漏判或误判。

**时间复杂度：** O(m * n)，共进行四次线性扫描，每次都是 O(m * n) 或 O(m)、O(n)。

**空间复杂度：** O(1)，只使用了两个布尔变量（标记信息复用了输入矩阵自身）。

**易错点 / 边界情况：**

- 必须先用布尔变量保存第一行/第一列的原始状态，再做标记；顺序反了会把标记当成原始数据。
- 第 2、3 步的下标都要从 1 开始，跳过第一行和第一列；否则会把标记位本身当作数据置零，产生连锁错误。
- 处理第一行/第一列必须放在第 3 步之后，否则它们置的零会被后面的循环当作标记。
- `m == 1` 或 `n == 1` 时中间两重循环不执行，完全依赖两个布尔变量兜底，要确保此时逻辑仍然正确。
- 标记时 `matrix[i][0] = 0` 会覆盖第一列原本的值，这没问题（该行本来就含零、需要清零），但不能影响列标记 `matrix[0][j]`。
- 第一行与第一列同时含 0 时，两个布尔变量都要生效，不能只处理其中一个。

## Go 代码实现

```go
// setZeroes 将矩阵中含 0 的行和列全部置零（原地操作）
// 使用第一行和第一列作为标记数组，实现 O(1) 额外空间
func setZeroes(matrix [][]int) {
    m, n := len(matrix), len(matrix[0])
    // firstRowZero 标记第一行是否需要置零
    // firstColZero 标记第一列是否需要置零
    firstRowZero := false
    firstColZero := false

    // 1. 检查第一行是否有 0
    for j := 0; j < n; j++ {
        if matrix[0][j] == 0 {
            firstRowZero = true
            break
        }
    }

    // 2. 检查第一列是否有 0
    for i := 0; i < m; i++ {
        if matrix[i][0] == 0 {
            firstColZero = true
            break
        }
    }

    // 3. 使用第一行和第一列作为标记数组
    // 遍历其余位置，如果 matrix[i][j] == 0，在对应的第一行和第一列做标记
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][j] == 0 {
                matrix[i][0] = 0 // 标记该行
                matrix[0][j] = 0 // 标记该列
            }
        }
    }

    // 4. 根据标记，将对应行和列的元素置零（跳过第一行第一列）
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][0] == 0 || matrix[0][j] == 0 {
                matrix[i][j] = 0
            }
        }
    }

    // 5. 处理第一行
    if firstRowZero {
        for j := 0; j < n; j++ {
            matrix[0][j] = 0
        }
    }

    // 6. 处理第一列
    if firstColZero {
        for i := 0; i < m; i++ {
            matrix[i][0] = 0
        }
    }
}
```
