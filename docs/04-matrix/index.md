# 第四章：矩阵

## 数据结构与算法背景

矩阵（Matrix）是二维数组，在线性代数和计算机科学中广泛应用。在算法面试中，矩阵题目主要考察对二维空间的遍历、索引操作和空间想象能力。

### 常见题型

1. **矩阵遍历**：螺旋矩阵、对角线遍历等，考察方向控制和边界处理
2. **原地旋转**：旋转图像，要求 O(1) 空间复杂度
3. **状态标记**：使用矩阵自身进行状态标记（如原地修改、多状态编码）
4. **模拟游戏规则**：生命游戏等，需要正确处理并发更新

### 解题关键

- 熟练掌握四方向（上下左右）的索引变化
- 对于原地算法，善用转置、翻转、符号标记等技巧
- 注意边界条件的处理（长宽不一致的情况）
- 对于需要原地更新的题目，考虑使用额外状态位保留旧值
