# 36. 旋转图像

## 题目描述

给定一个 `n x n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**示例 1：**

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**约束条件：**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 题目分析

**算法思路：** 顺时针旋转 90 度可以分解为两步：

1. **转置**（沿主对角线翻转）：`matrix[i][j]` 与 `matrix[j][i]` 交换
2. **水平翻转**（每行逆序）：`matrix[i][j]` 与 `matrix[i][n-1-j]` 交换

数学原理：顺时针旋转 90 度等于 `(i, j) -> (j, n-1-i)`。而 `转置 + 水平翻转 = (i, j) -> (j, i) -> (j, n-1-i)`。

**时间复杂度：** O(n^2)，每个元素被访问两次。

**空间复杂度：** O(1)，原地操作。

## Go 代码实现

```go
// rotate 将 n x n 矩阵顺时针旋转 90 度（原地操作）
// 先转置再水平翻转
func rotate(matrix [][]int) {
    n := len(matrix)

    // 第一步：矩阵转置（沿主对角线翻转）
    // 只需遍历上三角区域
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        }
    }

    // 第二步：水平翻转（每行逆序）
    // 每行的左右元素依次交换
    for i := 0; i < n; i++ {
        for j := 0; j < n/2; j++ {
            matrix[i][j], matrix[i][n-1-j] = matrix[i][n-1-j], matrix[i][j]
        }
    }
}
```
