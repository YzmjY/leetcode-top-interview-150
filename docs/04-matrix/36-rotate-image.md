# 36. 旋转图像

## 题目描述

给定一个 `n x n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**示例 1：**

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**约束条件：**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 题目分析

**算法思路：** 直接按 `(i, j) -> (j, n-1-i)` 做四元循环交换是可行的，但需要小心处理每个四元组，容易写错。更简单的观察是：顺时针旋转 90 度可以由两个**已知的简单变换**复合得到——

1. **转置**（沿主对角线翻转）：把 `(i, j)` 处的元素送到 `(j, i)`；
2. **水平翻转**（每行逆序）：把 `(j, i)` 处的元素送到 `(j, n-1-i)`。

两者复合后 `(i, j) -> (j, n-1-i)`，正是顺时针旋转 90 度后元素的新位置。这两个操作都只需要比较交换，天然满足「原地」的要求。

数学原理：顺时针旋转 90 度等于 `(i, j) -> (j, n-1-i)`。而 `转置 + 水平翻转 = (i, j) -> (j, i) -> (j, n-1-i)`。

**算法步骤：**

1. 转置：只遍历主对角线以上的元素（`j` 从 `i+1` 到 `n-1`），交换 `matrix[i][j]` 与 `matrix[j][i]`。
2. 水平翻转：对每一行，只遍历前一半（`j` 从 `0` 到 `n/2-1`），交换 `matrix[i][j]` 与 `matrix[i][n-1-j]`。

**为什么正确：** 设 `n` 阶矩阵，转置是对合变换（做两次等于不变），水平翻转也是；只遍历上三角/前半行保证每对元素恰好交换一次，不会交换两次又变回原位。设元素原来在第 `i` 行第 `j` 列：转置后它到第 `j` 行第 `i` 列；水平翻转后列下标变为 `n-1-i`，即来到第 `j` 行第 `n-1-i` 列。这恰是顺时针旋转 90 度把原第 `i` 行（自左向右）变成第 `n-1-i` 列（自上向下）的结果。由于该映射是 `n^2` 个位置上的双射，所有元素恰好各就各位，最终矩阵正确。

**时间复杂度：** O(n^2)，转置处理上三角约 `n^2/2` 个元素，水平翻转处理约 `n^2/2` 个元素，合计仍是 O(n^2)。

**空间复杂度：** O(1)，仅借助交换用的临时变量原地修改。

**易错点 / 边界情况：**

- 转置必须从 `j = i + 1` 开始，遍历整个矩阵会把每对元素交换两次，等于没转置。
- 水平翻转必须只遍历 `j < n/2`，同理。
- 顺序不能反：顺时针 90 度 = 「先转置，再水平翻转」；若先水平翻转再转置，得到的其实是逆时针 90 度。
- 逆时针 90 度是「转置 + 垂直翻转」，注意区分方向。
- 交换要用并行赋值 `a, b = b, a`，写成分步会互相覆盖。
- `n = 1` 时转置与翻转的循环体都不执行，结果不变，正确。
- 函数原地修改入参、没有返回值，调用方必须传可变的二维切片（切片元素可写）。

## Go 代码实现

```go
// rotate 将 n x n 矩阵顺时针旋转 90 度（原地操作）
// 先转置再水平翻转
func rotate(matrix [][]int) {
    n := len(matrix)

    // 第一步：矩阵转置（沿主对角线翻转）
    // 只需遍历上三角区域
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        }
    }

    // 第二步：水平翻转（每行逆序）
    // 每行的左右元素依次交换
    for i := 0; i < n; i++ {
        for j := 0; j < n/2; j++ {
            matrix[i][j], matrix[i][n-1-j] = matrix[i][n-1-j], matrix[i][j]
        }
    }
}
```
