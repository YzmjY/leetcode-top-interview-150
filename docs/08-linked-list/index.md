# 第八章 链表

## 链表数据结构

链表（Linked List）是一种线性数据结构，其中的元素不存储在连续的内存位置，而是通过**指针**将一系列节点连接在一起。

### 链表的核心特点

- **动态大小**：不需要预先分配大小，可以根据需要动态增长和收缩。
- **高效插入/删除**：在已知节点位置的情况下，插入和删除操作只需 O(1) 时间（修改指针即可）。
- **随机访问效率低**：不能像数组那样 O(1) 访问任意位置的元素，必须从头遍历，O(n)。
- **额外空间开销**：每个节点需要额外的指针存储空间。

### Go 中链表节点的定义方式

在 Go 中，链表节点通常定义为包含数据域和指针域的结构体：

**单向链表节点：**

```go
type ListNode struct {
    Val  int       // 数据域：存储节点的值
    Next *ListNode // 指针域：指向下一个节点
}
```

**双向链表节点：**

```go
type DLinkedNode struct {
    Key, Val int          // 数据域
    Prev     *DLinkedNode // 指向前驱节点
    Next     *DLinkedNode // 指向后继节点
}
```

**创建与遍历链表的示例：**

```go
// 使用数组构建链表
func buildList(nums []int) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    for _, v := range nums {
        cur.Next = &ListNode{Val: v}
        cur = cur.Next
    }
    return dummy.Next
}

// 遍历链表
for cur := head; cur != nil; cur = cur.Next {
    fmt.Println(cur.Val)
}
```

### 链表与数组的对比

| 操作 | 数组 | 链表 |
|------|------|------|
| 随机访问 | O(1) | O(n) |
| 头部插入/删除 | O(n) | O(1) |
| 尾部插入/删除 | O(1)* | O(1)/O(n) |
| 中间插入/删除 | O(n) | O(1)（已知节点位置） |
| 空间效率 | 无额外开销 | 需额外指针空间 |
| 缓存友好性 | 高（连续内存） | 低（内存分散） |

## 常见链表题型

### 1. 环形链表检测（快慢指针）

使用快慢指针（Floyd 判圈算法）：慢指针每次走 1 步，快指针每次走 2 步。若快慢指针相遇，说明存在环。从相遇点和头节点各出发一个指针，每次走 1 步，再次相遇处即为环入口。

**关键代码模板：**

```go
func hasCycle(head *ListNode) bool {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}
```

### 2. 链表反转

**关键技巧**：三指针法（prev、cur、next），逐步反转指针方向。

```go
func reverse(head *ListNode) *ListNode {
    var prev *ListNode
    cur := head
    for cur != nil {
        next := cur.Next // 暂存后继
        cur.Next = prev  // 反转指针
        prev = cur       // 前进
        cur = next
    }
    return prev
}
```

**变体**：
- 反转链表 II（指定范围反转）
- K 个一组翻转链表
- 头插法（穿针引线法）

### 3. 链表合并

将两个有序链表合并为一个有序链表。使用双指针比较节点值，每次取较小者连接。可使用 `dummy` 节点简化头节点处理。

### 4. 删除节点

- **删除指定值节点**：遍历找到目标并跳过。
- **删除倒数第 N 个节点**：双指针法，快指针先走 N 步，然后两个指针同时移动。
- **删除重复元素**：注意区分保留一个 vs 全部删除（需要 dummy 节点）。

### 5. LRU 缓存

结合**哈希表 + 双向链表**实现 O(1) 的 GET 和 PUT 操作：
- 哈希表提供 O(1) 的键值查找。
- 双向链表维护访问顺序（最近使用的在头部，最久未使用的在尾部）。

### 6. 模拟运算

用链表表示大整数，逐位相加并处理进位（如两数相加）。

## 链表题常用技巧

1. **Dummy 节点（哨兵节点）**：在头节点前创建一个虚拟节点，统一处理边界情况（如删除头节点）。
2. **快慢指针**：用于找中点、判环、找倒数第 N 个节点。
3. **头插法**：用于 K 个一组反转等场景中重建局部链表。
4. **多指针协作**：pre、cur、next 三指针反转链表。
5. **哈希表辅助**：复制带随机指针的链表等场景。
