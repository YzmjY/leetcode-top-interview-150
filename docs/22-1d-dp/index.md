# 第22章 一维动态规划 (1D Dynamic Programming)

## 章节概述

动态规划（Dynamic Programming, DP）是算法面试中最核心的考点之一。一维 DP 是 DP 的入门形态，它的状态只需要一个维度来表示，是理解 DP 思想的最佳起点。

## DP 核心概念

### 1. 状态定义

状态是 DP 的核心。对于一维 DP，通常定义为：
- `dp[i]` 表示以第 i 个元素结尾（或前 i 个元素）的最优解。
- 例如：`dp[i]` = 到达第 i 级台阶的方法数，`dp[i]` = 偷前 i 间房子的最大收益。

### 2. 状态转移方程

状态转移方程描述了当前状态如何从之前的状态推导而来。常见的转移模式：

- **线性递推**：`dp[i] = dp[i-1] + dp[i-2]`（斐波那契类）
- **选择/不选择**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`（打家劫舍类）
- **分割枚举**：`dp[i] = max(dp[j] + ...)` for j < i（单词拆分、LIS 类）
- **最值子问题**：`dp[i] = min(dp[i-coin] + 1)`（零钱兑换类）

### 3. 边界条件

边界条件是 DP 正确性的基础，必须明确定义 `dp[0]`、`dp[1]` 等初始状态。

### 4. 遍历顺序

一维 DP 通常从前向后遍历，但有时也需要从后向前（与状态依赖关系有关）。

## 常见优化技巧

- **滚动数组**：当 `dp[i]` 只依赖于固定的前几个状态时，可以用 O(1) 空间替代 O(n) 空间。
- **状态压缩**：将多种状态合并到一维中表达。

## 复杂度速查

- 爬楼梯：时间 O(n)，空间 O(1)（滚动优化）
- 打家劫舍：时间 O(n)，空间 O(1)（滚动优化）
- 单词拆分：时间 O(n^2)，空间 O(n)
- 零钱兑换：时间 O(amount * n)，空间 O(amount)
- 最长递增子序列：时间 O(n^2) 或 O(n log n)（二分优化），空间 O(n)
