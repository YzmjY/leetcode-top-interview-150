# 138. 打家劫舍 (House Robber)

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

**示例 1：**

```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**

```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

**约束条件：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 题目分析

### 算法思路

**朴素想法**：枚举每间房「偷/不偷」，共 2^n 种，n ≤ 100 时不可行。但相邻约束是局部的，当前决策只受前一间影响，适合 DP。

**方法：一维 DP（选/不选模式）**

- **状态定义**：`dp[i]` = 只考虑下标 `0..i` 这些房子时，能偷到的最大金额。
- **状态转移**：对第 i 间房子只有两种选择：
  - **不偷**：最大金额 = `dp[i-1]`；
  - **偷**：第 i-1 间就不能偷，最大金额 = `dp[i-2] + nums[i]`。
  两者取最大：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。
- **边界条件**：`dp[0] = nums[0]`（只有一间房，偷它）；`dp[1] = max(nums[0], nums[1])`（两间房只能偷其中一间）。空数组按题意返回 0。

**为什么正确**：`dp[i]` 的两项恰好枚举了第 i 间房「不偷」「偷」这两种互斥且完备的情况。不偷时问题退化为下标 `0..i-1` 的最优值；偷时由约束必须跳过 i-1，剩下的问题正是下标 `0..i-2` 的最优值加 `nums[i]`。两者分别由归纳假设达到各自子问题的最优，取最大值即为 `dp[i]` 的最优解，最优子结构成立。

**空间优化**：只依赖前两个状态，用 `prev2 = dp[i-2]`、`prev1 = dp[i-1]` 滚动更新，空间降到 O(1)。

### 复杂度分析

- **时间复杂度**：O(n)，一次线性遍历。
- **空间复杂度**：O(1)，只用两个滚动变量。

### 关键点

- 状态定义的下标口径要一致：代码里 `dp[i]` 表示「下标 0..i 的房子」，因此 `dp[0] = nums[0]`；如果改成「前 i 间」的口径，就要配 `dp[0] = 0`、`dp[1] = nums[0]`，两种写法不能混用。
- 空数组和单元素要单独处理，否则 `prev1 := max(nums[0], nums[1])` 会越界。
- 与爬楼梯的区别在于状态转移里多了 `max`：每间房可以主动选择放弃。

## Go 代码实现

```go
package main

func rob(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    if n == 1 {
        return nums[0]
    }

    // prev2 = dp[i-2], prev1 = dp[i-1]
    prev2 := nums[0]
    prev1 := max(nums[0], nums[1])

    for i := 2; i < n; i++ {
        current := max(prev1, prev2+nums[i])
        prev2 = prev1
        prev1 = current
    }

    return prev1
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```
