# 第十章 二叉树的层序遍历（BFS）

## 算法背景

层序遍历（Level Order Traversal）是二叉树的一种遍历方式，按照从上到下、从左到右的顺序逐层访问节点。与 DFS（前序、中序、后序）不同，层序遍历属于**广度优先搜索（BFS）**，使用队列（Queue）数据结构实现。

## 层序遍历通用模板

层序遍历的核心模板如下，几乎所有 BFS 相关题目都可以在此模板基础上进行修改：

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func levelOrder(root *TreeNode) [][]int {
    if root == nil {
        return nil
    }

    var result [][]int
    queue := []*TreeNode{root} // 初始化队列

    for len(queue) > 0 {
        levelSize := len(queue) // 当前层的节点数（关键信息）
        var level []int

        for i := 0; i < levelSize; i++ {
            node := queue[0]  // 出队
            queue = queue[1:]

            level = append(level, node.Val) // 处理当前节点

            // 将子节点入队
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        result = append(result, level) // 保存当前层结果
    }

    return result
}
```

### 模板要点

1. **队列（Queue）**：使用 Go 切片模拟队列，`append` 入队，`[1:]` 出队。
2. **层大小（levelSize）**：在每层开始时记录当前队列长度，这是处理当前层的关键——它告诉我们在本轮循环中需要出队多少个节点。
3. **逐层处理**：外层 `for` 循环控制层数，内层 `for` 循环处理当前层的每个节点并收集子节点。
4. **结果存储**：根据题目需求，可以按层存储为二维数组，或计算每层的统计量。

## 常见题型分类

### 1. 基础层序遍历

直接要求返回层序遍历结果，是 BFS 的最基本考察。

**代表题目**：二叉树的层序遍历

### 2. 层统计量

在层序遍历的基础上，对每层节点值进行统计计算（求和、平均值、最大值等）。

**代表题目**：二叉树的层平均值

### 3. 视图问题

从特定视角看二叉树（右侧视图、左侧视图、俯视图等），本质是取每层的最后一个（或第一个）节点。

**代表题目**：二叉树的右视图

### 4. 变形遍历

改变遍历方向，如锯齿形（Z 字形）遍历，只需在标准模板基础上控制每层的结果排列方向。

**代表题目**：二叉树的锯齿形层序遍历

## 解题关键技巧

1. **掌握 BFS 模板**：层序遍历模板是解决此类题目的基石，需要烂熟于心。
2. **levelSize 不可省略**：必须记录每层的节点数，否则无法区分层级。
3. **方向控制**：锯齿形遍历等变体只需控制每层填充结果的顺序（正序/反序）。
4. **DFS 替代方案**：某些 BFS 问题也可以用 DFS 解决（记录深度信息），但 BFS 通常更直观。

## BFS vs DFS 对比

| 特性 | BFS（层序遍历） | DFS（前/中/后序遍历） |
|------|----------------|----------------------|
| 数据结构 | 队列（Queue） | 栈（Stack）/ 递归 |
| 空间复杂度 | O(w)，w 为树的最大宽度 | O(h)，h 为树的高度 |
| 适用场景 | 逐层处理、最短路径 | 路径问题、树结构变换 |
| 实现方式 | 迭代 | 递归 + 迭代 |
