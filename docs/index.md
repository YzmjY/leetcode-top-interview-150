## 每道题解包含

每道题解文档包含三个部分：

- **题目描述**：题目的完整描述，包括输入输出格式和约束条件
- **题目分析**：解题思路分析，包括算法选择、时间空间复杂度分析
- **Go 代码实现**：完整可运行的 Go 语言代码，包含详细注释

## 快速开始

```bash
# 安装依赖
pip install mkdocs-material

# 启动本地预览
mkdocs serve

# 构建静态站点
mkdocs build
```
