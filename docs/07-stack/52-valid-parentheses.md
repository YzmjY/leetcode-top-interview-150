# 52. 有效的括号

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

```
输入：s = "()"
输出：true
```

**示例 2：**

```
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```
输入：s = "(]"
输出：false
```

**示例 4：**

```
输入：s = "([])"
输出：true
```

**约束条件：**

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 题目分析

### 算法思路

**核心思路：** 先想简单做法：只统计左括号和右括号的数量是否相等？这不够——`"([)]"` 的括号数量完全配对，却不是合法序列。问题出在**交叉**：不同类型的括号必须各自嵌套，不能互相穿插。

再想一步：合法括号序列的结构是递归的——要么是 `()`（空串被一对括号包住），要么是 `A B`（两个合法序列拼接），要么是 `(A)`（合法序列被一对括号包住）。这种「最近出现的左括号，最先需要一个右括号来配它」的嵌套结构，正是**后进先出**，所以用栈。

**算法步骤：**

1. 用一个映射 `pairs` 记下右括号到左括号的对应关系：`)→(`、`]→[`、`}→{`。
2. 用切片 `stack` 当栈，遍历字符串的每个字符 `ch`：
   - 若 `ch` 是右括号（在 `pairs` 里查得到）：
     - 若栈为空，说明没有与它匹配的左括号，直接返回 `false`；
     - 若栈顶不是它对应的左括号，说明类型不匹配，返回 `false`；
     - 否则弹出栈顶，配对成功。
   - 否则 `ch` 是左括号，压入栈中。
3. 遍历结束后，若栈为空返回 `true`，否则返回 `false`（还有左括号没被闭合）。

**为什么正确：** 用循环不变量论证。**不变量：处理完前 `i` 个字符后，栈中从底到顶恰好是这 `i` 个字符里所有「已出现但尚未匹配」的左括号，且按它们出现的先后顺序排列。**

- 遇到左括号：它尚未匹配，压到栈顶，栈中顺序仍是出现顺序，不变量保持。
- 遇到右括号 `ch`：它只能和「最近一个未匹配的左括号」匹配（因为括号不能交叉，任何更早的左括号都必须等它内部的括号全部闭合后才轮到）。这个「最近的未匹配左括号」正是栈顶。若栈为空或栈顶类型不同，则该右括号无处可配，序列不可能合法，提前返回正确；否则弹出栈顶，不变量保持。
- 遍历结束时，不变量说明栈中就是所有未匹配的左括号。全部匹配的充要条件正是栈空。因此返回 `len(stack) == 0` 是精确的判定。

### 复杂度分析

- **时间复杂度**：O(n)。每个字符只处理一次，且每个字符最多进出栈各一次，入栈出栈都是均摊 O(1)。
- **空间复杂度**：O(n)。最坏情况（如 `"((((…"`）栈里存下所有字符；映射表的大小固定为常数，不计入。

### 易错点 / 边界情况

- **三种失败情形都要覆盖**：① 右括号到来时栈为空（如 `")"`、`"()]"`）；② 栈顶类型不匹配（如 `"(]"`）；③ 遍历结束后栈非空（如 `"("`、`"([")`。漏掉任意一种都会得到错误的解。
- **不能只数数量**：`"([)]"` 左右括号数量相等，但交叉嵌套不合法。栈顶检查才能发现它。
- **匹配判断的写法**：用 `if left, ok := pairs[ch]; ok` 判断「是不是右括号」是清晰的；若写成 `pairs[ch] != 0`，虽然本题字符集中恰好成立，但依赖了「零值不会出现在映射值里」这个巧合，不可靠。
- **按字节遍历即可**：题目限定 `s` 只由 ASCII 括号组成，`s[i]` 取 `byte` 不会把一个多字节字符拆开。
- **长度剪枝**：奇数长度的字符串一定无效，可以提前返回 `false`。这是可选的常数优化，不影响正确性。
- **栈用切片实现**：弹出后切片尾部的元素不需要清零，但要注意弹出前必须先判空，否则 `stack[len(stack)-1]` 会 panic。
- **题目没有空串情形**（`1 <= s.length`），但加上空串处理返回 `true` 也无害——空串是合法序列。

## Go 代码实现

```go
func isValid(s string) bool {
    // 右括号到左括号的映射
    pairs := map[byte]byte{
        ')': '(',
        ']': '[',
        '}': '{',
    }

    stack := []byte{}

    for i := 0; i < len(s); i++ {
        ch := s[i]
        // 如果是右括号
        if left, ok := pairs[ch]; ok {
            // 栈为空或栈顶不匹配
            if len(stack) == 0 || stack[len(stack)-1] != left {
                return false
            }
            // 匹配成功，弹出栈顶
            stack = stack[:len(stack)-1]
        } else {
            // 左括号直接入栈
            stack = append(stack, ch)
        }
    }

    // 栈为空说明所有括号都匹配
    return len(stack) == 0
}
```
