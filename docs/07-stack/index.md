# 第七章 栈

## 栈简介

栈（Stack）是一种**后进先出**（LIFO, Last In First Out）的线性数据结构。元素的添加（入栈 / Push）和删除（出栈 / Pop）都在同一端（栈顶）进行。

### 栈的基本操作

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| Push | 将元素压入栈顶 | O(1) |
| Pop | 弹出栈顶元素并返回 | O(1) |
| Peek/Top | 查看栈顶元素（不出栈） | O(1) |
| IsEmpty | 判断栈是否为空 | O(1) |
| Size | 获取栈中元素个数 | O(1) |

### Go 中的栈实现

Go 中没有内置的栈类型，通常使用切片（slice）来模拟：

```go
// 使用切片模拟栈
stack := []int{}
// Push
stack = append(stack, val)
// Pop
val := stack[len(stack)-1]
stack = stack[:len(stack)-1]
// Peek
val := stack[len(stack)-1]
// IsEmpty
len(stack) == 0
```

## 栈的经典应用场景

1. **括号匹配**：利用栈的 LIFO 特性检查括号是否合法配对。
2. **表达式求值**：中缀/后缀表达式（逆波兰表达式）的计算。
3. **函数调用**：编程语言中的函数调用栈。
4. **撤销操作**：编辑器中的 Undo 操作。
5. **路径简化**：Unix 路径的规范化。
6. **单调栈**：寻找下一个更大/更小元素等问题。

## 常见题型

1. **括号匹配与合法性校验**：如有效的括号、简化路径。
2. **辅助栈设计**：如最小栈（在 O(1) 时间获取最小值）。
3. **表达式求值**：如逆波兰表达式求值、基本计算器。
