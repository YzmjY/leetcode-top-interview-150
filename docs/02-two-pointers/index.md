# 第二章：双指针

## 数据结构与算法背景

双指针（Two Pointers）是一种在数组或链表中使用两个指针协同工作的算法技巧。它通常能将暴力解法的 O(n^2) 时间复杂度优化到 O(n)，是面试中最高频的技巧之一。

### 常见题型

1. **对撞指针**：左右指针从两端向中间移动，常用于有序数组、回文判断、两数之和等
2. **快慢指针**：一快一慢两个指针同向移动，常用于链表环检测、数组去重等
3. **分离指针**：两个指针分别遍历不同的数据结构，常用于合并有序数组等

### 解题关键

- 明确两个指针的移动规则和停止条件
- 对于对撞指针，通常需要先排序或利用已排序的性质
- 注意去重逻辑，避免重复答案
- 灵活运用 `left++` / `right--` 的组合来控制搜索空间
