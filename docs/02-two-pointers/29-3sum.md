# 29. 三数之和

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0。
不同的三元组是 [-1,0,1] 和 [-1,-1,2]。
注意，输出的顺序和三元组的顺序并不重要。
```

**示例 2：**

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

**示例 3：**

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

**约束条件：**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 题目分析

**算法思路：** 直接三重循环枚举是 O(n³)，需要降到 O(n²)。关键是把「三数之和」拆成「固定一个数 + 两数之和」：枚举第一个数 `nums[i]` 后，问题变成在剩余区间里找两个数之和等于 `-nums[i]`。如果剩余数组有序，就能用对撞双指针 O(n) 完成，于是先排序（O(n log n)），再对每个 `i` 做一次双指针扫描。排序还顺带解决了去重：相同的数会挨在一起。

**算法步骤：**

1. 对 `nums` 排序（**原地排序，会修改传入的切片**）。
2. 枚举 `i` 从 0 到 `n-3` 作为三元组中最小的数：
   - 若 `nums[i] > 0`，由于数组已升序，后面不可能再有和为 0 的组合，直接 `break`；
   - 若 `i > 0 && nums[i] == nums[i-1]`，说明以该值为最小数的三元组已经找过，`continue` 去重。
3. 在区间 `[i+1, n-1]` 内用双指针 `left, right` 找 `nums[left] + nums[right] == -nums[i]`：
   - 相等：记录 `[nums[i], nums[left], nums[right]]`；然后让 `left` 跳过所有重复值、`right` 跳过所有重复值，再各移动一步；
   - 和偏小：`left++`；和偏大：`right--`。
4. 返回结果。

**不变量：** 外层枚举到 `i` 时，以 `nums[0..i-1]` 中任意元素为最小数的解都已收集完毕；内层双指针区间 `[left, right]` 内仍包含所有以 `nums[i]` 为最小数、尚未被排除的解。

**为什么正确（双指针与去重都正确）：**

- **双指针**：区间已升序。若 `nums[left] + nums[right] < target`，对任意 `k < right` 有 `nums[k] <= nums[right]`，和只会更小，故 `left` 与区间内任何元素都凑不出 target，排除 `left`；反之排除 `right`。这与「两数之和 II」的排除法完全一致。
- **去重**：三元组按 `[最小, 中间, 最大]` 生成，排序保证每个三元组只有一种有序表示。外层跳过与 `nums[i-1]` 相同的 `i`，避免重复的「最小数」；内层找到解后跳过与当前 `nums[left]`、`nums[right]` 相同的值，避免同一个三元组被多次记录。三元组互不相同当且仅当其有序表示不同，所以结果不重不漏。

**时间复杂度：** O(n²)。排序 O(n log n)，外层 O(n) 次、每次内层双指针 O(n)，合计 O(n²) 为主导项。

**空间复杂度：** O(log n)（不计结果数组）。除结果外只有常数个变量，主要额外开销是排序的递归栈（Go 的 `sort.Ints` 为原地排序，栈深 O(log n)）。结果数组需要 O(k)，k 为解的个数，通常不计入算法空间。

**易错点：**

- **排序会原地修改入参 `nums`**，函数返回后调用方拿到的数组已被重排；若后续还要用原顺序，需要自行拷贝。
- 题目示例解释里的 `nums[0]`、`nums[4]` 等下标是**排序前**的下标，而代码先排序再处理，两套下标并不对应，阅读示例时容易混淆。
- 内层去重要在「找到解之后」再做，并且先跳过重复的 `left`/`right`、再各移动一步，顺序写错可能漏解或死循环。
- `nums[i] > 0` 的剪枝依赖升序；写成 `>= 0` 会漏掉 `[0,0,0]` 这组解。
- 结果顺序任意，比较答案时需按集合/排序后比较。
- `nums[i]` 绝对值可达 10^5，三数之和不超过 3×10^5，32 位 int 足够。

## Go 代码实现

```go
import "sort"

// threeSum 找出所有和为 0 的不重复三元组
// 排序 + 固定一个数 + 对撞双指针
func threeSum(nums []int) [][]int {
    // 先排序，便于使用双指针和去重
    sort.Ints(nums)
    n := len(nums)
    result := make([][]int, 0)

    // 固定第一个数
    for i := 0; i < n-2; i++ {
        // 如果最小的数大于 0，后面的和不可能等于 0
        if nums[i] > 0 {
            break
        }
        // 去重：跳过重复的第一个数
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }

        // 双指针寻找另外两个数
        left, right := i+1, n-1
        target := -nums[i]

        for left < right {
            sum := nums[left] + nums[right]
            if sum == target {
                // 找到一组解
                result = append(result, []int{nums[i], nums[left], nums[right]})
                // 去重：跳过重复的 left
                for left < right && nums[left] == nums[left+1] {
                    left++
                }
                // 去重：跳过重复的 right
                for left < right && nums[right] == nums[right-1] {
                    right--
                }
                left++
                right--
            } else if sum < target {
                // 和太小，左指针右移
                left++
            } else {
                // 和太大，右指针左移
                right--
            }
        }
    }

    return result
}
```
