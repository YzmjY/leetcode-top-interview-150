# 29. 三数之和

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0。
不同的三元组是 [-1,0,1] 和 [-1,-1,2]。
注意，输出的顺序和三元组的顺序并不重要。
```

**示例 2：**

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

**示例 3：**

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

**约束条件：**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 题目分析

**算法思路：** 排序 + 固定一个数 + 对撞双指针。核心思路将三数之和转化为两数之和：

1. 先对数组排序（O(n log n)）
2. 固定第一个数 `nums[i]`，然后在 `[i+1, n-1]` 范围内使用双指针寻找满足 `nums[left] + nums[right] == -nums[i]` 的两个数
3. 当三数之和小于 0 时，`left++`；大于 0 时，`right--`
4. 关键是去重：固定第一个数时跳过重复值；找到答案后，跳过重复的 `left` 和 `right`

**时间复杂度：** O(n^2)，排序 O(n log n)，双指针扫描 O(n^2)。

**空间复杂度：** O(1)（不考虑排序栈空间和结果数组）。

## Go 代码实现

```go
import "sort"

// threeSum 找出所有和为 0 的不重复三元组
// 排序 + 固定一个数 + 对撞双指针
func threeSum(nums []int) [][]int {
    // 先排序，便于使用双指针和去重
    sort.Ints(nums)
    n := len(nums)
    result := make([][]int, 0)

    // 固定第一个数
    for i := 0; i < n-2; i++ {
        // 如果最小的数大于 0，后面的和不可能等于 0
        if nums[i] > 0 {
            break
        }
        // 去重：跳过重复的第一个数
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }

        // 双指针寻找另外两个数
        left, right := i+1, n-1
        target := -nums[i]

        for left < right {
            sum := nums[left] + nums[right]
            if sum == target {
                // 找到一组解
                result = append(result, []int{nums[i], nums[left], nums[right]})
                // 去重：跳过重复的 left
                for left < right && nums[left] == nums[left+1] {
                    left++
                }
                // 去重：跳过重复的 right
                for left < right && nums[right] == nums[right-1] {
                    right--
                }
                left++
                right--
            } else if sum < target {
                // 和太小，左指针右移
                left++
            } else {
                // 和太大，右指针左移
                right--
            }
        }
    }

    return result
}
```
