合并两个有序数组 Merge Sorted Array

题目说明LEETCODE 88

给你两个按非递减顺序排列的整数数组 nums1 和 nums2，以及各自的有效元素个数 m 和 n。请将 nums2 合并到 nums1 中，使合并后的数组仍然有序。

你需要原地修改 nums1，无须返回值。它的长度为 m + n：前 m 项是有效元素，后 n 个零是预留位置，不参与比较。

示例输入nums1 = [1, 2, 3, 0, 0, 0]，m = 3
nums2 = [2, 5, 6]，n = 3
合并结果[1, 2, 2, 3, 5, 6]
数组 / 字符串逆向双指针原地合并O(m + n)

§ 02 · STRATEGY

解题思路

换一个方向，问题就简单了。
01.

先看空间，再定方向

nums1 的后面已有 n 个预留位置。从前往后写会覆盖未读元素；从后往前填，就能安全复用这些空间。

02.

比较末尾，大的先落位

i、j 分别指向两组有效元素的末尾。比较后，将较大值写入 nums1[k]，再把对应指针和 k 左移。

03.

直到第二组全部归位

当 j < 0，合并就已完成。第一组尚未移动的前缀天然有序，无须再复制。相等时取第二组，结果依然正确。

↳

每个元素至多处理一次，时间为 O(m + n)；只维护三个指针，额外空间为 O(1)。

k = i + j + 1
